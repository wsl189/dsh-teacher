# @deepseek-ai/dsh-client-ui-teacher-workbench

[English](README.md) | 中文

dsh Web GUI 的教师工作台功能。它在“新会话”和工作区浏览之间贡献“工作台”折叠入口，在 `shell.main` 中贡献应用内教学界面，并在“常规设置”中贡献本功能拥有的设置行。选择已展开的模块后，工作台会直接显示在中间内容区，同时保留应用侧边栏。界面直接从当前模块开始，不重复显示“工作台”标题栏；选择或再次选择任一会话以及进入新会话时，工作台会退出并显示仍在挂载的会话。

界面首先提供“日常管理”。模块标题右侧的摘要以右对齐方式显示当前时间、日期、天气地点与实时天气，点击后可查看完整时间信息和未来 12 小时预报。今日待办、重要事项和紧急事项分别占用等宽独立卡片，并与可编辑随记及包含农历、法定节假日和日期事项的可展开日历共同显示；在哪张待办卡片中新增，事项就只属于该分类，编辑时可把事项移到另一张卡片。重要事项和紧急事项行提供十色圆点选择器，今日待办行不显示颜色圆点。展开日历可经共享 OCR Remote 导入图片、PDF、DOCX、PPTX 和 XLSX 校历，将识别到的日期与活动投影为可编辑复核列表，并在一次带修订号写入中只持久化已选行。HTML 表格投影会处理跨行和跨列单元格，使负责人及部门信息与带日期事项保持分离。

课程表模块可切换今日课表、本周课表、年级课表和早晚自习。今日课表与本周课表可以选择一个班级，也可以按 dsh 设置中的教师姓名筛选全部持久化课程；个人视图会在每节课中保留班级名称。今日课表、本周课表和早晚自习共用普通课表班级目录，年级课表则持有独立班级目录，并只投影所选年级。年级课表中识别或新建的班级因此不会出现在今日课表、本周课表、早晚自习、班级名册、成绩分析或试题切割中；名册班级也不会出现在课程表控件中。本周课表、年级课表和早晚自习可通过共享 OCR Remote 接收图片、PDF、DOCX、PPTX 和 XLSX，并要求在一次批量写入前复核班级、年级、类型、星期、节次、时间、课程、教师和地点。年级课表提取会保留 OCR 外围文本，因此主表 Markdown 遗漏的年级标签仍可为序号班级列命名；早晚自习还支持班级作为列、星期作为行的安排表，包括分别列出的早读表、晚自习表与科目简称。识别出的班级名称必须以“班”结尾，该行才能被选中导入；节次或表头等结构文本会保持未选中，直至用户修正。接受的识别结果会替换已经占用的班级、类型、星期和节次组合，而不会产生相互矛盾的安排。

试题切割模块保留参考应用的顶部栏、当前年份/班级层级、叠层抽屉与操作流程，只移除其中的错题分析和图片搜索工作区。班级层级只读取名册目录，因此普通课表与年级课表班级不会出现在这里。界面使用 DSH 设计令牌，因此背景、文字、边框、控件、遮罩与强调色会跟随当前浅色或深色外观，不再固定使用独立应用的黑橙配色。双击班级会打开学生抽屉；在学生抽屉中，单击打开图片，双击展开或收起下级目录，三击新建持久化子目录。选择 PDF 后会打开原式页码选择顶层面板；留空表示全部页，并支持 `1-5,8` 这类逗号分隔的单页与区间。随后模块调用共享 `ocr.layout` Remote 获取 MinerU 页面几何信息。一条确定性规则会在相同左侧位置附近选择单调递增的题号链，把相邻题号转换为一个或多个页面区域，用 PDF.js 从浏览器中保留的原 PDF 栅格化、纵向拼接切图，并自动保存所得批次。持久图片库支持选择、预览、框选擦除、旋转、另存为、覆盖保存、删除，以及把所选试题复制给一名名册学生或其子目录。在学生图片抽屉中，“临时保存”会用当前准确勾选图片的快照替换该学生上一次生成选集，并显示暂存数量。“技能库”的 Word 与 PowerPoint 入口会先打开参考系统的目录选择器，对其中图片进行自然排序，生成一份以目录命名的产物，并显示保存或重试。班级抽屉保留独立的 Word 与 PowerPoint 操作，并仅在至少一名学生有临时图片时启用：Word 打开带批量控制的逐学生标题、姓名、日期配置，PowerPoint 直接开始生成；两者都只读取各学生的暂存快照，在成功后移除对应选集，并返回每名学生一份文件，不再打成 ZIP。单个生成文件使用“另存为”，多个结果则分别直接下载，不再申请整个目录的写入权限，从而避开 Chromium 对受保护系统文件夹的限制。学生副本仍独立于源批次，并通过同一套班级/学生抽屉流程查看。

后续模块提供日常备课资源与听课模板、支持粘贴表格导入的班级名册、与名册匹配的成绩分析，以及模板驱动的教学记录。待办分类与颜色、随记、日期事项、课程表条目、教学业务数据、试卷批次元数据与分发元数据全部通过生成的 `teacherWorkbench` Remote 读写；试题字节使用专用 Host 媒体 Remote。浏览器本地只保留折叠、当前模块、课程表筛选、板块展开、导入复核、当前抽屉、页码面板、编辑器选区和图片选择状态。本模块明确不包含试题搜索、错题分析与 LLM 二次筛选。

当前学年、教师姓名、学校、默认学科、天气地点、语音识别语言、成绩阈值、PDF 渲染倍率与切题边距属于 `ui-teacher-workbench` dsh 设置命名空间。每个班级也可保留自身的学年目录，因此多个年份可跨重载保留，而旧班级会回退到已配置的当前学年。MinerU 端点、后端、混合解析质量、语言、超时与大小限制属于 DSH 插件设置中的 `dsh-ocr-mineru` 插件行。试卷批次与学生目录，以及每图与每批次字节上限，属于 `teacher-workbench` 插件行。天气地点可填写区县或城市；重名时可在逗号后补充上级市或省份，例如 `浦东新区, 上海市`。天气板块的展开视图也可更新地点，经过校验的预报通过 Host 的 `teacherWorkbench/weather` Remote 获取，因此浏览器跨域或隐私策略不会拦截天气服务请求；语音入口会先请求麦克风权限，再启动浏览器 Web Speech API，并把识别文本交给普通待办或随记编辑流程。

## 扩展点

本包占用 `sidebar.workbench`，向 `shell.main` 添加一个条目，并注册一个 `settings.general.item` 设置行；它不声明新的子 slot。

## 模型体验

无。工作台存储并呈现教师持有的业务数据，不增加提示词内容、工具或 transcript 事件。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与延后工作

- **名册导入仍仅支持剪贴板**：班级名册支持表格软件产生的制表符分隔数据和普通带引号 CSV；原生工作簿仅可用于日历识别，适合打印报告的图表仍延后实现。
- **识别校历与课程表需要复核**：密集表格、合并单元格、扫描件和手写内容可能产生错误日期、班级、节次或阅读顺序；不以“班”结尾的课程表班级名称会保持未选中，直至用户修正，原始上传与未选复核行不会存储。
- **试题检测采用确定性规则**：试卷需在相近左侧位置显示递增的顶层阿拉伯数字题号。无题号、罗马数字、特殊分栏或含义模糊的小题编号可能不产生切图或得到较粗边界；失败对话框可以重试，但不会调用 LLM 猜测缺失结构。
- **天气需要 Host 联网**：已配置的地理编码服务解析地点，当前天气和未来 12 小时预报由 Open-Meteo 提供；任一服务或宿主出站网络不可用时，已保存的工作台数据不受影响。
- **语音能力取决于浏览器**：缺少 Web Speech API 时语音按钮会禁用；麦克风权限、设备缺失、未检测到语音、语言不支持和识别网络故障会显示本地化通知，手动录入仍可使用。
- **节假日数据按年份发布**：日历在已收录年份显示中国法定节假日和调休上班日；尚未收录的年份会明确提示，但阳历、农历和个人事项仍可使用。
