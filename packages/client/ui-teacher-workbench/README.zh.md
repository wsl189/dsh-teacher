# @deepseek-ai/dsh-client-ui-teacher-workbench

[English](README.md) | 中文

dsh Web GUI 的教师工作台功能。它通过 `sidebar.primary.section` 贡献侧栏首项“工作台”，通过 `shell.overlay` 贡献应用内教学界面，并在“常规设置”中贡献本功能拥有的设置行。侧栏展开工作台时会先显示八行模块，其余入口保留滚动访问。overlay 跟随渲染后的侧边栏与详情栏宽度，因此选择已展开的模块后，工作台只替换中间内容区，同时保留应用侧边栏。界面直接从当前模块开始，不重复显示“工作台”标题栏；每次明确的会话或新会话导航都会退出工作台并显示仍在挂载的对话，包括再次选择当前会话。每次打开界面都会重新读取 Host 权威文档，使普通对话工具产生的修改替换浏览器缓存的旧快照。

界面首先提供“日常管理”。模块标题右侧的摘要以右对齐方式显示当前时间、日期、天气地点与实时天气，点击后可查看完整时间信息和未来 12 小时预报。今日待办、重要事项和紧急事项分别占用等宽独立卡片；备忘录、账本与日历组成第二行三张卡片。账本卡片会打开占满板块的视图，其中分类可新增或删除；每个分类都可手动或通过语音填写说明、填写人民币金额并设置必填的本地日期与时间，已有账目也可编辑。在哪张待办卡片中新增，事项就只属于该分类；编辑会保留该分类且不提供分类控件。重要事项和紧急事项行提供十色圆点选择器，今日待办行不显示颜色圆点。展开日历结合阳历、农历、法定节假日和日期事项，还可经共享 OCR Remote 导入图片、PDF、DOCX、PPTX 和 XLSX 校历，将识别到的日期与活动投影为可编辑复核列表，并在一次带修订号写入中只持久化已选行。HTML 表格投影会处理跨行和跨列单元格，使负责人及部门信息与带日期事项保持分离。待办的时间图标会打开同一个截止时间与提醒编辑器：设置未来截止时间后，可选择一次性提前提醒或重复频率，再从可选的 dsh-im 列表中指定一个平台和一个机器人。两种提醒都可手动输入数值，并在其后选择分钟、小时或天；编辑期间的空值或超限值会禁用保存，但不会替换尚在输入的文本。备忘录编辑器会显示同一组配置；每个账本分类的新增区都有提醒按钮，已有账目也会在编辑弹窗中保留这些控件。两者的提醒截止时间独立于备忘录修改时间和账目发生时间。已经过去的截止时间会禁用提醒开关并显示行内说明，但不会阻止保存普通修改。截止时间不足 30 分钟时，开启提醒会选择仍处于未来的最大整分钟提前量。日历议程行提供独立提醒按钮并复用相同控件；不启用提醒时仍保持普通记录且不会发送通知。

课程表模块可切换今日课表、本周课表、年级课表和早晚自习。今日课表与本周课表可以选择一个班级，也可以按 dsh 设置中的教师姓名筛选全部持久化课程；个人视图会在每节课中保留班级名称。今日课表、本周课表和早晚自习共用普通课表班级目录，年级课表则持有独立班级目录，并只投影所选年级。年级课表中识别或新建的班级因此不会出现在今日课表、本周课表、早晚自习、班级名册、成绩分析或试题切割中；名册班级也不会出现在课程表控件中。每个可编辑视图都用纯图标入口新建班级。本周课表和早晚自习用纯图标入口删除所选普通班级，年级课表则为每个班级行提供纯图标删除操作；每个图标都保留无障碍名称和悬停提示。确认提示会说明删除班级及其全部课程安排，成功删除当前班级后，选择器会切换到下一个可用班级。新建课表班级只需填写名称和年级。工具栏不再提供新增课程入口；点击本周课表、年级课表或早晚自习的空白格会直接打开课程编辑器，并填入该格对应的班级、星期、节次及适用的自习类型。本周课表、年级课表和早晚自习可接收图片、PDF、DOCX、PPTX 和 XLSX。每份上传文件都会先经过 MinerU；栅格图片请求增强整图与相互重叠的细节区域，PDF 与 Office 文件使用提取内容。确定性整理会把增强整图与合并后的细节区域作为两个独立候选，保留具有更多不同课程表时段的候选，并在数量相同时优先采用细节候选。它会拼合拆开的星期表头、重复班级轴、分离的课程／教师行和按时间排列的局部节次区段；早晚自习表会从表内或表外标题确定类型，再按年级和末尾班号对齐班级名称，优先使用当前目录的写法，否则使用来源中首个完整写法。只有这些规则没有产生可用条目时，文本 agent loop 才会检查 MinerU 结果，在不假定固定版式的前提下提交紧凑语义矩阵，修补被拒绝的草稿行，再通过结构化输出返回已接受草稿的令牌。异步工作前会锁定导入目标、班级目录、年级与默认值，因此识别期间切换视图不会改变结果去向。浏览器仍会要求在一次批量写入前复核班级、年级、类型、星期、节次、时间、课程、教师和地点。识别出的班级名称必须以“班”结尾，该行才能被选中导入；接受的识别结果会替换已经占用的班级、类型、星期和节次组合，而不会产生相互矛盾的安排。

试题切割模块保留参考应用的顶部栏、当前年份/班级层级、叠层抽屉与操作流程，移除其中的错题分析、图片搜索工作区和重复设置按钮。顶部栏只显示模块标题与操作，不显示居中的试卷名称框。班级层级只读取名册目录，因此普通课表与年级课表班级不会出现在这里。界面使用 DSH 设计令牌，因此背景、文字、边框、控件、遮罩与强调色会跟随当前浅色或深色外观，不再固定使用独立应用的黑橙配色。双击班级会从工作区最左侧打开学生抽屉；在学生抽屉中，单击打开图片，双击展开或收起下级目录，三击新建持久化子目录。选择学生会显示该学生根目录与所有子目录内的全部已分发试题，选择目录则只显示该目录内的试题。学生与目录名称在两侧固定行操作之间保持居中。再次选择同一学生或目录会收起图片抽屉。学生图片与试题库互斥：打开任一方都会先收起另一方再显示自己的抽屉。试题库目录树只投影物理目录，文件夹名最多显示前 7 个 Unicode 字符，悬停时显示完整名称；配置根目录中存在直接图片时，会用一个“试题图片库根目录”行表示该物理目录。试卷批次名不会成为目录树节点；选择目录行会打开该目录中全部持久化批次与文件系统批次的直接图片，独立的展开箭头则用于展开下级目录。叶子文件夹不显示展开占位点，只有含下级内容的文件夹显示展开箭头。标题栏用于新建根文件夹；单击文件夹会打开其中的直接图片，没有这类图片时则展开或收起目录，双击新建子目录，三击重命名，行内删除操作会移除该目录层级并把其中试卷移到上一级。再次选择已打开的目录会收起图片抽屉。关闭班级抽屉时也会先收起其图片抽屉。选择 PDF 后会打开原式页码选择顶层面板，其中的保存目录控件默认不选择目录，并且只列出现有叶子路径；页码留空表示全部页，并支持 `1-5,8` 这类逗号分隔的单页与区间。浏览器会读取所选 OCR 提供方的当前限制，只把选中的源页面复制成有界 PDF 批次；批次超限时自动二分，只有单个复制页仍无法装入时才会栅格化。无论原始 PDF 有多少字节，它都只保留在浏览器中。每个批次调用共享 `ocr.layout` Remote 获取 MinerU 页面几何信息，随后模块再以已配置的工具模型和内置语义 skill 启动一次短生命周期题目边界 agent loop。子 agent 分块读取与提供方无关的 OCR 元素，先归纳当前 PDF 的题目起点模式，再按不透明元素 id 提交顶层题头、错序续文与图形，以及需要排除的标题，接受后才返回令牌。编号可以使用任意语法，可以重启、重复、随章节变化，也可以完全不存在。Host 会拒绝不匹配或编造的 id、未排除且已识别的章节与答案标题和空裁剪；它会按可信 OCR 顺序归一化有效题头，并分配唯一的来源顺序显示序号，把已接受 id 映射回可信二维坐标，并用邻近内容限制留白。PDF.js 随后从浏览器保留的原 PDF 栅格化，只在一道题真实跨页时纵向拼接多个区域。未选择目录时，Host 会在根目录下创建或复用以 PDF 命名的真实物理目录，并把每张裁剪图片作为直接文件保存到其中；明确选择叶子目录时，图片则直接保存到该叶子目录。试卷批次 id 不会创建存储目录，批次元数据只负责分组、续传与删除。持久图片库支持选择、预览、框选擦除、旋转、另存为、覆盖保存和删除。从顶部栏打开试题库时，所选图片会用防重名文件名保存到浏览器选定的本地目录；从学生或嵌套目录打开时，所选图片则直接分发到该目标。在学生图片抽屉中，“临时保存”会用当前准确勾选图片的快照替换该学生上一次生成选集；每张图片卡片显示该题的累计已保存次数与最近保存时间。“技能库”的 Word 与 PowerPoint 入口会先打开参考系统的目录选择器，对其中图片进行自然排序，生成一份以目录命名的产物，并显示保存或重试。班级抽屉保留独立的 Word 与 PowerPoint 操作，并仅在至少一名学生有临时图片时启用：Word 打开带批量控制的逐学生标题、姓名、日期配置，PowerPoint 直接开始生成；两者都只读取各学生的暂存快照，在成功后移除对应选集，并返回每名学生一份文件，不再打成 ZIP。保存任一种班级输出都会打开一次目标目录选择器，再用防重名文件名把全部逐学生产物写入其中。学生副本仍独立于源批次，并通过同一套班级/学生抽屉流程查看。

由当前配置根目录扫描出的目录行保留参考应用的真实文件夹手势：学生或其下级目录三击新建子目录，四击或更多次重命名所选目录；试题库目录双击新建子目录，三击或更多次重命名。每行目录在鼠标悬停或键盘焦点进入时显示删除操作；确认删除文件系统目录后，会递归移除该物理子树，通过文件系统发现的图片、试卷、班级与名册编辑仍保持只读。每个非隐藏试题库目录只保留一个文件夹节点，即使其中已有图片且没有下级目录，因此完整目录树都可使用这些操作。持久化批次与文件系统批次的元数据都会合并到所属目录行之后，不会增加子节点；同一目录保存多份 PDF 时，该行会直接打开全部图片。试题库文件夹的展开标记固定在行内左侧，名称与图片数量仍保持居中。浏览器只提交最近一次扫描得到的不透明标识；Host 会在写入文件系统前重新校验目标仍位于当前配置根目录内。新增持久化名册班级、学生、学生目录或试题库目录时，Host 会在 Web 修改成功前创建完整物理层级。重命名持久化学生或学生目录时，现有物理目录会一并移动，并更新已保存分发图片的相对路径；持久化试题库目录的重命名与删除也会连同已提交元数据移动其物理图片。

OCR 版面重新合并后，较长的选择会按可配置的 20 页核心组进行语义分割。每个语义子 agent 还会检查两侧各一个相邻所选页；只有推断题头位于核心组内的题目才会渲染，既避免重叠重复，也保留跨页续文。各组依次渲染，任一组超过 Host 解码字节上限时还会继续拆成多个保存分片。首个分片创建一个试卷批次，后续分片全部追加到该批次，因此全部分片会作为同一元数据分组归入目标目录行，同时原始 PDF 字节数与全部裁剪图片的累计字节数都不会形成整份文档上限。

后续模块提供日常备课资源与听课模板、班级名册、与名册匹配的成绩分析，以及模板驱动的教学记录。班主任板块最后五个入口复刻参考工作台的家校沟通、班级记录、谈话记录、排座位和班级总结：家校通知提供八种可编辑校园场景模板、基于事实的微信群初稿、复制和保存复用；三类记录分别持有模板库和可编辑跟进记录；排座位复用或导入一份名册，支持 3–8 排、4–10 列、随机分配和拖拽微调，为每个班级持久化一份座次，并可导出教师视角图片。名册、成绩与排座位名单导入可经共享 OCR Remote 接收图片、PDF、DOCX、PPTX 与 XLSX，解析 MinerU Markdown 或 HTML 表格，合并重复图片分块，并在导入可能覆盖教师填写的表格数据时要求复核。名册行保留识别到的标准列与额外列；成绩行先按学号、再按不重复姓名匹配异步工作开始时锁定的班级名册。待办分类与颜色、备忘录、账本分类与账目、日期事项、课程表条目、教学与班主任数据、班级座次、试卷批次元数据与分发元数据全部通过生成的 `teacherWorkbench` Remote 读写；试题字节使用专用 Host 媒体 Remote。浏览器本地只保留折叠、当前模块、课程表筛选、板块展开、导入复核、当前抽屉、页码面板、编辑器选区、拖拽状态、图片选择状态，以及试题切割队列与进度历史。试题搜索与错题分析仍不在本模块内；课程表整理与题目边界检测是其中由模型支撑的二次处理。

当前学年、教师姓名、学校、默认学科、天气地点、语音识别语言、成绩阈值、PDF 渲染倍率与切题边距属于 `ui-teacher-workbench` dsh 设置命名空间。常规设置行把说明置于全宽的“基础信息”“成绩标准”和“试题切割”分组上方。渲染倍率控制超限 OCR 页面与最终切题图片使用的 PDF.js 栅格，切题边距则以 MinerU 版面单位扩展已接受的题目内容，同时不越过相邻元素。每个班级也可保留自身的学年目录，因此多个年份可跨重载保留，而旧班级会回退到已配置的当前学年。MinerU 端点、后端、混合解析质量、语言、超时、大小限制与结构化版面分批页数属于 DSH 插件设置中的 `dsh-ocr-mineru` 插件行。课程表与题目边界子 agent 使用**设置 → 模型 → 工具模型**；来源、输出、重试与截止时间上限和试题存储限制一起属于 `teacher-workbench` 插件行。天气地点可填写区县或城市；重名时可在逗号后补充上级市或省份，例如 `浦东新区, 上海市`。天气板块的展开视图也可更新地点，经过校验的预报通过 Host 的 `teacherWorkbench/weather` Remote 获取，因此浏览器跨域或隐私策略不会拦截天气服务请求；语音入口会先请求麦克风权限，再启动浏览器 Web Speech API，并把识别文本交给普通待办、备忘录或账目编辑流程。

试题切割模块挂载期间，浏览器会在页面可见时每秒重新扫描已配置的学生根目录和试题库根目录，并在标签页重新获得焦点后立即扫描。目录新建、重命名或删除成功后也会强制执行一次新扫描。结果未变化的扫描不会重新渲染目录树；稳定的文件系统标识会保留已展开行和仍然有效的选择，已删除的目录与图片则会在下一次扫描后消失。扫描结果发生变化后，已打开的图片卡片会重新读取，因此目录操作期间短暂出现的图片缺失结果不会在文件映射恢复后继续显示。

框选擦除只采样选区外侧八像素环带，并使用其中位颜色填充，因此选中的深色文字不会再把浅色纸张背景拉成灰色。

## 后台试题切割

确认 PDF 页码范围后，浏览器保留的文件会加入插件生命周期内的顺序队列，上传入口随即恢复，可继续选择下一份 PDF。中间工作区按上传顺序列出所有已接受文件，显示当前阶段、整数百分比、已保存题数、计时和适用的最终错误。队列每次只执行一份 PDF，避免 PDF.js、OCR、模型与持久化写入相互争用；后续上传会以 0% 和零计时等待，只在轮到并开始处理后计时。

每个已接受任务会在异步工作开始前锁定页码、目标目录、渲染设置和当前父会话。离开试题切割、打开其他工作台板块或切换对话只会移除当前界面的订阅，不会取消后台工作，也不会把已接受任务改投到后续会话。返回试题切割后，中间区域会重新连接同一队列进度。

## 试题裁剪比例

所有语义页组合并后，Host 会返回全部源自 MinerU 的已接受试题区域中的最大宽度，并按各自来源页面归一化。PDF.js 会保留每个区域自己的左、上、下坐标，再把右边界设为左边界加该最大宽度，并在页面右侧截断。它不做横向补白或缩放，因此不同栏目的试题不会合并，而来自相同尺寸页面的试题通常保持同一图片宽度与栅格倍率。

## 扩展点

本包添加一个 `sidebar.primary.section`、一个 `shell.overlay` 条目，并注册一个 `settings.general.item` 设置行；它不声明新的子 slot。

## 模型体验

本包通过 `@deepseek-ai/dsh-tool-teacher-workbench` 的普通对话操作，以及消费提取 Markdown、锁定视图默认值和提供方无关 MinerU 几何信息的 Host 课程表与题目边界子 agent，间接影响模型。

#### KV Cache 影响

普通对话工具 schema 会进入父请求前缀；Host 持有的子 agent 仍使用相互独立的请求缓存。

## 已知限制与延后工作

- **未完成的 PDF 切割只保存在浏览器中**：切换板块与对话会保留插件生命周期内的队列，但完整刷新页面、退出浏览器或关闭应用会丢弃未完成的源文件与进度行；已经提交的题图仍会持久保留。
- **工作台识别文档需要复核**：OCR 与模型重建仍可能产生错误日期、班级、节次、学生、成绩或阅读顺序。不以“班”结尾的课程表班级名称会保持未选中，直至用户修正；未匹配的成绩行会被跳过，原始上传与未接受的复核数据不会存储。
- **可打印成绩图表仍延后实现**：成绩分析已提供持久考试表格、总分、排名、比率、多次考试跟踪与个人成长，但尚不生成基于图表的可打印报告。
- **试题切割仍依赖 OCR 证据**：语义子 agent 不使用固定页面模板即可处理任意编号或无编号、分栏、分页、小问与图形，但无法恢复文本与非文本 OCR 元素全部缺失的题目。Host 遇到编造 id 或未排除且已识别的章节与答案标题时会拒绝保存。
- **天气需要 Host 联网**：已配置的地理编码服务解析地点，当前天气和未来 12 小时预报由 Open-Meteo 提供；任一服务或宿主出站网络不可用时，已保存的工作台数据不受影响。
- **语音能力取决于浏览器**：缺少 Web Speech API 时语音按钮会禁用；麦克风权限、设备缺失、未检测到语音、语言不支持和识别网络故障会显示本地化通知，手动录入仍可使用。
- **节假日数据按年份发布**：日历在已收录年份显示中国法定节假日和调休上班日；尚未收录的年份会明确提示，但阳历、农历和个人事项仍可使用。
