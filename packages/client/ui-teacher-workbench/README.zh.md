## 使用本包

它通过 `sidebar.primary.section` 贡献侧栏首项“工作台”，通过 `shell.overlay` 贡献应用内教学界面，并在“常规设置”中贡献本功能拥有的设置行。 侧栏展开工作台时会先显示八行模块，其余入口保留滚动访问。 overlay 跟随渲染后的侧边栏与详情栏宽度，因此选择已展开的模块后，工作台只替换中间内容区，同时保留应用侧边栏。 界面直接从当前模块开始，不重复显示“工作台”标题栏；每次明确的会话或新会话导航都会退出工作台并显示仍在挂载的对话，包括再次选择当前会话。 每次打开界面都会重新读取 Host 权威文档，使普通对话工具产生的修改替换浏览器缓存的旧快照。

界面首先提供“日常管理”。模块标题右侧的摘要以右对齐方式显示当前时间、日期、天气地点与实时天气，点击后可查看完整时间信息和未来 12 小时预报。今日待办、重要事项和紧急事项分别占用等宽独立卡片；备忘录、账本与日历组成第二行三张卡片。账本卡片会打开占满板块的视图，其中分类可新增或删除；每个分类都可手动或通过语音填写说明、填写人民币金额并设置必填的本地日期与时间，已有账目也可编辑。在哪张待办卡片中新增，事项就只属于该分类；编辑会保留该分类且不提供分类控件。重要事项和紧急事项行提供十色圆点选择器，今日待办行不显示颜色圆点。展开日历结合阳历、农历、法定节假日和日期事项，还可经共享 OCR Remote 导入图片、PDF、DOCX、PPTX 和 XLSX 校历，将识别到的日期与活动投影为可编辑复核列表，并在一次带修订号写入中只持久化已选行。HTML 表格投影会处理跨行和跨列单元格，使负责人及部门信息与带日期事项保持分离。待办的时间图标会打开同一个截止时间与提醒编辑器：设置未来截止时间后，可选择一次性提前提醒或重复频率，再从可选的 dsh-im 列表中指定一个平台和一个机器人。两种提醒都可手动输入数值，并在其后选择分钟、小时或天；编辑期间的空值或超限值会禁用保存，但不会替换尚在输入的文本。备忘录编辑器会显示同一组配置；每个账本分类的新增区都有提醒按钮，已有账目也会在编辑弹窗中保留这些控件。两者的提醒截止时间独立于备忘录修改时间和账目发生时间。已经过去的截止时间会禁用提醒开关并显示行内说明，但不会阻止保存普通修改。截止时间不足 30 分钟时，开启提醒会选择仍处于未来的最大整分钟提前量。日历议程行提供独立提醒按钮并复用相同控件；不启用提醒时仍保持普通记录且不会发送通知。

课程表模块可切换今日课表、本周课表、年级课表和早晚自习。本周课表、年级课表和早晚自习将每行的时间段去重后显示在节次下方；悬停课程可查看该课程的准确时间。今日课表与本周课表可以选择一个班级，也可以按 dsh 设置中的教师姓名筛选全部持久化课程；个人视图会在每节课中保留班级名称。今日课表、本周课表和早晚自习共用普通课表班级目录，年级课表则持有独立班级目录，并只投影所选年级。年级课表中识别或新建的班级因此不会出现在今日课表、本周课表、早晚自习、班级名册、成绩分析或试题切割中；名册班级也不会出现在课程表控件中。每个可编辑视图都用纯图标入口新建班级。本周课表和早晚自习用纯图标入口删除所选普通班级，年级课表则为每个班级行提供纯图标删除操作；每个图标都保留无障碍名称和悬停提示。确认提示会说明删除班级及其全部课程安排，成功删除当前班级后，选择器会切换到下一个可用班级。新建课表班级只需填写名称和年级。工具栏不再提供新增课程入口；点击本周课表、年级课表或早晚自习的空白格会直接打开课程编辑器，并填入该格对应的班级、星期、节次及适用的自习类型。本周课表、年级课表和早晚自习可接收图片、PDF、DOCX、PPTX 和 XLSX。每次上传都由独立的工具模型子代理理解。MinerU 为 PDF 和 Office 文件提供文本与表格；图片提取包含增强全图，以及在规则网格可用时保留表头的细节区域。支持图片的模型可通过专用工具按需查看原图和放大视图，以核对提取文本；图片提取失败时，这类模型仍可直接使用这些视图。子代理会收到所选目标和条目必需字段，自行理解文档版式，按有界页面读取完整来源，再分批提交经过校验的课程条目供复核。每次导入都会创建并释放自己的隐藏父任务和子代理，因此不需要当前聊天会话。右上角图标只隐藏识别窗口；关闭窗口或切换模块后，浏览器插件会继续处理。课程表的每个视图都可查看进度或结果，完成后不会自动打开已隐藏的窗口。修改后的条目会保留至导入或主动清除，导入失败也可继续复核重试。同一时间只接受一个待处理任务或复核结果；刷新或关闭浏览器会清除这些临时状态。异步工作前会锁定导入目标、班级目录、年级与默认值，因此识别期间切换视图不会改变结果去向。浏览器仍会要求在一次批量写入前复核班级、年级、类型、星期、节次、时间、课程、教师和地点。选中行需要班级名称，以及课程或自习负责教师；班级名称不要求固定后缀。接受的识别结果会替换已经占用的班级、类型、星期和节次组合，而不会产生相互矛盾的安排。

试题切割模块保留参考应用的顶部栏、当前年份/班级层级、叠层抽屉与操作流程，移除其中的错题分析、图片搜索工作区和重复设置按钮。顶部栏只显示模块标题与操作，不显示居中的试卷名称框。班级层级只读取名册目录，因此普通课表与年级课表班级不会出现在这里。界面使用 DSH 设计令牌，因此背景、文字、边框、控件、遮罩与强调色会跟随当前浅色或深色外观，不再固定使用独立应用的黑橙配色。双击班级会从工作区最左侧打开学生抽屉；在学生抽屉中，单击打开图片，双击展开或收起下级目录，三击新建持久化子目录。选择学生会显示该学生根目录与所有子目录内的全部已分发试题。选择学生目录会显示该目录直属图片及所有下级目录中的图片；全选与临时保存使用同一子树，不包含同级目录或其他学生的图片。学生与目录名称在两侧固定行操作之间保持居中。再次选择同一学生或目录会收起图片抽屉。学生图片与试题库互斥：打开任一方都会先收起另一方再显示自己的抽屉。试题库目录树只投影物理目录，文件夹名最多显示前 7 个 Unicode 字符，悬停时显示完整名称；配置根目录中存在直接图片时，会用一个“试题图片库根目录”行表示该物理目录。试卷批次名不会成为目录树节点；选择目录行会打开该目录中全部持久化批次与文件系统批次的直接图片，独立的展开箭头则用于展开下级目录。叶子文件夹不显示展开占位点，只有含下级内容的文件夹显示展开箭头。标题栏用于新建根文件夹；单击文件夹会打开其中的直接图片，没有这类图片时则展开或收起目录，双击新建子目录，三击重命名，行内删除操作会递归移除该目录层级、其中的试卷批次及相关学生副本。再次选择已打开的目录会收起图片抽屉。关闭班级抽屉时也会先收起其图片抽屉。选择 PDF 后会打开原式页码选择顶层面板，其中的保存目录控件默认不选择目录，并且只列出现有叶子路径；页码留空表示全部页，并支持 `1-5,8` 这类逗号分隔的单页与区间。浏览器会读取所选 OCR 提供方的当前限制，只把选中的源页面复制成有界 PDF 批次；批次超限时自动二分，只有单个复制页仍无法装入时才会栅格化。无论原始 PDF 有多少字节，它都只保留在浏览器中。每个批次调用共享 `ocr.layout` Remote 获取 MinerU 页面几何信息，随后模块再以已配置的工具模型和内置语义 skill 启动一次短生命周期题目边界 agent loop。子 agent 分块读取与提供方无关的 OCR 元素，先归纳当前 PDF 的题目起点模式，再按不透明元素 id 提交顶层题头、错序续文与图形，以及需要排除的标题，接受后才返回令牌。编号可以使用任意语法，可以重启、重复、随章节变化，也可以完全不存在。Host 会拒绝不匹配或编造的 id、未排除且已识别的章节与答案标题和空裁剪；它会按可信 OCR 顺序归一化有效题头，并分配唯一的来源顺序显示序号，把已接受 id 映射回可信二维坐标，并用邻近内容限制留白。PDF.js 随后从浏览器保留的原 PDF 栅格化，只在一道题真实跨页时纵向拼接多个区域。未选择目录时，Host 会在根目录下创建或复用以 PDF 命名的真实物理目录，并把每张裁剪图片作为直接文件保存到其中；明确选择叶子目录时，图片则直接保存到该叶子目录。试卷批次 id 不会创建存储目录，批次元数据只负责分组、续传与删除。持久图片库支持选择、预览、框选擦除、旋转、另存为、覆盖保存和删除。从顶部栏打开试题库时，所选图片会用防重名文件名保存到浏览器选定的本地目录；从学生或嵌套目录打开时，所选图片则直接分发到该目标。在学生图片抽屉中，“临时保存”会把勾选图片加入该学生跨目录累积的暂存选集。同一张图片再次保存会更新其快照，不同图片即使同名也会各自保留。显示的总数包含所有已暂存目录，“清空暂存”只移除该学生的暂存副本。学生暂存和技能库生成不设固定图片数量上限，已有图片大小检查仍然有效。每张图片卡片仍显示累计保存次数与最近保存时间。“技能库”的 Word 与 PowerPoint 入口会先打开参考系统的目录选择器，对其中图片进行自然排序，生成一份以目录命名的产物，并显示保存或重试。班级抽屉保留独立的 Word 与 PowerPoint 操作，并仅在至少一名学生有临时图片时启用：Word 打开带批量控制的逐学生标题、姓名、日期配置，PowerPoint 直接开始生成；两者都只读取各学生的暂存快照，在成功后移除对应选集，并返回每名学生一份文件，不再打成 ZIP。保存生成的 Office 文件时，会通过已组合的原生或应用内目录选择器，选择运行 DSH 的电脑上的现有目录，再通过已认证的 Host 服务逐个写入。应用内选择器会明确标注该电脑。目录空白字符原样保留，同名文件自动添加序号，成功后显示所选目录。选择目录和写入期间，保存与关闭按钮保持禁用。取消或写入失败会保留生成文件；部分失败时仅保留未成功文件供重试。未组合 Host 选择器的配置使用浏览器文件或目录选择器，失败时显示原因，不回退到下载。浏览器写入失败会中止写入流。进度分别显示暂存、生成文档、选择目标位置和写入文件；暂存或生成请求被拒绝时会解除控件禁用，并保留选图或请求供重试。学生副本仍独立于源批次，并通过同一套班级/学生抽屉流程查看。

当原始 PDF 自身超过 OCR 提供方的文件上限时，不再走有界复制路径。PDF.js 会通过临时 Blob URL 打开浏览器 `File`，逐页把所选页面栅格化到该上限以内，因此数百页源文件不会先被整体复制成一个 JavaScript `ArrayBuffer`。提取或切割阶段结束时会显式释放 Blob URL、PDF.js 文档、页面对象和画布。

由当前配置根目录扫描出的目录行保留参考应用的真实文件夹手势：学生或其下级目录三击新建子目录，四击或更多次重命名所选目录；试题库目录双击新建子目录，三击或更多次重命名。每行目录在鼠标悬停或键盘焦点进入时显示删除操作。当前根目录扫描返回的每个班级、学生、目录、试卷与图片都会显示适用的新建、重命名、删除、编辑、分发和临时保存操作，不再根据来源进入只读模式。每个非隐藏试题库目录只保留一个文件夹节点，即使其中已有图片且没有下级目录，因此完整目录树都可使用这些操作。批次元数据会合并到所属目录行之后，不会增加子节点；同一目录保存多份 PDF 时，该行会直接打开全部图片。试题库文件夹的展开标记固定在行内左侧，名称与图片数量仍保持居中。浏览器只提交最近一次扫描得到的不透明标识；Host 会在写入文件系统前重新校验目标仍位于当前配置根目录内。新增具有元数据的名册班级、学生、学生目录或试题库目录时，Host 会在 Web 修改成功前创建完整物理层级。重命名具有元数据的学生或学生目录时，现有物理目录会一并移动，并更新已保存分发图片的相对路径；具有元数据的试题库目录重命名会移动物理子树；删除则会以可回滚方式摘除子树，并删除其中批次及相关学生副本。

OCR 版面重新合并后，较长的选择会按可配置的 4 页核心组进行语义分割。每个语义子 agent 还会检查两侧各一个相邻所选页；只有推断题头位于核心组内的题目才会渲染，既避免重叠重复，也保留跨页续文。题界阶段只发送有界 OCR 证据，不再为全部页面长期保留 Base64 预览。可恢复的题界失败不再取消其他分组：失败组会以没有初步题目的状态进入整页视觉复核，在其中重新建立有效题界，仍无法确认时则显示未确认并跳过该组。随后由一个可复用 PDF.js 读取器在 Host 公布的并发上限内复核独立分组，而最终渲染、编号与追加保存仍按来源顺序串行执行。同时最多只有该上限数量的分组分配检查预览和复核题图；分组完成复核并等待前序分组时，这些载荷即可被回收，轮到来源顺序中的位置后再渲染最终题图并立即持久追加。任一组超过 Host 解码字节上限时还会继续拆成多个保存分片。首个非空分片创建一个试卷批次，后续分片全部追加到该批次，因此全部分片会作为同一元数据分组归入目标目录行，同时原始 PDF 字节数与全部裁剪图片的累计字节数都不会形成整份文档上限。

后续模块提供日常备课资源与听课模板、班级名册、与名册匹配的成绩分析，以及模板驱动的教学记录。班主任板块最后五个入口复刻参考工作台的家校沟通、班级记录、谈话记录、排座位和班级总结：家校通知提供八种可编辑校园场景模板、基于事实的微信群初稿、复制和保存复用；三类记录分别持有模板库和可编辑跟进记录；排座位复用或导入一份名册，支持 3–8 排、4–10 列、随机分配和拖拽微调，为每个班级持久化一份座次，并可导出教师视角图片。名册、成绩与排座位名单导入可经共享 OCR Remote 接收图片、PDF、DOCX、PPTX 与 XLSX，解析 MinerU Markdown 或 HTML 表格，合并重复图片分块，并在导入可能覆盖教师填写的表格数据时要求复核。名册行保留识别到的标准列与额外列；成绩行先按学号、再按不重复姓名匹配异步工作开始时锁定的班级名册。待办分类与颜色、备忘录、账本分类与账目、日期事项、课程表条目、教学与班主任数据、班级座次、试卷批次元数据与分发元数据全部通过生成的 `teacherWorkbench` Remote 读写；试题字节使用专用 Host 媒体 Remote。浏览器本地只保留折叠、当前模块、课程表筛选、板块展开、导入复核、当前抽屉、页码面板、编辑器选区、拖拽状态、图片选择状态，以及试题切割队列与进度历史。试题切割不搜索自身的图片库或分析错题；课程表整理与题目边界检测是其中由模型支撑的二次处理。

当前学年、教师姓名、学校、默认学科、天气地点、成绩阈值、PDF 渲染倍率与切题边距属于 `ui-teacher-workbench` dsh 设置命名空间。常规设置行把说明置于全宽的“基础信息”“成绩标准”和“试题切割”分组上方。渲染倍率控制超限 OCR 页面与最终切题图片使用的 PDF.js 栅格，切题边距则以 MinerU 版面单位扩展已接受的题目内容，同时不越过相邻元素。每个班级也可保留自身的学年目录，因此多个年份可跨重载保留，而旧班级会回退到已配置的当前学年。MinerU 端点、后端、混合解析质量、语言、超时、大小限制与结构化版面分批页数属于 DSH 插件设置中的 `dsh-ocr-mineru` 插件行。课程表、题目边界与典例校对子 agent 使用**设置 → 模型 → 工具模型**。默认关闭的切题思考开关位于**设置 → 插件 → 插件配置 → 文档提取**；来源、输出、重试、截止时间与存储限制属于同一 `teacher-workbench` 插件行。天气地点可填写区县或城市；重名时可在逗号后补充上级市或省份，例如 `浦东新区, 上海市`。天气板块的展开视图也可更新地点，经过校验的预报通过 Host 的 `teacherWorkbench/weather` Remote 获取，因此浏览器跨域或隐私策略不会拦截天气服务请求；语音入口通过 `MediaRecorder` 录制一份 Blob，发送到 Host speech Remote，再把配置所得文本交给普通待办、备忘录或账目编辑流程。供应商接入与凭据位于**设置 → 模型 → 服务接入**，语音模型则在**使用场景**中只分配一次，供工作台、对话与 QQ Consumer 共用。

工作台语音命令使用共享录音器；Web Audio 解码可用时，它会在调用 Host 前把 Chromium WebM 等受支持的浏览器容器转换为 16 kHz 单声道 PCM WAV。录音器也会采样这份 Web Audio 输入：中性的麦克风图案会闪烁并按当前音量向上填充，连续三秒没有有效声音则结束录音并开始识别。QQ 消息本来就把 WAV 发送给同一个已配置 ASR 服务，因此浏览器链路不再依赖该本地服务也支持 WebM。没有 AudioContext 解码器的宿主会保留原始 MediaRecorder blob，并需要手动结束录音。

试题切割模块挂载期间，浏览器会在页面可见时每秒重新扫描已配置的学生根目录和试题库根目录，并在标签页重新获得焦点后立即扫描。目录新建、重命名、删除、图片替换或分发成功后也会强制执行一次新扫描。结果未变化的扫描不会重新渲染目录树；稳定的文件系统标识会保留已展开行和仍然有效的选择，已删除的目录与图片则会在下一次扫描后消失。每次扫描只显示当前根目录下实际存在的物理目录，即使持久化记录仍指向先前根目录也不例外。每张可见图片都能编辑、删除、在适用时分发，并加入临时 Office 生成。扫描结果发生变化后，已打开的图片卡片会重新读取，因此文件系统操作期间短暂出现的图片缺失结果不会在文件映射恢复后继续显示。

框选擦除只采样选区外侧八像素环带，并使用其中位颜色填充，因此选中的深色文字不会再把浅色纸张背景拉成灰色。

### 典例收集

展开后的 Word 窗口使用 Tiptap 编辑文字和段落，用本地内嵌字体的 MathLive 公式编辑器输入数学公式。公式菜单跟随工作台语言。“大括号方程组”插入共用左大括号的两行公式，按 Tab 切换到下一个占位符。预览和导出 Word 中的大括号均随方程组高度伸展。输入选区和正在编辑的结构使用工作台主题的柔和高亮，即使系统采用不同的深浅色偏好也保持一致。输入框下方常驻高中数学符号面板，按字母、运算、集合关系、几何向量、函数与计数、罗马数字分类，提供小写 i–viii。集合关系提供斜线版本的小于等于和大于等于（⩽/⩾）、左右方向的真子集（⫋/⫌）和子集（⊆/⊇）、采用专用符号 ∁、可填写全集与集合的非花体补集模板，以及任意、存在和不存在（∀/∃/∄）。几何面板提供斜线形式的不平行（⫽⃥）、圆（⊙）和平行四边形（▱）；补集、真子集及斜线平行符号采用由 STIX Two Math 派生的内嵌字形子集；左右真子集缩小并上移，使下方双横线贴近字母基线；补集符号保持直立，表示全集的下标与集合名称使用数学斜体。应用、保存、重新打开及导出 Word 均保留这些字形与字母样式。中文输入法确认输入时保留选中位置的公式结构，字号与样式和直接键入一致。几何面板用紧凑双斜线符号（⫽）表示平行，重新编辑公式和导出 Word 后保持相同比例。函数面板提供一阶与二阶导数模板，可填写括号中的自变量。罗马数字使用正体文字。其下方的常用帽子一行提供帽号、宽帽号、横线、长横线、波浪号、向量箭头及单点、双点；可包裹选中字母，也可先插入再替换选中的字母。字体样式菜单使用文字标签，加粗保留数学斜体和当前字体类别。公式颜色随 Word 保存、重新打开、再次编辑及导出，结构符号同样保留颜色。MathLive 对单个字母或整条公式设置的粗斜体在应用、保存及重新打开时均有效；已保存的旧版加粗分组保留其内容。点击在当前选区插入，结构模板提供可填写的占位符。菜单不显示剪切、复制、粘贴和全选，键盘快捷键仍可使用。Word 预览和符号面板使用本地内嵌 TeX 字体与排版，保持根号比例一致，并保留 MathML 供辅助技术读取。每张预览卡片将导入的 Word 样式限定在自身文档中，排除已渲染的公式，保留公式字体、分数间距和根号线条。公式加粗立即显示，保存、重新打开及从搜索结果导出后仍会保留。选中的关系与几何符号加粗时保留原有字形，包括没有独立粗体字体的符号；相邻未选中的符号保持原有字重。应用公式后立即显示；不支持的公式会保留当前公式内容。工具栏支持字体、字号、加粗、斜体、下划线、对齐、行距、缩进、撤销和重做。字号菜单先按初号到八号列出中文名称，不显示磅值，再列出其他数字字号。字体框根据选中的中文、西文或公式显示对应字体；选区包含不同字体时显示“混合字体”。中文字符直接使用保存的中文字体，西文保留独立字体，打开文档即与字体框一致，无需重新选择；富文本复制保留独立的 Word 中西文字体名称，不把浏览器替代字体列表写入文档。保存状态显示在工具栏“保存”按钮左侧。保存及 Ctrl/Cmd+S 提交结构化段落；关闭未保存的编辑时，较大的提示文字下方排列“继续”“放弃”“保存并关闭”三个按钮，按钮组右边缘与提示文字对齐。已保存文档可从预览卡片下载。从搜索结果勾选导出使用最近一次保存的 Word；尚未保存的编辑不会进入导出。Host 依据原件标识与 Word 修订号拒绝过期保存，编辑后的段落保留用户格式，后续预览、下载及两种合并导出不会重置它。未改动的原生公式和图片保留原始 XML 或媒体；修改的公式转换为原生 Office 公式并同步预览 MathML。自动校对仍不得改写题目，手动编辑不调用模型。

打开**工作台 → 典例收集**，点击目录列表下方的**添加新题**。目录默认使用数字名称，单击展开，双击或按 F2 重命名，并可通过右键或更多菜单重命名、删除。内容区从原件与 Word 预览开始。将图片/PDF 上传或拖入左上区域；MinerU 提取文本后，独立的工具模型子 agent 会对照原件校对，再生成右上 Word 预览及可下载的 DOCX。下一排左侧上传解析图片/PDF，右侧显示生成的解析 Word，下方依次为标签和描述。两组区域分别支持上传、预览、下载和识别；新目录的两组区域均为空。**AI 校对**会使用新提取的 OCR 文本与原件重新检查已有 Word。子 agent 只修复转写错误，不改写原题或解析。随后由独立子 agent 识别并删除开头的题号、教材或试卷来源及变式标记，保留剩余正文，无法确定的文字也会保留。已有 Word 在首次预览、下载或导出时执行该识别，完成后复用结果。切换模块或目录时识别会继续，且无需打开对话；失败会保留原件及已有 Word 供重试。请选择支持图片输入的工具模型，并遵循 [Host 校对限制](../../host/teacher-workbench/README.zh.md#example-collection)。

同一道题或解析可多选、拖入多个图片/PDF。在上传窗口中按从上到下的阅读顺序移动文件、移除不需要的文件或继续添加，再点击**上传并转换**。PDF 内部保留页码顺序。整组文件保存为连续的 PDF 原件，并一起校对生成一个 Word。Word 卡片标题栏提供 AI 校对和放大操作。更换文件、AI 校对、下载和打开题目使用与搜索相同的圆角背景按钮样式。四个原件/Word 卡片均提供放大按钮，打开可滚动的大窗口预览；按 Escape 或关闭按钮返回卡片。下载使用同一份已保存内容。PDF 原件在卡片和大窗口中都按阅读顺序显示逐页渲染的图片。加载失败时可重新载入，已保存的 PDF 仍可下载。

标签区通过点击预设名称切换选择，已选行显示勾选图标。悬停或聚焦预设行时，右侧显示独立的删除按钮；触屏设备始终显示该按钮。删除预设会将它从共用下拉列表移除，已经标在题目上的标签仍然保留。编辑区和搜索结果中的已选标签按名称使用固定颜色。悬停或聚焦编辑区标签时，其右上角显示取消按钮；触屏设备始终显示该按钮。取消标签只修改当前题目，共用预设仍然保留。保存选择时下拉框保持展开并保留焦点；点击外部区域、通过键盘离开或按 Escape 可收起。**添加标签**保存所有题目共用的预设，不会自动选中；切换选项行只保存当前题目的选择。描述区在停止编辑 500 毫秒、失去焦点或切换题目时保存键入和语音转写的文字，并只读展示已存笔迹。顶部状态仅在保存中或存在未保存草稿时显示；保存失败后点击**重试**会重新提交保留的草稿，存在待保存草稿时会触发浏览器的离页确认。搜索按空格分隔的每个关键词匹配已保存标签或文字描述，从右侧滑出的抽屉展示每条结果的真实 Word 预览、标签、描述及已保存笔迹。手写笔迹按原样保存，不转写为可搜索的文字。

聚焦描述框或搜索框，长按空格 500 毫秒开始录音，松开结束。短按会在选区插入一个空格，输入法选词和带修饰键的快捷键保持原生行为。每个输入框与对应的麦克风按钮共用录音器，并使用模型设置中选定的语音模型。描述转写追加到当前草稿并自动保存。搜索框旁的麦克风会用转写文字替换查询，检查后点击**搜索**。焦点移走或页面隐藏会结束正在进行的长按录音。

在搜索抽屉左侧勾选题目，点击右上角的**导出 Word**，选择题目后紧跟解析，或全部题目在前、解析集中在后。导出按结果顺序仅合并题目与解析原文，不添加标题、编号、标签或描述，题目之间留两行空白。题目生成 Word 后方可勾选；未上传的解析会省略，已上传但尚未生成 Word 的解析须先完成识别。导出失败时保留选择和排列方式供重试。

[Host 参考](../../host/teacher-workbench/README.zh.md#example-collection) 定义 SQLite 存储、上传限制、OCR 失败及原生公式转换。题目、解析和搜索 Word 预览显示 DOCX 内嵌插图并按面板宽度缩放，保留下载文件的数学强调格式和字号，正文使用本地替代字体。选项编号紧邻内容，选项按列对齐，面板过窄时整项换行。正文使用 1.25 倍行距，插图居中放在对应题目或解析的选项之后。下载 DOCX 后可使用 Word 公式编辑器修改公式；Web 区域提供预览。文件读取失败时可点击重试；已有插图占位符会按需从已存原件补齐。不支持的 TeX 和 Markdown 表格保留为文本。

### 后台试题切割

PDF 页码选择面板把持久化且默认关闭的切题思考开关放在保存目录控件下方。关闭后会严格禁用思考；没有公布 Off 档的推理模型不能执行切题。确认 PDF 页码范围时会锁定该 PDF 的思考选择，把浏览器保留的文件加入插件生命周期内的顺序队列，并随即恢复上传入口以继续选择下一份 PDF。因此队列中的 PDF 可以分别开启或关闭思考，后续上传修改持久化默认值也不会影响已接受任务的题界识别、视觉复核或修复阶段。中间工作区按上传顺序列出所有已接受文件，显示入队时锁定的页码范围、当前阶段、整数百分比、已保存题数、计时和适用的最终错误。视觉缺陷只修复被点名的题目标识；经过三次局部题图修订仍未解决时，该题保留最近一次通过 Host 校验的裁切结果，在已完成任务中计入警告数量，并且不阻止后续分组或队列中的 PDF。只要初步题界已经产生，预览准备失败、复核超时、供应商或模型错误、复核调用抛错及无效复核输出也采用同一兜底，不再使整份 PDF 失败：已有完整缺陷时只把被点名题目标为未复核，否则把当前复核范围内的全部题目标为未复核。队列每次只执行一份 PDF，避免 PDF.js、OCR、模型与持久化写入相互争用；后续上传会以 0% 和零计时等待，只在轮到并开始处理后计时。

每个已接受任务会在异步工作开始前锁定页码、目标目录、渲染设置和思考选择。Host 拥有私有处理会话，因此切题不要求打开一个对话。离开试题切割、打开其他工作台板块或切换对话只会移除当前界面的订阅，不会取消后台工作，也不会改变已接受任务的设置。返回试题切割后，中间区域会重新连接同一队列进度。刷新或关闭浏览器仍会结束这份内存队列。

处理大文件时，提取阶段通过一个临时 PDF.js 读取器流式处理所选页面，分割阶段只保留 OCR 几何信息；随后由另一个可复用读取器在 Host 公布的上限内同时复核多个独立语义组，而最终渲染与持久化仍按来源顺序执行。进度行会显示已持久完成的组数；每个非空组都会在全部前序组完成后追加保存，分组完成复核并等待轮次时，其预览和复核题图载荷即可被回收。这样浏览器图片内存被限制在配置的复核窗口内，先前已经保存的组会保留，当前组视觉复核失败时也会带未复核警告保存其安全裁切。可恢复的初步题界失败只隔离当前页面组，并额外执行一次整页恢复复核；若仍无法确认，则带分组警告跳过这些页面并继续后续组。OCR 失败、无效或不可用的模型配置、最终题图渲染失败及持久化写入失败仍会终止任务，因为隔离单个语义组无法修正这些问题。

### 试题裁剪比例

同尺寸所选页会提供重复的题头栏起点。后续栏为空时，前一区域会在下一栏起点停止；已识别的归属内容跨过该起点时仍保留完整来源范围，因此半空双栏拼版不会把所有输出画布都撑到整张拼版宽度。

所有语义页组合并后，Host 会返回全部源自 MinerU 的已接受试题区域中的最大宽度，并按各自来源页面归一化。每个区域还会携带一项来源右界，它由纵向重叠且属于其他试题的右侧内容推导。PDF.js 保留区域自己的左、上、下坐标，从该左边界最多采样一份最大宽度，同时不越过来源右界。输出画布仍使用最大宽度，无法取得来源像素的右侧区域以白色补齐，因此不同栏目不会相互串入，而相同尺寸页面仍保持同一图片宽度与栅格倍率。

## 模型体验

本包通过 `@deepseek-ai/dsh-tool-teacher-workbench` 的普通对话操作，以及 Host 自有的课程表、题目边界与典例校对子 agent，间接影响模型。这些子 agent 接收其任务所需的来源文本、图片或几何信息，独立于用户对话历史。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- **未完成的 PDF 切割只保存在浏览器中**：切换板块与对话会保留插件生命周期内的队列，但完整刷新页面、退出浏览器或关闭应用会丢弃未完成的源文件与进度行；已经提交的题图仍会持久保留。
- **工作台识别文档需要复核**：OCR 与模型重建仍可能产生错误日期、班级、节次、学生、成绩或阅读顺序。缺少班级名称的课程表行会保持未选中，直至用户修正；未匹配的成绩行会被跳过，原始上传与未接受的复核数据不会存储。
- **可打印成绩图表仍延后实现**：成绩分析已提供持久考试表格、总分、排名、比率、多次考试跟踪与个人成长，但尚不生成基于图表的可打印报告。
- **试题切割仍依赖 OCR 证据**：语义子 agent 不使用固定页面模板即可处理任意编号或无编号、分栏、分页、小问与图形，但无法恢复文本与非文本 OCR 元素全部缺失的题目。Host 遇到编造 id 或未排除且已识别的章节与答案标题时会拒绝保存。
- **天气需要 Host 联网**：已配置的地理编码服务解析地点，当前天气和未来 12 小时预报由 Open-Meteo 提供；任一服务或宿主出站网络不可用时，已保存的工作台数据不受影响。
- **语音采集与 ASR 是两项独立依赖**：缺少 `MediaRecorder` 或麦克风采集时按钮会禁用，自动静音收尾与音量填充需要 Web Audio，转写还要求已配置供应商线路并分配受支持的语音模型；本地化通知区分权限拒绝、找不到麦克风、设备启动失败、不支持录音要求、空音频、配置、大小和提供方故障。采集使用浏览器所在电脑的输入设备，并受浏览器及系统权限控制；手动停止和手动录入仍可使用。
- **节假日数据按年份发布**：日历在已收录年份显示中国法定节假日和调休上班日；尚未收录的年份会明确提示，但阳历、农历和个人事项仍可使用。
