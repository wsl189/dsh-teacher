# Agent Note: 论文原件与自动预览

Status: implemented

[English](2026-10-05-paper-collection.md) | 中文

## 问题

典例收集负责题目与解析的 OCR 和可编辑的生成 Word 文档。研究论文需要上传 PDF、图片、Word 和 CAJ 原件，并保留目录序号、标签和描述，无需手动转换即可阅读。

## 决策

论文收集拥有独立的版本化存储域和只含元数据的目录。一个来源修订中的原始字节保持不变。PDF、图片和普通 DOCX 从原件渲染；DOC、CAJ 以及含 TIFF、EMF、WMF 或 EPS 图片的 DOCX 生成单独缓存的 PDF 预览，以保留浏览器图片解码器无法显示的 Word 插图。预览在元数据队列之外运行，同一来源的并发请求共享一次转换，提交前检查不可变来源标识。删除或替换来源后，旧转换不能恢复文件。集合在关闭存储前取消并等待转换结束。

Windows x64 桌面包准备一个经校验和固定的独立 CAJ 命令及原生解码器。用户设置保留完整 argv 命令，显式包含输入与输出占位符、时限和字节上限。转换不经过 Shell，在私有临时目录中运行，不调用模型或 OCR 提供者。

## 考虑过的替代方案

**扩展典例 OCR。** 这会将论文原件耦合到生成的可编辑题目文档，并引入论文阅读不需要的识别工作。

**启动外部阅读器。** 这会增加手动阅读步骤，阅读区域也不能与已保存的标签和描述放在一起。

**使用转换 PDF 替换原件。** 这会丢失来源并掩盖兼容性失败。独立集合保留原件下载，并在预览区域报告失败。

## 影响

CAJ 兼容性仍受所选转换器限制。预览失败后已上传原件仍可使用，也可重试。非 Windows 部署单独配置转换器。来源文件和生成预览通过有界完整 base64 载荷传输；没有流式传输或自动缓存淘汰。

## 验证

SQLite 集合测试覆盖重新打开、原件字节一致性、共享 Word/CAJ 预览、并发元数据编辑、拒绝旧来源写入、上传拒绝和取消结束。完整 Web 组合场景覆盖侧栏顺序、自定义序号、标签、描述、PDF/图片/DOCX 预览、原件下载、重载持久化、搜索快照以及自动 CAJ 预览传输。打包运行时验证使用一份 15 页研究 PDF、一张论文页面图片、一份含四张 TIFF 插图、五个公式和一张表格的 Word 稿件，以及一份 110 页 CAJ 学位论文；所有原件下载均保持字节一致。
