# Agent Note: Agent 判定的题外边界

Status: implemented

[English](2026-09-03-agent-classified-outside-question-boundaries.md) | 中文

> 本决策部分取代 [Agent 自主发现题界](2026-09-03-agent-owned-question-boundary-discovery.zh.md)中的受保护候选降级规则；其中的完整来源发现、不透明 OCR id、必需工具调用与 Host 几何所有权仍然有效。

## 问题

边界 Agent 可以识别出后一套试卷的标题、试卷前言、带编号总结或答案块不是学习者题目，但提交协议无法保留这项完整语义判断。`nonQuestionHeadElementIds` 只表示元素不是顶层题头，并且刻意允许它继续作为题目内容。除非 Agent 另外提供单题停止位置或像素排除项，否则按来源顺序自动归属时可能把题外块附加到前一套试卷的末题。通用作答要求模式还可能把带编号总结标为受保护项，阻止 Agent 在检查完整来源后排除它。

## 决策

边界草稿与完整分组修复草稿接受 `outsideBoundaryElementIds`。每个 id 指向文档级标题、后续试卷前言、总结、答案或其他不属于任何题目的内容块中的首个语义 OCR 元素。Host 不会把该标记放入裁剪，并把它作为跨页面栏位生效的来源顺序归属停止位置。只有后续已提交题头才会重新开始自动归属，因此不需要 Agent 枚举每一行，夹在中间的前言和总结元素也会保持无归属。

协议继续区分 `nonQuestionHeadElementIds`。保留的非题头仍可能是小问、续文或题目内的其他内容；题外边界则表示后续内容块不能属于前一道题。当可能题头候选被提交为题目、保留非题头、题外边界或经检查的像素排除项时，它就获得一项显式分类。

受保护作答要求候选继续作为强回忆提示与确定性降级输入，但不再成为凌驾于已接受完整来源草稿之上的语义权威。Host 仍会拒绝仅被归类为保留非题头的受保护候选。只有把同一 id 提交为题外边界，Agent 才能覆盖该提示；这记录了更强的主张，即完整来源证明此处开始的是非题目内容块。没有 Agent 草稿被接受时，现有降级仍会在视觉复核前保留受保护候选。

Host 会校验每个题外边界都是唯一且已经检查的语义 OCR 元素，并且不与题头或显式像素排除项冲突。题外边界是全局文档内容块停止位置；`stopBeforeElementId` 继续作为单题例外。Agent 仍返回来源 id 而不是坐标，Host 继续推导并校验裁剪几何。

## 考虑过的替代方案

**扩充文档标题与总结模式。** 增加模式只能覆盖已知出版社和措辞，既无法表达 Agent 对完整来源的判断，也会继续给带编号总结施加同样的误判压力。

**把每个保留非题头都当作归属停止位置。** 选项、小问、引用和续文即使不是顶层题头，也经常是有效题目内容。复用 `nonQuestionHeadElementIds` 会抹掉这一区别。

**移除受保护候选证据。** 这些证据仍能防止意外的假阴性分类，并在 Agent 失败后提供有用的降级输出。显式题外分类允许完整来源语义受控覆盖提示，而无需丢弃降级能力。

**要求每道题返回原始坐标或结束 id。** 原始坐标会把权威从 MinerU 转移出去，而强制局部结束位置会让每道前置题重复同一项文档内容块决策。一个题外标记可以直接记录这次语义转换。

## 后果

- 合订试卷的标题、说明与总结可以同时保持在前一套试卷末题和后一套试卷首题之外。
- Agent 必须区分保留非题头内容与不属于任何题目的内容块；把全局题外边界用于栏内局部续文可能截断有效归属，因此仍需视觉复核。
- 受保护候选模式不再强迫已接受 Agent 草稿把带编号总结当作题目，但在 Agent 没有记录显式题外分类时仍保持保守。
- 边界与修复工具 schema、提示词、包文档和完整来源测试都会携带新增字段。

## 测试

Host 测试要求未知题外 id 无法通过校验；只有显式题外边界才能让受保护的带编号总结产生零道题；一个边界无需枚举每一行，就能排除同页重新开始试卷的前言。跨页合订试卷测试证明，后一套试卷标题无需单题 `stopBeforeElementId` 即可全局停止前一套末题。聚焦的题目分割测试套件与包类型检查覆盖接受和拒绝路径。
