# Agent Note: 有界试题图片复核

Status: implemented

[English](2026-09-04-bounded-question-crop-review.md) | 中文

## Problem

一次关闭思考的任务花费二十多分钟反复重写 63 张题图的视觉报告。不同拒绝消息拥有独立计数，参数格式错误又完全绕过工具执行。缺少已接受输出时还可能生成确定性题界或保存未验证题图，掩盖失败而非完成复核。

## Decision

[试题处理器](../../../../packages/host/teacher-workbench/README.zh.md) 在每个子 agent 内按同一归一化诊断类别累计连续失败调用。语义拒绝在执行阶段消耗预算，工具终结回调还会累计参数格式与分派失败；不同诊断会重置连续计数。预算耗尽会结束或取消当前子 agent；配置允许的全新题界或缺陷记录前恢复子 agent 会获得新预算，每个有界修复子 agent 也一样。每个子 agent 默认拥有可配置的五分钟截止时间，独立的复核和修复子 agent 分别计时，不限制整份 PDF 的总耗时。

Web 配置与服务默认值均采用每组四个核心页，保留相邻续题上下文和两组并发，将紧凑复核输出限制为 8,192 token。报告使用简短识别性语句。浏览器和 Host 来源流水线只有通过视觉复核才会标记为已验证。系统最多应用三次已接受的裁剪修订，随后执行最终复核。经校验的纯删除修订若未留下变化后的题图，无须继续检查像素。缺少已接受题界草稿仍然返回错误，因为此时没有裁剪几何。初步裁剪一旦存在，任何视觉复核失败都采用[题目级修复兜底](2026-09-05-question-local-repair-fallback.zh.md)；完整缺陷保持精确裁剪范围，缺陷形成前的失败则把当前复核范围标为未复核。

## Alternatives considered

**仅关闭思考。** 观察到的任务已关闭思考，主要时间花在报告生成和失败的工具调用上。

**逐条接受题图记录。** 这种方式可以避免重复有效记录，但会改变完整组覆盖协议，并可能漏掉来源页上的独立题目。沿用更小的页面分组能减少报告体积，同时保留覆盖检查。

**保存模型最后一次被拒绝的几何。** 这可能发布被裁断、跨题或其他无效题图。兜底只保存已经通过 Host 校验的几何，并把受影响题目标记为未复核。

## Consequences

更多分组会重复部分相邻页面上下文与模型启动开销。特别慢的本地模型可能需要超过五分钟；截止时间与组大小仍可配置。单个异常高密度页面不会继续拆分。浏览器队列仍要求页面保持打开，不能跨刷新持久运行。不承诺成功任务具有固定加速比例。

工具运行时回归用例混合语义与参数格式错误，并记录归一化结果。完整 Web 组合用例在真实子 agent 循环内验证有界修复失败。控制器与 Host 来源测试要求精确的受影响标识，在最终复核仍未解决时保留第三次通过 Host 校验的修订，在复核返回错误或抛错后保留当前裁剪，并继续后续分组。题界失败仍要求被接受的输出；初步裁剪存在后，视觉缺陷形成前的失败不再中止任务。
