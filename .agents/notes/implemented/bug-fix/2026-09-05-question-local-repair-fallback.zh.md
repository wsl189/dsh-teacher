# Agent Note：题目级裁剪修复兜底

状态：已实现

[English](2026-09-05-question-local-repair-fallback.md) | 中文

## 问题

裁剪级视觉缺陷已经指出像素错误的具体题目，但修复提交被拒绝时仍可能使整个处理分组失败。缺陷产生前的复核超时和供应商错误也可能丢弃几何已经通过 Host 校验的初步裁剪。大 PDF 会因此在后续分组之前停止，即使 Host 仍持有每道题的安全几何。[可纠正的边界决策](2026-09-04-question-boundary-corrections.zh.md)保持精确的修复范围与诊断；本记录替代初步题界产生后整个视觉复核阶段的失败即停结果。

## 决策

Host 接受完整题界草稿前仍不能保存被拒绝的草稿，因为此时没有安全裁剪几何；但可恢复的题界失败只隔离当前页面组，不再传播到整份 PDF。其他分组全部继续，失败组以空的初步题目列表进入整页视觉复核，让基于像素的修复路径重新建立有效题界；复核仍失败时才把该组标为未确认并跳过。即使被拒完整草稿额度已经用完，最终改正确的草稿仍可接受；真正超过额度时会立即结束当前子 agent，不再用剩余失败调用额度重复撞同一个上限诊断。题界与复核阶段默认最多使用三个全新子 agent。

初步题界一旦产生通过 Host 校验的裁剪，视觉分类就改为尽力复核：预览准备失败、超时、供应商或模型错误、无效输出、复核调用抛错及资源释放失败都会保留当前安全分组，不再中止整份 PDF。尚无完整缺陷集时，系统无法确定更窄范围，因此把当前复核范围内的全部题目标为未复核。

完整缺陷点名现有裁剪后，修复次数耗尽、超时或模型停止会返回 `unresolved` 裁剪复核结果，其中只包含被引用的 `affectedQuestionIds`。纯页级漏题缺陷仍影响完整分组，因为没有现有裁剪能够标识遗漏任务。返回的题目始终使用最近一次通过 Host 校验的分组几何；模型被拒绝的参数绝不会提升为保存区域。

每次修正被接受后，调用方只重新渲染 `affectedQuestionIds`。系统最多应用三次局部修订并执行最终视觉复核。复核返回错误、调用抛错、预览未完成、最终仍要求修改或返回 `unresolved` 时，浏览器都会保存最近一次安全裁剪，在已完成任务的警告中统计相应题目，并继续后续分组。普通对话流水线保存同一份最近安全分组，并通过 `unverifiedGroupCount` 报告。

## 考虑过的替代方案

**一道裁剪无法收敛后让处理分组失败。** 这能阻止不确定输出，却会丢弃无关且已验证的工作，并阻断大文档的后续分组。

**保存最后一次被拒绝的修复参数。** 被拒绝的草稿可能裁掉学习者内容、跨越其他题头或引用错误元素类型。只有最近一次通过 Host 校验的几何能够用于兜底持久化。

## 后果

未复核裁剪仍可能包含触发修复的视觉缺陷，未确认的空分组也可能含有漏题，因此进度行分别显示题目和分组警告，不会悄悄宣称已完整验证。无效 OCR 输入、系统性的模型或视觉配置失败、最终题图渲染失败及持久化写入失败仍会终止任务。普通对话切题在全部分组都确认无题或仍未确认时可以正常结束，而不会创建空批次。聚焦的 Host 与浏览器测试覆盖精确受影响标识、被拒草稿额度耗尽后的有效接受、可恢复题界分组隔离、三次已接受修订加最终未解决复核、复核返回错误与调用抛错、最近安全像素持久化、继续后续分组，以及 Web 组合中的修复预算耗尽。
