# Agent Note: 试题版面完整性恢复

Status: implemented

[English](2026-08-24-question-layout-integrity-recovery.md) | 中文

> 补充[逐区域保留试题裁切起点](2026-08-24-per-region-question-crop-origin.zh.md)中的渲染规则。

## 问题

MinerU 的多页 `para_blocks` 可能把后一页顶部的行附加到前一页底部附近的段落。受影响的后一页段落可能只留下空的 `lines_deleted` 块，而边界框相同的 `preproc_blocks` 条目仍保留原始行。只归一化 `para_blocks` 会把一道题移到前页，并从其来源页面删除。

题目边界提交也只校验召回结果：Host 会验证子 agent 选中的 id，却不会拒绝遗漏的高置信题目标记。多级小数章节标题没有被识别为分区边界，显式重新归属的图形也可能在没有几何一致性检查的情况下从前题移给后题。

## 决策

MinerU 结构化归一化只接受边界框中心位于所属块内部的子行。清理后没有有效元素的段落会由边界框相同且可用的预处理块替换。任一修复信号都会把该页标记为可疑。多页 PDF 响应含可疑页时，提供方只把该页作为单页范围重新请求，并替换其批次结果；未受影响页面保留原批量结果。

题目边界 Host 会识别多级小数章节标题，并要求答案边界之前每个带括号或括号受损的“题”编号候选都成为已选择题头。如果一项附属元素与同页另一道已选择题头的纵向区域重叠，却不与其拟归属题头重叠，Host 也会拒绝把它移给后题。运行时 skill 会向子 agent 提供相同要求，使被拒绝草稿能够在不编造几何信息的前提下修正。

## 已考虑的替代方案

**逐页解析所有 PDF。** 这种方式可避开 MinerU 的跨页合并行为，但会增加请求数量，并放弃有界页面批次的常规吞吐收益。

**所有页面都使用 `preproc_blocks`。** 预处理几何信息的召回率更高，但全面替换已清理的段落顺序会改变未受影响文档。按相同边界框恢复只在清理结果丢失内容时介入。

**给每个分割子 agent 都附加预览图。** 当前工具模型与子 agent 协议支持会话中有记录的图片附件，但无条件传入页面图片会增加渲染、上下文与视觉推理延迟，裁剪仍必须回到可信元素 id。确定性几何修复与候选覆盖可以直接处理这些故障信号。以后若确定性检查仍无法产生已接受草稿，视觉回退可以只附加少量带标注的可疑页。

## 后果

正常多页版面仍按每个已配置批次发起一次 MinerU 请求。损坏响应只为标记页增加单页请求，替换后来源页码保持稳定。如果定向恢复返回了意外页数，结构化提取会失败，而不会悄悄接受错位几何信息。

带括号的练习册题目与小数章节过渡不会再消失于前一道裁图中。跨栏图形的重新归属必须与已选择题头几何信息一致。提供方、Host 校验器、浏览器渲染器与普通对话渲染器分别具有跨页恢复、遗漏候选、错误附属归属和排除右栏像素的聚焦回归测试。
