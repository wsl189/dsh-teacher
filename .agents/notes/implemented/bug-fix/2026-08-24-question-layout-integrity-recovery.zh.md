# Agent Note: 试题版面完整性恢复

Status: implemented

[English](2026-08-24-question-layout-integrity-recovery.md) | 中文

> 补充[逐区域保留试题裁切起点](2026-08-24-per-region-question-crop-origin.zh.md)中的渲染规则。

## 问题

MinerU 的多页 `para_blocks` 可能把后一页顶部的行附加到前一页底部附近的段落。受影响的后一页段落可能只留下空的 `lines_deleted` 块，而边界框相同的 `preproc_blocks` 条目仍保留原始行。只归一化 `para_blocks` 会把一道题移到前页，并从其来源页面删除。

即使没有跨页损坏信号，MinerU 也可能遗漏普通数字题头，或在横向跨页中把左右两半的内容合成一组。扁平来源顺序随后会把两栏交错排列。一个恰好在同栏下一题题头上方开始的装饰图可能被分给前一道题，并把其矩形裁剪向下撑过后续多道题。

题目边界提交也只校验召回结果：Host 会验证子 agent 选中的 id，却不会拒绝遗漏的高置信题目标记。多级小数章节标题没有被识别为分区标记，显式重新归属的图形也可能在没有几何一致性检查的情况下从前题移给后题。

## 决策

MinerU 结构化归一化只接受边界框中心位于所属块内部的子行。清理后没有有效元素的段落会由边界框相同且可用的预处理块替换。任一修复信号都会把该页标记为可疑。多页 PDF 响应含可疑页时，提供方只把该页作为单页范围重新请求，并替换其批次结果；未受影响页面保留原批量结果。

完成这些修复后，如果横向页面中的普通数字题头存在向前跳号，提供方会再发起两次 MinerU 请求，分别解析左、右半页 PDF。所得坐标会映射回来源页面。缺失的编号题组会被加入；只有同题号原始题组跨过页面中线时，恢复出的单栏题组才会替换它。没有跳号的页面保留批量结果。

试题分割 Host 会识别并自动排除多级小数章节标题，同时把答案标记之前每个带括号、OCR 受损的“题”编号或普通行首数字候选作为权威审计列表提供给子 agent。每个候选都必须成为已选择题头或被明确排除，补齐已选数字序列缺口的普通候选不得排除。无效或重复的元素引用仍必须修正，但不消耗完整草稿次数。Host 会拒绝把紧接在已排除数字候选之后的续行选作题头，因此 OCR 重叠副本会保留一个完整的数字起点。同页左右两半都有题头时，Host 会把未显式归属且位于单栏的元素交给同侧纵向位置最近的前一道题头，删除同侧没有在前题头的栏首元素，并忽略未显式归属且跨越中线的元素。裁剪不得越过同一横向范围内靠后的已选择题头。页面下半部中在至少三页的近似归一化位置重复出现的大尺寸文字会作为模板装饰排除，相关的跨中线图片也会随之排除。当后续页面的第一道普通题头在分区标题之后从 1 重新开始时，其前置说明会被排除，而不会附加到上一套试卷的末题。不与已归属元素重叠的排除框会成为白色消除区，从而保留分区标题侧面的图形，无需在二者之间选择一条横向切线。显式附属元素声明仍需通过几何一致性检查。运行时 skill 会向子 agent 提供相同要求，并明确不由子 agent 修复同页栏顺序。

## 已考虑的替代方案

**逐页解析所有 PDF。** 这种方式可避开 MinerU 的跨页合并行为，但会增加请求数量，并放弃有界页面批次的常规吞吐收益。

**把每张横向页面都拆栏。** 这种方式会让普通页面多付出两次请求，还可能破坏真正的通栏版式。使用向前跳号信号可把额外工作限制在具有直接内容缺失证据的页面。

**所有页面都使用 `preproc_blocks`。** 预处理几何信息的召回率更高，但全面替换已清理的段落顺序会改变未受影响文档。按相同边界框恢复只在清理结果丢失内容时介入。

**给每个分割子 agent 都附加预览图。** 当前工具模型与子 agent 协议支持会话中有记录的图片附件，但无条件传入页面图片会增加渲染、上下文与视觉推理延迟，裁剪仍必须回到可信元素 id。确定性分栏恢复、空间归属与候选覆盖可以直接处理这些故障信号。以后若确定性检查仍无法产生已接受草稿，视觉回退可以只附加少量带标注的可疑页。

## 后果

正常多页版面仍按每个已配置批次发起一次 MinerU 请求。损坏响应只为标记页增加单页请求；横向页面出现编号缺口时会增加两次半页请求。替换后来源页码保持稳定。如果定向恢复返回了意外页数，结构化提取会失败，而不会悄悄接受错位几何信息。

带括号的练习册题目、普通数字编号缺口与小数章节过渡不会再悄悄消失于前一道裁图中。同页分栏不依赖模型编写的附属元素列表；后题像素不会进入前题矩形，排除标签也可在不裁掉相邻题目内容的前提下消除。提供方、Host 校验器、浏览器渲染器与普通对话渲染器分别具有跨页和半页恢复、遗漏及错位候选、分栏归属、裁剪停止位置、白色消除区和排除右栏像素的聚焦回归测试。
