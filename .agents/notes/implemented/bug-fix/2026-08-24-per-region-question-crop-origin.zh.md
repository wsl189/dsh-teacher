# Agent Note: 逐区域保留试题裁切起点

Status: implemented

[English](2026-08-24-per-region-question-crop-origin.md) | 中文

> 本决策细化[试题切割工作台](../feature/2026-08-19-question-segmentation-workbench.zh.md)的裁切几何规则。

## 问题

通过校验的试题区域会保留各自的左、上、右、下坐标，但两套 PDF 渲染器都会把每个区域的横向坐标替换为整份 PDF 的最小左坐标与最大右坐标。双栏试卷会让这段距离接近整页宽度，因此左栏试题会带入右栏内容，每张已保存图片也会接近整页宽度。

## 决策

所有语义页组合并后，Host 会先把每道题全部区域中最大的 `(rightLimit - left) / pageWidth` 作为该题宽度，再用题宽中位数表示大部分题。题宽高出中位数的比例超过 `maxQuestionWidthOutlierExcessRatio` 时，不参与 `maxQuestionWidthRatio` 计算；默认超出比例为 0.5。切题结果把剩余最大归一化宽度同时交给两套渲染器。

视觉复核与局部重切会保留首次选定的整份 PDF 统一宽度。它们可以修订各区域的来源几何，但修订题目中的原始安全栏界不能在下一轮复核或最终持久化前替换经过异常值过滤的宽度。

Host 还会为每个页面片段记录 `rightLimit`：它取纵向重叠且不属于该题的右侧内容与下一条重复编号版式栏之间最近的安全边界。已接受题头与带编号的理论标题都能在完全相同的页面尺寸组内建立栏目起点；若已归属内容跨过该起点，则不用这条推断边界。来源页面右边缘仍是最终回退值。该值是不受区域内容右界 `right` 影响的来源像素硬上限。

同页左右两半都有已接受题头时，未显式归属且位于单栏的元素使用同侧纵向位置最近的前一道题头；未显式归属且跨越中线的元素不会扩大任一栏目。同一横向范围内靠后的题头也是纵向硬停止位置。不与已归属元素重叠的语义排除框会作为 `excludedAreas` 传递，而不会强行用一条横向停止线切过相邻内容。

浏览器 PDF.js 渲染器与普通对话 Host 渲染器都会保留每个区域自己的左、上、下坐标。渲染器从该区域的左边界向右最多采样一份最大非异常归一化宽度，并受 `rightLimit` 限制，随后把 `excludedAreas` 涂成白色。未缩放的来源像素会放入使用该统一宽度的白色画布。跨页试题会先对每个页面片段分别应用同一规则，再把片段纵向拼接。

## 已考虑的替代方案

**使用整份 PDF 的最小左坐标与最大右坐标。** 这种方式能让相同尺寸页面只产生一种宽度，但会丢失栏目归属，并导致本决策修复的整页宽裁切。

**保留每个区域原来的右边界。** 这种方式能保留栏目，但会产生不同的输出宽度，也不满足工作台统一使用最宽已接受试题的要求。

**只在来源页面右边缘截断。** 这种方式会保持统一输出宽度，但只要 PDF 其他位置存在较宽试题，共用宽度仍会采样相邻栏目。

**裁剪前识别任意页面栏目拓扑。** 无需建立完整栏目模型。重复编号标志可以揭示稳定的栏目起点；页面缺少足够重复证据时，纵向重叠且不属于该题的元素提供局部边界。两条规则都不假设栏目宽度固定。

## 后果

不同栏目的试题会保留不同的横向起点，并在相同尺寸页面上获得一致的输出宽度。带编号的非试题内容也能在该栏首道已接受试题出现前建立同一条安全栏目边界。受到页面边缘或相邻栏目限制的区域会在右侧留下白色空间，而不会取得无关来源像素。被排除的分区文字可以在不裁掉纵向范围与其重叠的相邻图形的前提下移除。

处于配置中位数相对容差内的试题仍可增大所有画布。更宽的统计异常题会保留已校验几何，但不会撑大统一画布；如果某类文档确实包含更宽试题，部署方可以调高配置容差。已经保存的图片不会被重写；用户需要重新切割来源 PDF 才能应用该几何规则。客户端与 Host 回归测试使用横向分离的区域，同时断言局部裁切起点及 `rightLimit` 之后不存在相邻栏目像素。测试还会在切割后注入更宽的原始安全栏，并断言复核与最终渲染继续使用首次计算的非异常比例。Host 覆盖还保证多区域试题只计一次、正好高出中位数 50% 的题宽被保留、更宽的值被排除，并在配置容差增大后重新保留该值。
