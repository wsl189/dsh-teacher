# Agent Note: 可纠正的试题边界决策

Status: implemented

[English](2026-09-04-question-boundary-corrections.md) | 中文

## Problem

反复提交整份草稿时，模型在修正一个被拒元素的同时改变了无关分类。只报告数组下标的诊断无法清楚标识错误元素。OCR 知识表格被拒绝作为题外标记，前面的题外块错误阻止后续题目的附件归属，自动图片保留又与图片题头发生冲突。这些错误耗尽了[有界复核预算](2026-09-04-bounded-question-crop-review.zh.md)，却没有取得进展。

## Decision

[边界与视觉修复提交工具](../../../../packages/host/teacher-workbench/README.zh.md)保留最近一次完整草稿，后续调用可以通过 `corrections` 替换单个元素的决策，保留未列出的全部决策。每项替换只选择一种角色，并移除同一元素的冲突分类；题目替换需提供完整的附件及停止位置字段。纠正也可以替换或显式清除保留的整组末尾停止位置，无需重写题目决策；只有这类修改允许空纠正数组。保留的无效末尾停止位置必须能通过恢复阶段的专用纠错工具修复，而不能在每次新子 agent 中持续存在。Host 校验合并后的完整草稿，包括候选覆盖、核心页归属、受保护作答要求、授权修复和几何。局部纠正不能绕过这些检查，也不重置失败调用预算。重复的被拒边界草稿保留原始诊断，最终错误包含最近一次具体诊断。描述性 `headConvention` 元数据不决定裁剪归属，因此改为可选。

OCR 来源、修复上下文和预览查询都可以重复读取。再次读取有效证据不消耗拒绝预算；预览复用已保存附件，并发请求也不会重复保存。无效分块下标、未知 id、单次图片请求中的重复 id，以及未检查必需证据仍会校验失败。子 agent 截止时间继续限制反复读取。

紧凑视觉复核将核心页与上下文页分别放入带标签的拼图，每张图上方重复准确 PDF 页码和范围。纯文本修复子 agent 接收核心页下标、候选与图片 id、当前题头。漏题缺陷要求完整分组替换，裁剪缺陷仍只允许局部修复。上下文页可提供续文证据，不能产生归本组所有的新题头。

紧凑局部裁剪修复使用独立的扁平工具和角色提示。每个修复条目标识已引用的现有裁剪，可选坐标使用准确页面标签，内容与几何变化交由同一完整校验器处理。此阶段不开放整组字段，避免模型为了调整一张裁剪而重建整份题目列表和多层几何对象。新的局部恢复保留同样的扁平草稿。仅页面的漏题缺陷省略无意义的修复意图，并保留整组处理路径；现有裁剪的缺陷仍须声明修改方向。

裁边、重新归属和删除上下文以有界必需分块提供裁剪内全部采样 OCR。仅边缘片段无法定位从长裁剪中间开始的题外块。已记录的上下裁边授权显式题外块决策，已记录的裁边或重新归属授权显式排除无关图片及其说明。单独坐标不能重新分类作答正文，也不能静默丢弃必要图片。完整校验和后续视觉复核仍然必需。

移除题外块可能删除开头或末尾的整个来源页面切片。即使没有同页矩形可供比较，这种删除也满足相应的上下裁边意图。被删除切片上的冗余坐标仍按原有采样范围校验，只能在页内向内裁剪；原裁剪不含该页、向外扩张或坐标越过页面都会被拒绝。语义归属和必要内容保护仍决定切片能否删除，避免要求模型为了满足坐标校验而重新引入已移除的内容。

来源大小决定传输方式，不决定视觉判断权限。即使展开后的 OCR 需要多个分块，紧凑序列化仍可能满足内联上限；完整内联来源满足全部这些分块的检查要求。紧凑证据超过上限时，没有页面预览的分块 OCR 仍使用自动图片归属，并且不开放像素删除字段。向没有预览的子 agent 要求基于预览的图片决策，会仅因文档文字增加而产生没有证据支持的分类工作。含图的完整分类测试显式提供并检查预览；纯 OCR 测试继续要求完整来源检查和后续视觉复核。

分块及内联 OCR 证据都标明每页范围。分块读取的角色提示与内联提示一样，要求直接提交工具而非输出分析长文。裁剪页头在 crop id 旁重复来源标注的 Q 标签。每个题界或紧凑修复子 agent 都有有界的重复诊断额度。系统归一化第一条可执行诊断，使变化的数组下标和元素数字后缀仍归为同一种失败；重复该类别会耗尽额度，到达不同诊断则重置重复计数。参数结构失败采用相同归一化，所有越界工具统一为一个类别。子 agent 截止时间和输出上限仍约束交替失败。额度耗尽后可使用 `maxQuestionBoundaryAgentRuns` 允许的剩余恢复次数，在新上下文中携带被拒绝草稿和诊断。新子 agent 必须重新检查证据，不能撤销已记录的视觉缺陷，并且必须通过完整校验。持续的题界失败会在配置允许的子 agent 次数后终止，不会无限重试，因为此时不存在裁剪几何。初步裁剪一旦存在，视觉复核失败就遵循[题目级兜底](2026-09-05-question-local-repair-fallback.zh.md)：完整缺陷只把被点名且最近一次通过 Host 校验的裁剪保留为未复核结果，缺陷形成前的失败则保留当前安全复核范围。

题外标记接受有语义文本的元素及表格，包括没有提取文字的表格。OCR 表示类型不能使知识表格变成前一道题的内容。显式题外标记只有位于该题题头之后、附件之前时才阻止附件归属。已选择的图片题头由该题拥有，不再额外获得自动保留图片分类。这些决策不依赖文件名、页码、出版社或特定教材条件。

紧凑缺陷提交一次报告全部冲突、遗漏、重复及未知分类引用。引用无效的提交不会更新草稿。有效补交填补缺少的分类、关注证据或图片检查时返回 `INCOMPLETE`，不消耗失败调用额度；把进展当作失败可能在最后一项检查前耗尽额度。后续可以省略未改变的数组，单独补交检查时也可省略 `verifiedCrops`。无进展重复和无效证据仍被拒绝。如果仅页面的漏题发现自己的证据又称不存在独立学习者问题或作答要求，Host 会在记录缺陷前拒绝该发现；没有题目的干净核心页应提交空发现列表。本轮工具守卫会在越界调用产生文件系统等副作用之前将其拦截，被拦截的图片读取不能游离于预算之外，一直循环到截止时间。接受前仍须完整覆盖全部裁剪和检查，子 agent 截止时间继续约束运行。紧凑视觉子 agent 耗尽额度后，使用配置允许的剩余恢复次数，只携带有效草稿条目和最近诊断，不携带格式错误的调用。全部来源拼图重新附加，缺少的检查仍须补充新证据；分类恢复不能清除已正式记录的缺陷。测试覆盖超过拒绝额度的分次补交、无进展重复的拒绝、自相矛盾的漏题发现，以及组装 Web 循环中的单独检查调用。裁剪元数据携带有界 OCR 题头片段，便于匹配来源标注与裁剪图；完整性仍必须由实际像素证明。

题界恢复保留了草稿时，只能调用专用纠错工具和必需的证据读取工具。纠错工具不暴露完整草稿字段，仍委托相同校验器处理。它的简短角色提示描述元素替换，不再重复初始完整切题任务。恢复过程不能通过混用完整列表和纠正项意外覆盖无关决策。

重复 OCR 括号不会隐藏通用标签题头、纯来源标签或小题标记。带限定词的求解要求会保护所属题目；带括号的小题不能仅因 OCR 多插入一个起始括号而成为独立题头。上下文题头错误给出准确的 omit 纠正，而不是要求子 agent 自行猜测替代角色；紧凑工具结构不提供不支持的像素排除操作。经过校验的内容重新归属修复，让已声明题外块同时约束归属和正文保护；仅有坐标或排除项不能授权删除作答正文。题外决策也阻止仅附件优化恢复被污染的原裁剪几何。测试保留陌生标签场景，证明发现题头不受解析器提示限制。 已选题头不能成为另一道题的附件。这可以防止附件声明夺走题头归属，而裁剪限位又把该题头从声明方裁剪中截掉，最终生成空标签图和缺失题头的题图。

局部裁剪修复中，显式保留的图片维持已知的原有归属，包括阅读顺序在题头之前的图片。Host 在完整校验之前将该决策转换为附件，而不是在校验后直接扩张几何。重复或冲突决策仍无效；未保留必要图片仍不能通过保护检查。

元素替换同时移除过时附件和根级分类，保留图片的纠正不会再与原有显式归属冲突。紧凑复核和单独图片复核要求相同的四边实际观察及必要图形证据。Host 不再用作答要求证据填充这些字段，避免只认出图中间的一道题，就忽略其他位置的无关内容。

视觉关注项显式标出采样表格和未完成的 OCR 作答尾句。复核者必须先确认表格属于作答任务而不是知识总结，再检查最后一行及底部边框。来源预览随题界识别或首次完整复核到达时，栅格像素确认的附近水平答题线可延伸未完成的 OCR 尾句裁剪；来源块和其他题图限制搜索范围，空白、厚像素或垂直分散的像素区域不会触发延伸。浏览器首次在复核时发送预览，因此该路径先完成整组分类，再返回修订几何并要求新的局部视觉验收。这会保留实际像素，而不是合成答题线或相信模型声称已有答题线。后续明确的视觉修复仍具有优先权。每张复核图表只排列一行，最多两张图片，避免供应商缩小多行大拼图时丢失边缘细节。

交错的 OCR 顺序不能决定同页栏位终止位置。归属计算在当前内容栏中按几何检查全部相关停止位置；另一栏题头不会删除本栏剩余小问或图形。独立题号分值标签或已识别的题干前缀没有独立作答内容时，不能与后续无编号题干拆成两题。显式附件不能抢占同栏其他题目的正文；诊断指出附件及双方题头，而不是诱导删除被清空的引用标签。章节转换后的独立括号编号作答问题即使位于理论资料中，也会进入显式候选；作答要求可出现在下一个同级条目前的续文中，其后续同级条目终止归属，包括带文字的 OCR 表格标题和重复起始括号。已有父题仍保留所属小问。

图片排除在最终坐标修改之后应用。如果只按自然 OCR 矩形计算遮除区域，刚好在矩形外的排除图片会被遗漏，修复选择更大的底边时其像素又会进入裁剪。最终采样矩形决定需要遮除哪些显式排除框，与所属作答正文重叠的框仍受保护。组装 Web 修复覆盖了位于自然矩形外、提交底边内的图片及说明排除块。

局部修复将新推导的几何与此前裁边取交集，并保留此前遮除区域，除非获准扩张或明确恢复内容需要补回像素。移除无关页面切片不会重建早前复核已移除的资源块。整组发现与这项局部裁剪保留规则分开处理。

纯 OCR 分类不能把受保护的作答候选判为题外内容，包括调用方虽有预览但紧凑子 agent 没有收到图片的情况。基于像素的复核仍能移除真正误报。这宁可产生可供复核的额外裁剪，也不让遗漏任务失去后续检查入口。没有作答要求的简短大纲标题无需出版社专用措辞表即可终止前题归属，同级条目终止位置则防止普通定义借用后一道题的作答要求。

视觉复核区分切割缺陷和来源缺陷。与必要源文字或图形重叠的水印、印章或扫描污点必须保留，因为矩形遮除会同时破坏作答像素。这不允许保留独立资源二维码或无关块、忽略内容缺失，也不能声称原本被遮挡的文档已被修复。两条复核路径共享相同的来源保真指令，几何测试保护重叠的作答正文，同时移除可分离的无关内容。

来源页上下文和实际输出使用不同的视觉标签。未采样但可读的上下文覆盖半透明灰色，实际裁剪像素保持不变。拼图附带 Host 计算的图片采样信息，不能把只在来源页可见的图片引用为裁剪内部内容。合格裁剪中的每个已采样图片都有明确角色及证据。缺少图片检查属于可修复的草稿遗漏；无关图片必须报告缺陷而不能通过，独立图片不能以原文覆盖层为由保留。这防止复核者一边描述资源无关，一边接受裁剪。测试覆盖缺少检查、仅来源页引用、必要内容、重叠覆盖层，以及矛盾合格声明后执行真实修复。

OCR 类型不决定已识别文字是否构成独立试题或章节标题。含文字的图片和表格参与语义候选识别，同时保留原始栅格框。续文扫描能识别中文标点前的单个作答下划线，不会把数学下标或图片选项标签当作新要求。这保留被 OCR 归类为图形的题干，并阻止图片型章节横幅并入前题。

独立前缀检查计入已选题头自己的文字，即使 OCR 将它标为图片或表格。否则候选校验可能要求保留两道独立题，而归属校验又同时要求合并。已识别的独立作答题头不接收未知提升警告；前面知识条目提供的一般学科知识，本身不使后面的自包含填空变成下属片段。真正未识别的题头仍需要该检查。

缺失内容诊断区分面向学习者的作答要求、答题标记、待求解集与已有答案及解答。这些用语本身不会禁止扩张，但仍须满足视觉证据、授权方向和相邻题头保护。缺陷同时要求加入已有答案或解答时仍然无效。

裁边缺陷可以用正确题干或小问作为无关内容的位置参照。证据提到这些作答内容，不代表它们是删除目标，Host 不能仅凭这些词语拒绝缺陷。后续修复校验仍拒绝截断必要 OCR、静默删除图片、修改未引用题目及未授权方向。重新分类无关文字块必须显式声明题外决策，保存前仍须再次通过视觉复核。

紧凑复核和单独图片复核共享视觉归属规则：可选资源图片不能仅因位置相邻就成为题目必要内容。同一次提交既报告某张裁剪的有效缺陷又称其合格时，有效缺陷优先；丢弃的是该图的合格判断及关注项检查，不是缺陷。该图仍须修复并再次复核。未知引用、无效缺陷及其余无效合格判断会拒绝整次提交且不更新草稿；仅缺少覆盖的有效条目可保留为尚未接受的草稿。

切题工具在严格参数校验前，按声明的结构解码 JSON 数组字符串。真实支持工具调用的模型可能仅因把数组编码成字符串，就反复重写整份分类。解码不损失信息，且仅用于这些工具：无效 JSON、非数组值、无效嵌套条目、未知引用和遗漏必填字段仍不能通过校验。证据字符串保持原样，也不会推断缺失分类。

只有括号编号的图注不能借用后面同编号试题的作答要求，也不能成为截断所属题目的同级条目。后续带正文的条目会结束作答要求扫描，即使前面的裸图注缩进在图片下方。这使标签和完整图形保持在所属题目内，而不是产生重复的纯图裁剪。未给出结果的条件结论仍作为作答空位证据，无需枚举全部待求量；已给出结果的完整结论不受此规则保护。题界与复核指令明确要求保留随题附录直到最后一行，并将其与解答区分。

图片采样元数据包含 OCR 文字及准确的题头归属。OCR 图片框可能是一整道文字题，而不是独立配图。保留的题头必须使用必要内容角色；无关或原文覆盖层分类会在正式记录破坏性裁剪缺陷之前被拒绝。保留图片引用指向非图片时属于引用错误，诊断会指出准确 id、实际元素类型、核心页内有效的图片 id，以及非图片应使用的附件方式。参考总结标题会阻止其中的括号编号方法说明项借用偶然出现的求解动词成为独立作答任务。合理的 remove-crop 缺陷只有在像素证据指出非任务类别，并明确说明没有独立学习者作答要求时，才能移除被 OCR 保护的误报；含糊否认仍保留该裁剪。仍要求检查或确认的发现并非视觉上已确认的缺陷。诊断明确指出无关角色来自复核者的分类，而不是复核者必须服从的 Host 检测结论。越界工具错误提供完整允许名称，帮助纠正被截断的本轮后缀，不接受别名或扩大权限。多目标上下文读取省略目标时会返回准确的可用 id 且不消耗失败调用；提供无效 id 仍然失败。方向错误直接给出当前及提交的坐标和允许方向，不要求修复子 agent 从大量上下文中重新推导。

## Alternatives considered

**增加拒绝次数。** 更多重试不能修复 Host 自相矛盾的规则，模型重复草稿时只会增加延迟。

**自动重新分类所有被拒候选。** 候选提示可能出错。猜测会隐藏漏题，或把知识和解答升级为试题，因此仍要求 agent 明确决策并接受视觉复核。

**每次纠正都要求完整替换草稿。** 这会重复正确决策，产生可避免的遗漏和数组冲突。按元素替换无需重复整份内容，也能保留完整结果校验。

## Consequences

模型分类仍具有不确定性。结构校验可以拒绝缺失决策、归属矛盾、不受支持的图片角色和无效几何，但不能证明每项视觉判断都正确。真实模型验证通过 Web 上传及队列运行配置中的 Ollama 模型并关闭思考，再将保存的裁剪像素与来源页对照，检查换行作答横线、知识材料中嵌入的题目、给定参考公式及图文混排。队列显示成功不能单独作为验收依据，这些协议检查也不保证任意模型输出都能正确切题。

切题操作保留一份完整草稿和有界的拒绝诊断缓存。补丁仍可能在语义上出错，系统不保证接受任意模型输出。视觉复核仍是已验证状态的必要条件；初步裁剪产生后的任何视觉阶段兜底只能带着明确未复核警告保存。针对性测试覆盖有文字和无文字表格、过渡两侧的附件、受保护题头及整组修复纠正、图片题头、重复读取证据、范围标签拼图像素、新上下文恢复、持续题界拒绝预算耗尽，以及裁剪级耗尽返回被引用未解决标识。组装后的 Web 场景通过真实子循环同时记录根据保留恢复状态提交的按元素纠正，以及被点名裁剪的兜底结果。
