# Agent Note: 分发不带可视化界面的 Univer 内容工具

Status: implemented

[English](2026-09-19-univer-headless-office.md) | 中文

## 问题

聊天 Office 任务会打开 Univer 工作树窗口，并提供与所需成品无关的配置。DSH 的文档侧边栏已经提供成品预览。Gateway 在工具完成后仍保留数据库句柄，导致 Windows 无法在应用运行期间删除临时工程。

## 决策

[无界面重打包](../../../../third-party/README.zh.md#artifact-notes)移除 Univer Client 入口、设置注册、实时预览与审阅路由、Viewer 资源及对应的 Host 状态缓存。AI 内容工具、隔离编辑工作树、导入导出和后台渲染继续可用。DSH 独立的 Office 侧边栏预览器继续挂载。普通 Office 交付直接发布已校验文件，省去 ready/status 两次收尾调用；用户要求保留的原生项目仍可通过工具使用审阅状态。

Gateway 提供 JSON 健康检查和目录释放操作。[Office 工作区所有者](../../../../packages/deliverables/office-workspace/README.zh.md)仅在验证受管理目录身份后发出可等待的释放事件。释放只关闭目录内的数据库缓存，不删除文件；存在活动 HTTP 操作或协作连接时拒绝释放。HTTP 活动包括 SDK 的异步请求体读取与响应处理。在缓存数据库全部关闭前，整个目录拒绝新的操作。已释放的项目可以重新打开继续编辑。发布和删除等待释放完成，失败时保留源文件，各独立项目继续清理。

本决策部分取代 [Viewer 评估模式决策](../bug-fix/2026-09-01-univer-viewer-evaluation.zh.md)：许可、水印和评估限制规则继续生效。[生成性能决策](../bug-fix/2026-09-16-office-generation-overhead.zh.md)继续规定批量编写、编译缓存与校验。工作台功能、模型设置及其他内置插件保持原有行为。

## 考虑过的替代方案

**默认关闭自动窗口偏好。** 这仍保留预览代码、路由、配置卡片及手动窗口。所需分发版移除该界面。

**移除后台渲染器。** 截图、Slide 编译尺寸测量和 PDF 导出需要它。移除这些操作会削弱 AI 编辑及校验。

**在 agent 停止前删除临时目录。** 停止监听器可以在同轮加入后续工作。清理属于显式收尾与已结束轮次的生命周期处理；暂停工程继续保留。

## 后果

用户通过 AI 工具编辑，并用 DSH 或默认应用打开导出文件。不提供原生 Univer 的交互式审阅。移除浏览器代码不会消除模型推理、worker 启动或文档渲染开销。释放操作保护活动项目，不强制删除；崩溃和未退出的外部编写进程仍可能留下可恢复目录。不扫描历史目录进行删除。

## 测量与验证

现有[构建后 worker 诊断](../../../../packages/bundle/web-app/tests/univer-generation.perf.ts)在 Linux x64 Node 24.14.0 下顺序运行，每次执行使用新的私有缓存，每种格式取三个样本。工作负载为 20 段文档、含 200 个公式的 200 × 8 表格及三页原生文本幻灯片。每个样本包含批量写入、独立回读、导出和 ZIP 内容校验；排除模型调用、界面加载、截图和 Gateway 启动。不宣称内存或聊天端到端延迟有所改善。

| 工作负载 | 优化前样本，ms | 优化后样本，ms | 优化前/后中位数，ms |
|---|---|---|---|
| DOCX | 2974.48, 2601.43, 2634.26 | 3051.09, 2697.53, 2634.06 | 2634.26 / 2697.53 |
| XLSX | 1727.75, 1717.40, 1709.51 | 1790.01, 1746.65, 1730.58 | 1717.40 / 1746.65 |
| PPTX | 2612.56, 2622.33, 2632.11 | 2653.96, 2650.26, 2657.68 | 2622.33 / 2653.96 |

Gateway 启动耗时前后分别为 1024.59 ms 和 1020.57 ms。内容中位数增加 1–2.4%，没有证据表明 worker 加速。本次改动减少界面工作与不必要的收尾调用，不宣称引擎提速。浏览器回归断言没有 Univer 请求和窗口，独立的 Office 预览场景验证 DOCX、XLSX 和 PPTX 渲染。真实生成场景检查活动连接及未完成的 SDK 请求阻止释放、重新打开后的持久内容、成品发布及目录删除。通过延迟数据库关闭，验证同一目录中的其他文件在释放完成前无法打开或创建。已录制技能指令固定文件交付流程。
