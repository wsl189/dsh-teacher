# Agent Note: 简化 Web 产品标识

Status: implemented

[English](2026-08-22-simplify-web-product-identity.md) | 中文

## 问题

Web 客户端把三项发布阶段限定长期呈现为产品界面：侧栏回退名称是 `DSH Local Build`，每个空会话都带本地化的「预览版」徽标，首次启动还会在提供方配置之前用版本化内测声明阻塞用户。徽标原本用于让所有预发布部署披露同一生命周期状态，确认字段则让修订后的声明再次出现，但二者都不提供产品能力。强制声明增加启动阻力；更早的遥测型内测提示同样不适合恢复，因为会话遥测只会在部署方显式开启后运行。

## 决策

展开侧栏的回退字标为 `DSH`，可选的构建修订徽标仍显示在旁边。空会话主视觉保留鱼形标记与本地化标题，但不再包含生命周期徽标、locale 键或徽标样式。

组装后的产品不注册内测声明。`ui-settings-models` 只保留按条件显示的 DeepSeek 凭据引导步骤。声明组件、文案、确认 store、聚焦测试、远程浏览器场景和版本 golden 均不存在。

确认机制随声明一起移除。`ui-settings-general` 不再注册 Host 侧设置，`ui-onboarding.welcomeNoticeVersion` 不作为产品偏好暴露或接受，Web 测试 scaffold 也不再预先确认启动声明。本仓库处于预发布阶段，不为未使用的设置分节保留兼容垫片。

可复用的 `settings.onboarding` 协调器与弹窗仍保留，因为提供方引导继续使用它们。重新引入产品生命周期披露需要新的产品决策、可见行为覆盖，以及由新内容证明必要的完成机制；已移除的确认字段不保留给未来复用。

## 曾考虑的替代方案

**保留徽标但允许配置。** 不采用：发布身份不是部署可调项，而当前要求的产品标识不包含预览限定。

**改写内测声明。** 不采用：阻塞步骤本身就是摩擦；移除生命周期警告之后，已经没有必须强制展示的命题。

**停止注册声明，但保留代码与设置字段。** 不采用：闲置组件、持久化 schema、测试开关与兼容处理会让一个不受支持的功能继续等待被意外恢复。

**保留 `ui-onboarding` 以便旧设置文档继续加载。** 不采用：仓库对预发布格式没有兼容承诺；接受一个无所有者的 namespace 会无限期保留死状态。

## 后果

新会话只呈现 DSH 名称与标题，不带预览或内测定位。没有可用提供方的用户仍会看到 API 密钥设置弹窗，其他用户则无需确认生命周期声明即可进入应用。产品放弃自动预览披露和按版本触发的重新确认；未来任何披露都必须证明当前需求，而不能直接恢复已删除机制。

## 测试

侧栏与会话组件测试固定回退字标和无徽标主视觉。组装后的首次启动浏览器场景直接从 DeepSeek 凭据弹窗开始，并保留只写 secret、已配置重载和无空接管层检查。仓库搜索与 fixture 清单检查固定已移除声明文案和 golden 的缺席。
