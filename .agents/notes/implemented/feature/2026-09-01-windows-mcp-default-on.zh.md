# Agent Note: 默认开启内置 Windows 桌面控制

Status: implemented

[English](2026-09-01-windows-mcp-default-on.md) | 中文

## 问题

安装即用的桌面控制要求内置运行时无需额外启用步骤即可启动。部署默认值仍然必须尊重用户已保存的关闭选择，也不能在未提供运行时的部署中启动 Windows 进程。

## 决策

本记录只取代[内置集成记录](2026-08-31-bundled-windows-mcp.zh.md)中默认关闭的启用决策。原记录继续拥有运行时发行、许可与 Loader 生命周期；[按会话控制的 Full access](2026-09-01-windows-mcp-full-access.zh.md)拥有工具可见性与批准规则。

插件的 `enabled` 默认值为 true。发行 Web profile 根据 `DSH_WINDOWS_MCP_COMMAND` 是否为非空白命令设置组合默认值，安装版桌面启动器只为受信任载荷提供该命令。没有命令的部署保持关闭。设置提供方把已保存的用户值合并在组合默认值之上，因此显式 `enabled: false` 会在插件重新挂载和后续启动后继续生效。现有设置卡片无需重启 DSH 即可关闭或重新开启子进程。

启用不会修改会话权限预设。受限会话仍需桌面操作批准，且不能调用系统工具；Full access 按现有策略开放固定工具目录。默认启用和 Full access 都不会提供管理员令牌或 UAC 豁免。

## 考虑过的替代方案

**保留默认关闭。** 这保留了显式首次启用步骤，但不满足安装即用的默认行为要求。

**无条件启用所有 Web 部署。** 没有私有运行时的部署会显示已开启却无法使用的能力，并输出启动诊断。

**覆盖已保存的关闭值。** 重启或升级后重新启用会丢弃用户的主动选择。只有未设置的值才会继承新默认值。

## 后果

- 运行时可用时，默认会增加一个 Python 子进程以及会话获准使用的工具 schema。关闭会移除二者；权限变化仍限制在各自会话内。
- 真实 Loader 测试覆盖省略启用值、显式关闭、运行时缺失，以及重新挂载后保留已保存关闭值。发行 Web 组合覆盖运行时存在和缺失的默认值，以及 Host 重新启动后保留关闭值。
- 无需密钥的会话快照省略显式 `enabled` 值挂载插件，并回放 Full access、受限调用与实时降级。Windows UI Automation 和打包后的 Python 可执行文件仍需 Windows workflow 的冒烟测试验证。
