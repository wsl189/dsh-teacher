# Agent Note: SQLite 典例收集

Status: implemented

[English](2026-09-08-example-collection.md) | 中文

## 问题

教师需要收集独立题目与解析及其原件、识别后的 Word 文本、可复用标签和描述，并在无需浏览试题切割层级的情况下找到它们。仅存于浏览器的文件会在刷新后消失，迟到的 OCR 结果也可能覆盖替换后的原件或恢复已删除的题目。

## 决策

教师工作台 Host 拥有独立的 `teacher_example_collection` 存储域。Web bundle 通过既有 SQLite 后端将其路由到 Harness 主目录下的 `teacher-workbench/examples.sqlite`。域版本 2 要求每道题包含独立的 `question` 和 `explanation` 文档记录。每份文档拥有源文件标识、字节、OCR 状态及 Word 修订号。请求显式选择一份文档；替换仅修改该文档，删除则在同一条记录提交中移除两组文件。可复用标签有独立目录。创建预设仅修改该目录，下拉选项行仅修改当前题目，因此添加共用预设不会将其分配给任何题目。预设行以勾选图标表示选中，悬停或键盘聚焦时显示独立删除操作。删除预设仅修改目录，已分配的标签仍保留在题目上。更新时可保留这些既有标签，但每个新分配的标签都必须存在于当前预设中。标签颜色按名称确定，在编辑区与搜索结果中保持一致。编辑区标签在悬停或键盘聚焦时显示取消按钮，触屏设备始终显示；取消时保留共用预设。保存期间通过 `aria-disabled` 阻止再次切换，同时保留焦点，因此选择标签不会收起下拉框。外部点击、焦点移出选择框及 Escape 可收起。目录读取不包含文件字节，预览仅请求所选文件。

一次上传是同一道题或解析的非空、有序片段集合。多个文件在原件提交前合成为一个 PDF：复制 PDF 页面，完整嵌入图片像素且不添加页边距，并对整次操作检查输入与输出字节限制。任一片段无效都会拒绝整批，保留旧 Word。单个合成原件保留既有持久化文档格式，为 OCR 提供统一资源命名空间，也让一个校对子 agent 能结合全部页面处理连续内容。逐片校对后拼接 Word 会丢失裁切处句子、公式和选项的上下文。子 agent 接收明确的连续页面标记，必须保留全部实质原文；题头识别检查每个段落开头的来源元数据，并保留跨页的小问和解答步骤。原件预览使用内置 PDF.js 渲染器按顺序显示所有页面。内嵌浏览器中的原生 PDF iframe 即使读取有效文件也可能保持空白。预览释放每页画布和文档读取器，在替换或关闭后忽略迟到结果，渲染失败时提供重试；下载保留已保存的 PDF 字节。

Host 串行执行元数据修改，并在 OCR 前保存原件。识别使用既有 OCR 服务并遵循 Host 生命周期取消，通过独立的工具模型子 agent 对照原件校对返回文本，从通过验证的结果生成 DOCX，仅在源文件标识仍匹配时提交。识别按题目标识和文档类型去重，因此两份文档可并发识别。完成时保留当前元数据及另一份文档、拒绝截断输出，并在失败后保留原件及已有 Word。浏览器在目录和模块导航期间保留待保存的描述草稿，仅在对应保存成功后移除草稿。

重命名不改变数字目录顺序。搜索组合已保存的标签和文字描述；已存归一化笔迹只读展示，不会被识别成可搜索文字。描述和搜索共用既有语音 Consumer。聚焦的输入框与对应麦克风按钮共用录音器，长按空格 500 毫秒启动，短按在当前选区插入一个空格。输入法选词、带修饰键的快捷键、其他输入框和未聚焦的对话输入区不会接管该手势。松键、失焦、页面隐藏和卸载会结束或取消长按；权限在松键后才返回时也不会留下持续录音。描述编辑在 500 毫秒后、失焦或切换目录时保存，保留的失败草稿通过重试重新提交。搜索转写仅替换查询，等待提交搜索。采集失败通知区分权限拒绝、找不到输入设备、设备启动失败及不支持录音要求。目录、搜索和批注操作不增加模型可见输入或会话事件。校对输入、图片附件与结果使用普通子 agent 会话日志记录。

校对后的 TeX 括号分隔符会在代码、链接、插图及既有公式之外规范化，完整规范化结果仍需通过文本长度限制。Markdown 公式解析识别由美元符号分隔的完整表达式。KaTeX 提供 MathML，mathml2omml 将其转换为原生 Office 公式，保留 Word 中的可编辑性。相同 MathML 存于 DOCX 自定义属性 `dsh.example.mathml`；浏览器预览净化后渲染它，因为 docx-preview 会遗漏重音符号及组合上下标。此属性仅属于收集功能生成的文档；编辑接口接受结构化段落，不接受浏览器提交任意 Word XML。新生成文件、已存文件读取与导出共用 DOCX 字体规范化，因此浏览器 CSS 不会掩盖下载文件的格式差异。正文使用 12 磅宋体/Times New Roman，公式使用 Cambria Math；移除 OCR 标题强调，同时保留表达数学含义的强调格式。转换器产生的无效正体样式会修正为 OMML 普通样式，公式文本属性遵循 schema 顺序。公式中的粗体小写拉丁字母和希腊字母在两种表示中统一使用粗斜体；仅从已存 MathML 重建受影响的公式，替换前要求公式数量一致且文本不变。OMML 粗斜体文本块不启用普通文本模式，使 Word 使用数学字形；浏览器预览应用相应字重。字体规范化还会重建支持的纯文本公式，仅在字节变化时提交派生产物，无需 OCR，也不修改题目元数据。不支持的 TeX 保持可见，供后续修正。

典例收集显式请求 OCR 图片资源。MinerU 返回有界的图片 data URL，Markdown 目标仅从这些返回字节解析。Word 写入器将插图解码为保持比例的嵌入 PNG。打印尺寸上限独立于 OCR 分辨率：规范化同时缩放绘图范围与图片变换，包括已编辑段落内的图片，同时保留媒体像素和文字格式。读取或导出含未解析引用的已有文件前，会从已存原件补图；补回的资源仅替换匹配的图片标记，保留原文和原生公式。仅补图时跳过校对以保留已存文本；完整重新校对会等待正在进行的补图，再启动自己的 OCR 与子 agent。识别流程负责并发补图去重，并在原件替换或题目删除后拒绝迟到提交。补图失败会保留旧 Word 供重试。编译器通过 docx 重新注册每张图片，在保留媒体字节与尺寸的同时分配输出引用；仅复制绘图 XML 会留下断开的引用或引用冲突。

搜索选择仅存于浏览器，限于可见且已生成题目 Word 的结果。导出按请求顺序取得已提交记录，并逐题放置解析或在新页集中附上解析。导出仅包含题目与解析原文，不添加标题、编号、标签或描述。未上传的解析会省略；记录缺失或已上传文档尚未完成识别时，整次操作失败。编译器接受收集功能生成的段落，裁去首尾空白，通过既有 docx 适配器导入 XML 和原生公式，并按同一顺序合并预览 MathML。相邻题目块与集中排列的相邻解析之间保留两个单倍行距空白段落；解析附录另起一页且不增加页首空行。完成必要的插图恢复和题头识别后，完整且已完成判定的文档合并不写入存储，也不调用模型或 OCR。

每个校对子 agent 都属于工作台自有的隐藏父 agent，独立于当前选中的对话。其目标是准确转写并匹配原件，绝不改写、解题或修正题目与解析原件中印出的错误。它接收完整 MinerU Markdown 与全部原始页面，使用支持图片输入的工具模型路由，并返回结构化最终 Markdown。配置的完整文本、页数、附件、栅格与时长限制会拒绝不完整处理；插图引用被改变时拒绝替换。

另一个全新的 spawn 子 agent 根据全部原始页面与精确的 Word 文本投影识别题头元数据，不接收父对话，只返回段落序号和该段开头精确复制的题头前缀。原生公式以带标记的原子形式提供；Host 在删除节点前验证前缀一致性、公式边界、实质正文保留及图片保留，并从预览 MathML 中移除题头公式对应的节点。文档在 `dsh.example.headingReviewed` 中记录版本 2 的完成状态，包括无题头判定；旧版记录会重新检查后续段落题头。首次读取或导出未标记的已有文件时执行识别，无需 OCR；后续预览、下载及两种导出形式复用处理后的字节。既有逐文档识别流程负责去重、等待取消结束，并在提交前检查原件标识和 Word 修订号。失败时保留已存 Word 字节与元数据。

教材排版使用明确的西文字体文本段，避免 Word 将相邻拉丁字母分配到中文字体。正文变量为斜体，段内明确声明的小写向量为粗斜体，数字、函数名与选项编号为正体。子 agent 保留原图的段落分组、选项行与插图顺序，并将数学符号输出为 TeX。Word 原生制表位将完整 A–D 选项序列与题干分开对齐；选项内部使用空格，使编号紧邻公式。选项前的独立答题括号并入前一段题干，正文使用 1.25 倍行距。插图位于所属来源的全部文字和选项之后，以专用图片段落靠右对齐。合并前按来源归组导入和补回的插图，图片段落样式在后续规范化时保留其位置。已存公式及媒体字节保持完整。浏览器将这些制表位投影为响应式列，因为固定页面坐标无法适应所有预览宽度。共用规范化保留来源的非空白字符，重复执行不产生变化，且无需 OCR。Markdown 空行不生成空段落，题间两行空白由导出编译器负责。Word 测试覆盖文本段样式、原文、选项排列、编译时的原生公式及幂等性；Client 与组装 Web 测试覆盖选项单元和预览资源释放。

项目所有者授权按 LGPL-3.0-or-later 发行 mathml2omml 0.5.0。转换器保持为独立的 Node 模块，用户可以替换接口兼容的修改版，无需应用签名密钥。[发行资料包](../../../../packages/host/teacher-workbench/third-party/mathml2omml/NOTICE.txt)随附完整 GPL 和 LGPL 文本、未修改的上游源码与构建配置、内含的 entities 源码、依赖许可声明以及重建和替换说明。许可声明生成器固定已审核的包标识、版本、许可、源码归档和许可文件；工作区清单检查要求发行文件列表包含该资料包，桌面安装包检查会拒绝缺失运行库或资料包的产物。这项限定版本的决定不授权无关的 copyleft 依赖，也不将 LGPL 归为宽松许可。

展开后的 Word 窗口使用 Tiptap 编辑文字和段落，用本地内嵌字体的 MathLive 公式编辑器输入数学公式。工作台词典提供补充菜单翻译，并在对话框打开时指定 MathLive 语言；关闭后恢复共享语言设置。React 面板在对话框内呈现高中数学符号，通过 MathLive 在保留的选区插入 LaTeX，支持包含选中文字和占位符的模板，不使用全局虚拟键盘容器。字体样式菜单使用本地化文字标签，加粗切换保留当前字体类别并区分正体与数学斜体。常用帽子一行排在罗马数字后方。空选区插入帽子时选中普通可编辑字母，因为 MathLive 0.110 无法进入帽子内部的占位符。斜线平行符号使用文本原子中的紧凑双斜线字形（U+2AFD），在 MathML 与 Office 公式中保留比例；对话框在应用编辑前，将 MathLive 对应的 `\sslash` 命令转换为该文本原子。菜单可插入带可编辑占位符的两行方程组模板。公式转换把单侧矩阵前的普通大括号转换为可伸展的 Office 定界符，内部各行左对齐；修改公式整体粗体时也使用同一转换。MathLive 的选区、当前结构、文本模式、括号和光标颜色通过公开 CSS 变量使用已解析的工作台主题令牌；其默认系统深色样式可能与明确选用浅色的工作台冲突。菜单排除剪贴板和全选命令，相关键盘快捷键仍可使用。应用公式使用与 Word 写入器相同的 KaTeX，并以完整 MathML 元素进行安全清理；独立的 MathML 片段在按 HTML 解析时会丢失数学命名空间。公式通过 KaTeX HTML、本地内嵌字体和 SVG 根号显示，另行保留供辅助技术读取的 MathML。导入的 DOCX 样式使用隐式 CSS 作用域，以所在预览容器为根，在已渲染的公式前终止；文档 span 的字体、最小高度和透明 SVG 填充不会覆盖 KaTeX，同时显示的文档也不会互相覆盖样式。编号计数器在该作用域根上重置。已保存的 MathML 先序列化为 XML，再通过与 Word 编辑器相同的转换器提供规范化 TeX，保留不换行空格字符，不将其变成 HTML 实体名称；无法转换时保留原生 MathML 显示。整条公式的粗体使用结构化编辑中的独立布尔值及预览外层字重，保留 MathML 内部的强调格式。改变该字重时，从保留的 MathML 重建原生公式，应用 Office 数学样式和控件属性并保留字号；未改动的公式保留原始 XML。不支持的公式在替换前被拒绝。工具栏支持字体、字号、加粗、斜体、下划线、对齐、行距、缩进、撤销和重做。中文字号标签映射为数字磅值；编辑器接受 5 至 96 磅的文字和公式，保存 Word 及合并导出时保留字号。字体框按选中字符读取 Word 的中西文字体字段，明确显示混合字体；光标处依据相邻字符类型和待输入文字格式显示字体。编辑器字体扩展在 CSS 中提供中西文字体，并按与字体框相同的字符分类规则生成中文范围的行内装饰，直接指定中文字体；即使西文字体也包含汉字，仍保持中文的字形和行高。这些装饰随文档变更更新，不进入保存内容。HTML 元数据在富文本复制时保留两个原始字体名称，不将 CSS 字体列表保存为单个 Word 字体名称。保存及 Ctrl/Cmd+S 提交结构化段落；关闭时可保存或放弃。已保存文档可从预览卡片下载。Host 依据原件标识与 Word 修订号拒绝过期保存，编辑后的段落保留用户格式，后续预览、下载及两种合并导出不会重置它。未改动的原生公式和图片保留原始 XML 或媒体；修改的公式转换为原生 Office 公式并同步预览 MathML。自动校对仍不得改写题目，手动编辑不调用模型。

公式颜色已保留在预览 MathML 中；mathml2omml 0.5.0 会计算颜色分组，但没有输出原生颜色属性。固定依赖补丁将继承的颜色与背景写入原生文字和结构控制属性，不改变公式转换过程。对应源码补丁与上游源码、替换说明一同分发，并由分发摘要和桌面产物检查覆盖。另一个固定依赖补丁为 mathml-to-latex 1.8.0 增加前景色和背景色包装，使用 color-string 规范化 CSS 颜色，使已存预览和重新打开的公式保留这些范围。Host 在转换前规范化不透明命名色、十六进制色和 RGB 色，并修复预览有颜色而原生 Word 缺色的已保存公式，同时保留公式字号、粗体和段落格式。

固定版本的 KaTeX 补丁将 MathLive 的 `\mathbfit` 识别为字体命令，避免整条表达式别名到 `\boldsymbol` 时生成标记元素包裹整行的 MathML。MathML 转 LaTeX 对粗斜体输出 `\mathbfit`，保留数字、运算符的字体变体，并读取旧版标记元素中的行；预览在安全清理前将这些无效包装替换为行。编辑器通过共用的原生公式写入器直接转换完整 TeX，不经过 Markdown 或临时 DOCX。背景色命令可包含文本模式内的数学分隔符，必须保留为一条公式。回归覆盖从菜单加粗坐标表达式、保存、重新打开、继续编辑和导出；无效命令仍会失败。

## 考虑过的替代方案

**将文件嵌入版本化工作台单例。** 每次班级、课程表或日常任务修改都会重新传输和写入无关题目文件。收集功能没有需要共同提交的名册或课程表引用。[工作台决策](2026-08-17-durable-teacher-workbench.zh.md) 仍然定义相互关联的教学记录。

**用正则表达式识别题头或重写整道题。** 题头格式多样，日期和括号内容也可能是实质条件。视觉识别只选择精确的开头前缀，Host 保留正文，不要求题头子 agent 重新输出正文。

**将原件和生成文件存于 SQLite 之外。** 文件删除和元数据删除需要跨介质清理及恢复。单条记录通过既有后端，原子地保存用户要求的原件、生成文档和元数据。

**仅保存识别文本，每次预览重新生成 Word。** 预览和下载无法读取同一份已保存产物，OCR 成功后仍然依赖后续转换可用性。持久化 DOCX 使重启后的预览和下载保持一致。

**将插图保留为外部引用。** MinerU 相对路径不是浏览器路由，下载的 Word 也不能依赖解析器临时文件。嵌入媒体使插图与生成文档归属同一 SQLite 记录及删除操作。

**将公式渲染为图片。** 图片无法通过 Word 原生公式编辑器修改。[KaTeX](https://katex.org/docs/options) 与 [mathml2omml](https://github.com/fiduswriter/mathml2omml) 库负责数学解析和转换；收集功能不自行维护 TeX 语法或 Office 公式转换器。

## 后果

题目在浏览器和 Host 重启后仍然存在，迟到的 OCR 不能恢复已删除数据。手写内容按原样保存，不承诺手写识别。Word 公式保持可编辑，不支持的 TeX 和 Markdown 表格仍为文本。存储域实现在 Host 内存中保留记录，因此即使浏览器目录读取不包含文件，大型收集库仍可能占用较多内存。

## 测试
