# Agent Note: 有界并行切题

Status: implemented

[English](2026-08-26-bounded-parallel-question-cutting.md) | 中文

> 候选默认成题的紧凑题界协议已由 [Agent 自主发现题界](../architecture/2026-09-03-agent-owned-question-boundary-discovery.zh.md) 取代。有界分组、并发、紧凑阶段图片自动归属、输出预算与降级行为仍然有效。

## 问题

试题分割由相互独立的语义页组拥有，但串行题界检测和串行视觉复核会让总延迟随分组数增长，即使不同分组并不共享可变题目归属。模型已经检查完整图片集合后，如果还要为每道裁剪各提交一次分类工具调用，裁剪复核也会形成很长的 agent loop（智能体循环）。

共享的归一化裁剪宽度比例不能保证完全相同的栅格宽度。PDF 各页的渲染视口只要相差一个或多个像素，取整后的目标宽度就会不同，因此同一份试卷的图片即使使用相同语义栏宽比例，也可能违反等宽要求。

## 决策

一个语义组默认最多拥有 20 个所选页面和 300 个可疑题头候选，同时不拆分单个异常高密度页面。题界检测通过可配置的 `questionSegmentationConcurrency` 上限处理归属相互独立的分组，默认值为二。浏览器与普通对话视觉复核采用同一个下发上限。同组内的重切尝试保持串行，因为每次尝试都要使用上一次返回的几何与缺陷。紧凑来源页图表保留五张可读标注页，裁剪图表保持复核宽度并按真实高度最多紧排九道题；组合图表数量不超过图片接纳限制的分组因此只用一次工具往返就能检查全部来源页和裁剪。

共享的零依赖 `mapConcurrently` 原语按分组索引顺序合并结果。任一分组失败后，它会停止接收新分组，等待全部在途分组结算，再返回来源顺序中的失败。最终渲染与追加保存仍按来源顺序执行，因此并发不会打乱题号或持久化图片。浏览器 bundle 可以内联这个不携带运行时身份的工具；Host 消费方通过工作区包依赖使用它。

当一个有界 OCR 分块能够容纳整个语义组时，Host 会把聚焦后的来源证据放进题界子 agent 的初始请求。该证据保留全部不确定题头、具有代表性的已接受题头和每页边缘元素，再按来源顺序扩展相邻 OCR 上下文，直到 `maxQuestionCompactBoundaryCharacters` 上限；Web 默认值为 24,000 字符。Host 通过通用作答要求与几何证据接受高置信度题头，其中包括具有独立作答要求的带括号或无括号“题 N 变式 N”“变式 N”、例题与示例标签，再把 `unprotectedQuestionHeadIds` 作为准确的剩余分类集合公开。子 agent 只返回误报判定、缺失题头、归属例外或停止位置例外，无需重新识别默认值或消耗来源工具轮次。显式停止位置只让覆盖范围包含一个来源元素时，除非该题头具有可见作答要求证据，否则 Host 会拒绝该覆盖。这个紧凑子 agent 会关闭推理强度，并拥有可配置的 32,768 token 输出上限。超过一个来源分块的分组仍使用渐进来源与页面预览工具协议和所选模型配置项的输出策略。

确定性保护还会识别组合例题变式标签、明确的多问要求、指定数学输出，以及“=.”等仅由标点构成的作答空位。这些来源信号能防止可独立作答的题头被子 agent 误判为非题目，同时不编码文档坐标或标题。

图片分类与题头分类采用相同的学习者页面范围。答案区页面的图片仍作为语义停止上下文，但不会作为归属候选公开，也不是边界提交或确定性降级必须处理的对象。这项对称规则避免仅属于解析的图阻止其他有效题目集合通过。

视觉工具默认每次最多返回 20 张图片，同时受附件提供方更低上限约束。紧凑复核把全部标注来源页图表和渲染裁剪图表放进这项接纳上限，并要求子 agent 在一次调用中请求每个列出的图表 id。随后它提交一份完整分类：`verifiedCropIds` 必须覆盖每张合格裁剪，只有该清单覆盖全部请求裁剪时才可省略 `findings`。每条缺陷都要在 `issue` 中点名可见证明像素，声明全部适用的 `repairIntents`，并可另加 `evidence`。Host 会拒绝不完整的图片检查、部分或矛盾的裁剪覆盖、没有可见题头的整题缺失，以及与所提交修正不一致的修复意图。只有完整分类记录缺陷后，才能检查 OCR 并执行局部重切。

紧凑视觉复核与修复子 agent 的可配置输出上限为 32,768 个 token。每个新鲜的边界、视觉复核与修复子 agent 都获得独立的 50 秒 Web 截止时间，因此前一个子 agent 的来源检查不会消耗后一个子 agent 的修正时间。三次相同的被拒工具结果会停止当前子 agent。边界超时、模型错误、缺少已接受草稿或边界视觉不可用时，会回退到 Host 的通用作答要求候选并继续视觉复核。视觉复核超时、模型错误、无效输出、服务不可用或资源释放失败时，会把当前几何保留为未解决结果。调用方会立即把该分组标记为未验证，不再让同一份未变化证据消耗另一段完整复核截止时间。确认不含学习者试题的所选范围会正常完成，不创建空试卷批次。

局部裁剪复核页面会用灰色遮罩覆盖不包含任何已列出裁剪区域的横向栏。遮罩中的像素不能作为内容、续文、选项、图形缺失或污染的证据。复核栏内未列出的题目继续作为只读边界上下文可见；没有已列出区域的相邻页面不加遮罩，以便继续核对跨页续文。

当续题页包含多道已接受的同页题目时，栏位重分配会让页首选项、小问或具有作答要求的元素继续归属于前一页的顺序所有者。下一道已接受题头或语义边界仍是停止位置，从而同时避免续题缺失和误收下一题。

耗尽单个分组的重切次数或收到未解决复核属于质量结果，而不是操作失败。调用方保留最近一次通过 Host 校验的区域，把该分组标记为未复核通过，并继续按顺序渲染和持久化整份 PDF。只有明确返回了修订结果才会消耗下一次局部重切。浏览器进度和普通对话工具结果都会报告未复核通过的分组数量。Web 组合包的正常 MinerU 版面请求最多发送五页；失败的多页请求会递归二分，使提供方峰值显存故障可以通过更小批次恢复。只有单页失败、渲染、取消或持久化错误仍会让操作失败。

两种栅格实现都会根据最宽的所选 PDF 页面视口和已校验的整卷安全栏宽比例计算唯一目标像素宽度。复核修正可以扩大该比例，但不能缩窄已规划的安全栏。同卷每道题的画布都使用这个精确宽度。每个来源切片仍只采样到自身 `rightLimit`；剩余部分填充为白色，因此精确等宽不会引入相邻栏像素。

## 考虑过的替代方案

**让全部分组保持串行。** 实现更简单，但会依次承担相互独立的模型延迟，页数增长后无法满足交互式吞吐量。

**不设上限地运行全部分组。** 无界的模型、附件、PDF 渲染和内存需求可能压垮本地提供方或浏览器。显式上限为题界与复核 agent 提供一个统一的部署负载控制项。

**每次工具调用提交一道裁剪分类。** 增量记录会缩小单次参数，但相同图片已经进入上下文后，它仍为每道裁剪增加一次模型轮次。一次经过 Host 校验的完整提交可以保留逐题证据，又不会重复切换 agent loop。

**配置固定的图片像素宽度。** 部署专用像素宽度会放大窄页或截断宽页，并忽略所选渲染比例。根据当前 PDF 推导唯一宽度可以同时保留来源分辨率和等宽输出。

**一个分组未复核通过时让整份 PDF 失败。** 这种处理会阻止用户取得其他全部已接受分组，并丢弃最近一次安全输出，而视觉复核意见未收敛并不是渲染或持久化失败。保留该分组并显示明确警告，可以保存可恢复工作并标出需要人工检查的范围。

## 后果

- 独立分组 agent 会在配置上限内竞争模型提供方容量、附件处理和 PDF 解码资源。本地模型资源受限的部署可以调低 `questionSegmentationConcurrency`，而不改变题目归属或校验。
- 更大的默认分组与图片读取量减少模型往返，但单组可以携带更多 OCR 与视觉证据。现有页面、候选、图片、元素、字符和墙钟时间上限仍然有效。
- 紧凑题界与复核子 agent 预留 32,768 token 的任务配额，使模型在检查有界证据后仍能完成 Host 提交。只有所选模型能够在更小配额内稳定提交时，部署才可降低这两项紧凑输出设置。
- 完整裁剪分类参数比单条增量记录更大。其数组仍受分组候选上限约束，覆盖不完整的提交不会开放 OCR 修正。
- 精确共享栅格宽度可能给来自较窄页面的题目增加白色区域。该补白不会扩大来源采样。
- 未复核通过的分组可能包含不理想的裁剪。明确显示其数量后，用户可以只检查这些分组，而不会丢失已接受分组或最近一次安全边界修正。

## 测试

Host 测试证明题界 agent 并发上限、来源顺序合并、失败后停止接收新任务、在途任务完全停稳、准确的未保护候选分类、聚焦来源字符预算、拒绝没有依据的单元素覆盖、紧凑输出覆盖、确定性题界回退、重复拒绝终止、版面失败批次二分、全部图表一次接纳、安全省略空缺陷数组、无关栏像素遮罩和复核耗尽后的结果保留。浏览器控制器测试证明独立复核会重叠运行、未解决输出会在一次复核后保存、零题范围不创建批次也能完成、未复核通过的分组会被报告，而最终保存仍然有序。浏览器栅格测试使用不同的 PDF 视口宽度，并要求图片字节元数据宽度完全相同。组装后的 Web 试题分割快照固定只接受批量提交的缺陷 schema 与遮栏证据规则。

答案区图片 fixture 要求直接提交的纯答案分组和学习者题目的确定性降级都能完成，且不把解析图归属给试题。
