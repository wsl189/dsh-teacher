# Agent Note: 试题切割工作台

Status: implemented

[English](2026-08-19-question-segmentation-workbench.md) | 中文

> 本决策扩展[持久化教师工作台](2026-08-17-durable-teacher-workbench.zh.md)与[可复用文档提取](2026-08-18-reusable-document-extraction.zh.md)。两者对存储和 OCR 的所有权保持不变；本决策增加结构化版面提取与第七个工作台模块。

## 问题

教师需要把 PDF 试卷转换为持久化的逐题图片，复核这些图片，把它们复用于可打印材料，并向名册中的学生分发独立副本。参考切题应用已经展示了该工作流，但它是一个具有自身文件系统假设的独立系统，还包含不在本次 dsh 模块范围内的错题分析、试题搜索与 LLM 二次筛选。

现有共享 OCR 能力返回阅读顺序 Markdown。Markdown 足以支持对话与校历导入，但不能可靠地把识别到的题号映射回源页面像素。版本 4 教师工作台文档也没有试卷批次与学生副本的标识或关系；如果把大型 base64 图片放入整份文档的 compare-and-set 状态，每次无关编辑都会重写整个媒体库。

## 决策

[`@deepseek-ai/dsh-ocr`](../../../../packages/ocr/ocr) 增加提供方无关的结构化版面类型与 Typert `ocr.layout` Remote。请求携带普通文档元数据与字节，以及可选的从零开始且首尾均包含的页码范围。成功结果包含按顺序排列且具有源索引与尺寸的页面；每个归一化元素包含内容类别、阅读顺序文本，以及页面坐标系中的 `[左, 上, 右, 下]` 边界框。每个已注册提供方都实现 Markdown 与版面提取，因此提供方选择与稳定错误处理仍由同一个运行时拥有。

[`@deepseek-ai/dsh-ocr-mineru`](../../../../packages/ocr/ocr-mineru) 通过请求 `return_middle_json=true`、关闭不必要的返回产物，并把页码范围转发为 `start_page_id` 与 `end_page_id` 来实现新路径。它校验完整响应、解析 `pdf_info`、把相对于所选范围的 `page_idx` 映射回源文档索引、保留 `page_size`，并归一化可用文本行、span 和非文本块的几何信息，而不暴露 MinerU 供应商 JSON。现有端点、后端、混合解析质量、语言、超时、上传上限与响应上限继续来自普通 `ocr-mineru` DSH 设置命名空间。

[`@deepseek-ai/dsh-client-ui-teacher-workbench`](../../../../packages/client/ui-teacher-workbench) 在侧边栏折叠区与主界面增加试题切割。模块界面移植参考应用的顶部栏、当前年份/班级层级、叠层试题库与学生抽屉、页码选择顶层面板、图片编辑器和班级输出流程。班级层级只读取名册目录持有的班级，因此普通课表与年级课表班级无法进入该工作流。移植后的应用外壳全部映射到 DSH 设计令牌，使浅色与深色外观都保持协调；只有文档像素有意保留白色画布。模块同时有意移除原来中间的错题分析与图片搜索工作区。双击班级会打开学生抽屉。学生与目录行在 260 毫秒内聚合点击：单击切换该行图片，双击展开或收起下级目录，三击打开持久化子目录的新建界面。学生行汇总该学生根目录与所有子目录中的已分发图片，目录行则把图片抽屉限制在该目录。固定在两侧的行操作不会挤偏学生与目录名称。学生图片与试题库互斥，因此打开任一方都会先收起另一方再显示自己的抽屉。选择批次会在试题库目录旁展开其图片，再次选择当前批次会收起其图片抽屉，关闭班级抽屉时则先收起其子图片抽屉。浏览器支持留空表示全部页，以及 `1-5,8` 这类逗号分隔页码语法；它把所选 PDF 与覆盖所选页的范围发送给 `ocr.layout`，在相近左侧位置选择单调递增的顶层阿拉伯数字题号序列，把每个题号到下一题号之间的区间转换为一个或多个页面区域，并只保留明确选择的页面。PDF.js 按已配置倍率从浏览器中保留的原 PDF 栅格化这些区域，纵向拼接跨页区域，并自动持久化批次。持久图片库支持预览、选择、框选擦除、旋转、另存为、覆盖保存和删除。从顶部栏打开试题库时，所选图片会用防重名文件名写入浏览器选定的目录；从学生或目录打开时，所选图片则直接分发到该目标。“技能库”的 Office 操作会打开浏览器目录选择器，对图片进行自然排序，生成一份以目录命名的文件，并显示保存或重试。班级抽屉分别提供 Word 与 PowerPoint：Word 保留逐学生标题、姓名、日期行和批量控制，PowerPoint 直接开始生成；两者都会为每名符合条件的学生返回一份独立产物。保存班级输出时会选择一个目标目录，并用防重名文件名把全部产物写入其中。

[`@deepseek-ai/dsh-host-teacher-workbench`](../../../../packages/host/teacher-workbench) 拥有媒体持久化与文档生成。版本 6 在带修订号的 domain 文档中包含试卷批次、嵌套学生目录与分发元数据，并要求其学生属于名册班级；PNG、JPEG 与 WebP 字节则位于已配置文件系统根目录下。目录图拒绝未知所有者、跨学生父目录、循环与同级重名。批次写入使用生成的不透明 id、路径包含关系检查、解码字节上限、临时兄弟目录与原子重命名。分发内容是在经过清理的学年、组合年级/班级、学生和所选嵌套目录名下创建的独立副本。目录删除会级联移除后代与其中的分发副本；移除班级和学生也会删除从属目录与分发记录。专用 Remote 负责读取或替换一张经过校验的图片、保存或删除批次、分发所选图片、从已存目标生成、直接从临时目录上传生成，以及返回带跳过列表的逐学生独立 Word 或 PowerPoint 产物。Word 使用四边 2 厘米的 A4 页面、可选居中 16 磅加粗标题、可选右对齐 9 磅姓名/日期和居中图片段落。PowerPoint 使用 13.333×7.5 英寸页面，每页一张不放大的图片，并保持参考系统左侧 0.5 厘米、顶部和右侧 1 厘米的边距，不添加标题或说明文字。

`ui-teacher-workbench` 设置命名空间增加当前学年、PDF 渲染倍率与切题边距。`TeacherClass` 可选地保留学年目录，使参考应用的多年份层级能够持久化；在该字段出现前写入的文档会回退到已配置的当前学年。Host 注册 `teacher-workbench` 设置区段，包含批次根目录、学生根目录、每图字节数和每批次字节数；[`@deepseek-ai/dsh-client-ui-settings-plugins`](../../../../packages/client/ui-settings-plugins) 在普通插件配置页中开放这些字段。Web 组合默认把存储位置设为 `~/.dsh/teacher-workbench/segments` 与 `~/.dsh/teacher-workbench/students`。本功能有意不包含试题搜索、错题分析或 LLM 二次筛选，也不增加任何模型可见提示词、工具或会话事件。

## 已考虑的替代方案

**在 dsh 内原样运行完整参考应用。** 这会保留三项明确排除的工作流，并创建第二套设置存储、持久化模型与访问策略。最终方案把其可见外壳与操作流程移植为 dsh 原生模块，同时继续使用 dsh 自有设置和持久化。

**从 Markdown 推断切图坐标。** 阅读顺序文本不保留页面尺寸或可靠源位置。字符串偏移量不能安全确定 PDF 像素边界，尤其无法处理跨页、图片与公式附近的情况。

**把 PDF 上传到第二个切题服务。** MinerU 已经接收所选文件，并能返回结构化中间表示。第二个服务会重复端点配置、上限、传输和失败行为，却没有新增独立产品需求。

**把图片字节存入带修订号的 JSON 文档。** 每次待办、课程表或名册变更都将重写完整试题库，domain 快照也会远大于其关系元数据。文件系统媒体加持久 id 能保持比较与关系校验轻量。

**使用 LLM 修复或排序检测边界。** 这会增加延迟、不确定性、提供方成本与模型可见的试卷内容。本次范围排除了二次筛选，因此不确定版面会显示确定性失败，并提供明确的重试路径。

## 后果

- 已安装的 MinerU 插件同时服务 Markdown 消费方与坐标消费方；试题模块不需要独立 OCR 端点或供应商客户端。
- 试题切图保持原 PDF 渲染的视觉质量，而不嵌入 MinerU 预览图；识别参数与切图倍率仍可分别配置。
- 已保存批次图片与学生副本可在浏览器重载后保留，并使用可读学生目录；但运维备份必须同时包含两个已配置根目录与工作台 domain 文档。
- 点击聚合保留参考应用的单击、双击与三击手势，但打开一行会等待 260 毫秒，以便组件判断预期操作。
- 确定性检测优先提供可检查行为，而不是猜测。没有清晰递增阿拉伯数字顶层题号序列的试卷可能不产生区域或得到较粗区域，需要清理源文件或改变页码选择。
- JSON base64 传输与同步 MinerU 解析会在内存中保留完整文档或图片。已配置上限限制可接受输入，但流式、断点续传、进度与浏览器取消仍延后实现。

## 测试

OCR 测试覆盖提供方分派、新 Remote、页码范围、`middle_json` 解析、元素归一化、错误页码范围与无效响应。客户端测试覆盖题号链选择、精确的逗号/区间页码语法、跨页区域、PDF 切图编排、参考顶部栏与只读取名册的层级、单击/双击/三击行为、嵌套目录创建与删除、班级/学生/试题库抽屉交互、技能库目录生成、逐学生 Word 控件、班级 PowerPoint 直接生成、模块接线、设置与既有工作台投影。Host 测试覆盖版本 6 schema 关系、原子批次持久化、嵌套分发路径、图片读取与替换、学生副本隔离、级联删除、临时上传生成、Word 页面 XML、PowerPoint 页面几何、逐学生独立产物、校验失败和重启恢复。约定类型检查、聚焦 Vitest 测试套件、Oxlint、Cordis 配置校验、生成的 Remote 产物、组合 Web 构建、DOCX/PPTX 渲染检查与幻灯片溢出测试共同守护集成边界。
