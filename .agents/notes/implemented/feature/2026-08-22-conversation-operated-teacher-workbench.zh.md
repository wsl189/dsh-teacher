# Agent Note: 对话操作教师工作台

Status: implemented

[English](2026-08-22-conversation-operated-teacher-workbench.md) | 中文

> 扩展[持久化教师工作台](2026-08-17-durable-teacher-workbench.zh.md)、[可复用文档提取](2026-08-18-reusable-document-extraction.zh.md)与 [agent loop 试题分割](2026-08-21-agent-loop-question-segmentation.zh.md)。其中的存储、OCR 与语义边界决策继续有效。

## 问题

教师工作台与普通对话原本使用两条独立的控制路径。教师可以让 agent 讨论 OCR 上传内容，但修改事项、课程表、名册、考试或试题库仍需重新打开对应工作台界面并手动重复操作。PDF 试题切割还有额外缺口：隐藏 OCR Markdown 能为父 agent 提供可读文本，却不包含渲染可信裁剪所需的原始 PDF 字节。

对话路径必须使用与手动工作台操作相同的修订检查、关系校验、级联行为、媒体存储和文档生成器。上传字节不得进入 textarea、模型提示词或会话日志，而后续工具调用仍需持久引用浏览器所选的完全相同 PDF。

## 决策

`@deepseek-ai/dsh-tool-teacher-workbench` 是 `@deepseek-ai/dsh-host-teacher-workbench` 的面向模型 Consumer，并注册七个全局工具：`teacher_workbench_read`、`teacher_question_image_read`、`teacher_daily_management`、`teacher_timetable`、`teacher_student_roster`、`teacher_score_analysis` 与 `teacher_question_workbench`。独立的 `tool-*` 包使每个 schema 都进入生成工具目录的完整性检查。板块读取工具返回一个指定板块及其稳定 id。持久附件可用时，图片读取工具会解析一张已存批次或分发栅格图，报告来源尺寸，并仅在当前模型路由声明图片输入能力后把它作为图片附件返回。修改工具操作权威修订文档，基于最新修订重试比较后写入冲突，并返回已提交修订号、简短摘要与新建 id。试题媒体、分发与 Office 生成复用现有服务操作。schema 公开明确的 action 词汇，每种 action 的载荷还会在持久化前再次校验。

日常管理支持待办、备忘录、账本分类、账目与日期事项的新增、编辑、删除、完成、改期及日历导入。其工具只按请求中的字面词路由：“备忘”或“备忘录”进入备忘录，今日或待办词以及重要或紧急词进入对应待办列表，账单或保险词进入账本操作，日历词进入日历操作。每次新建前，Host 都会读取当前 agent 轮次中的直接用户文本，独立于模型参数推导路由，并拒绝与之不匹配的 action。新条目没有路由词时不会写入，直到用户明确其去向。工具不会根据内容、截止时间、语气或后果推断列表，编辑时保留原有去向。课程表要求明确指定 `week` 或 `grade` 视图：今日、本周与早晚自习使用 `timetable` 班级目录，只有明确的年级视图使用 `gradeTimetable`。课程表修改会拒绝另一目录的班级 id 以及同一次导入中重复的班级／类型／星期／节次时段，再读回受影响 id 后返回已确认视图和修订号。学生名册支持名册班级和保留身份的学生导入。成绩分析会先把每行解析为所选名册班级中唯一的持久学生，再替换考试。试题切割支持 PDF 分割、目录和媒体删除、旋转、来源像素裁剪、以周围采样颜色消除矩形区域、分发，以及 Word 或 PowerPoint 生成。裁剪和消除只替换所选已存图片；消除最多接受 32 个正尺寸矩形，并在提交替换前校验每个边界。其中的本地目录 action 通过已挂载文件系统提供方递归读取图片，无需创建学生、目录、分发关系或临时选集即可生成一份产物。既有 schema 校验与删除级联仍是跨模块关系的最终权威。

对话文档入口继续通过已配置 OCR 提供方提取所有支持的文件，并把准入的 Markdown 作为已记录 `mineru-ocr` 上下文注入。PDF 上传还会在“发送”可用前调用 `teacherWorkbench/stageSource`。Host 校验规范 base64 与已配置解码字节上限，把字节存入私有内容寻址对象根目录，每次读取都重新校验摘要，并返回不透明 `sha256:` 来源 id。已记录文档上下文携带该 id、显示名称和媒体类型；原始字节与服务器路径都不会到达模型。

试题工具按来源 id 解析已暂存 PDF，把所选页面复制为受所选 OCR 提供方限制的请求，取得 MinerU 几何信息，在调用 agent 下启动既有受限语义边界子 agent，在 Host 从原 PDF 渲染已接受区域，并保存一个持久试卷批次。该操作没有默认目标：当前直接用户请求必须明确说出试题库根目录或一个现有叶子目录的完整路径。模型提交对应的根目录选项或持久化目录 id，Host 在 OCR 开始前将其与日志中的当前轮次文本匹配；缺少目标或自行猜测时会被拒绝，并要求先询问用户。Web 切题独立保留自动目录或所选目录行为。其 Office action 区分三种来源：普通本地目录只需文件系统路径，已存批次或分发图片使用持久目标 id，按学生生成则使用已分发或临时学生选集。省略按学生来源与 Word 元数据时遵循试题切割界面：使用临时图片、标题留空且不显示姓名和日期；全部已分发图片必须显式指定来源。每条路径都复用 Host 的图片规范化、题号／自然排序、字节上限和 Office 渲染器。输出会写入私有生成输出根目录，并返回绝对路径。打开浏览器工作台或切换当前模块都会刷新 Host 文档，使对话修改替换缓存快照。

## 已考虑的替代方案

**教 agent 模仿浏览器 Remote 调用。** 浏览器编排包含临时复核状态，并假定 UI 已挂载。模型工具需要稳定 action schema 和 Host 校验，而不是复制客户端控制流的说明。

**把五个模块都放在一个不受限制的文档替换工具后。** 完整任意状态载荷会增加 token 成本，并使一次错误调用能够删除无关数据。分板块读取和语义 action 限定每次修改，同时底层仍保留既有整份文档原子写入。

**把原始 PDF 字节放进对话上下文。** Base64 会扩大每次请求与会话日志，把私有来源字节暴露给模型提供方，并且工具执行时仍需解码和校验。已记录的不透明 id 保留可回放意图，私有 Host 存储保留字节。

**从 OCR Markdown 重建试题图片。** Markdown 不保留页面几何信息或原始像素。仍需使用既有 MinerU 版面与 Host 推导裁剪权威。

**默认保存到已配置试题库根目录。** 这种方式不会创建目录，却仍会选择用户没有要求的目标，并在根目录混合无关试卷。

**复用 Web 切题的来源同名自动目录。** 对话请求没有保存目录控件，因此从隐含界面默认值创建文件夹会增加用户未要求的层级。

**生成前先把任意图片目录暂存到某名学生下。** 这会编造用户来源并不具备的名册关系，还会使一次单文件目录转换依赖可变的分发状态。本地目录 action 保持源图片短暂存在，并在不修改工作台数据的情况下使用同一生成器。

**持续轮询工作台中的 agent 修改。** 工作台会替换中间对话界面，因此打开工作台或选择模块就是同步点。这些有界读取即可观察工具修改，无需永久浏览器定时器。

## 后果

- 普通对话可以完成所要求的五个工作台工作流，手动操作与 agent 操作共享同一权威修订和校验路径。
- 课程表 action 无法在写入年级目录后报告完成本周导入，也无法静默折叠上午和下午重复使用的本地节次编号；模型必须先修正目标或节次映射，持久化才能成功。
- 名册、课程表与成绩导入使用随用户消息准入的隐藏 OCR 上下文。多模态模型也可以直接读取附加图片，再调用相同修改工具。
- 读取已存试题图片会在工具结果和后续 Session 历史中增加一个持久图片附件。纯文本路由会在读取或附加栅格图前失败；支持图片输入的路由会收到来源尺寸，以及提交来源像素编辑时所需的附件预览缩放信息。
- 对话 PDF 切题只有在当前用户请求说出保存目标后才能开始，因此选择根目录或完整叶子路径可能增加一次澄清轮次。
- PDF 来源独立于会话保留策略持久化在 `sourcesRoot` 下。内容寻址会去重相同上传，但自动过期与垃圾回收仍延后实现。
- agent 生成的 Office 文件是 `generatedRoot` 下的私有 Host 产物。工具会报告其路径；浏览器下载交接仍延后实现。
- 已挂载文件系统提供方允许时，本地目录生成可以读取会话当前工作目录以外的嵌套图片。它会拒绝跳出所选目录的路径、循环、超限输入和超过 120 张的图片；来源字节只短暂保留。
- 七个额外工具 schema 会增加每次普通 Web 模型请求的前缀。试题切割还会产生 MinerU 提取，以及每个已配置页面组一次语义子 agent 调用。
- 当前工作台文档属于部署全局，因此来源与生成根目录沿用同一单工作台部署作用域，不引入独立用户授权模型。

## 测试

Host 测试固定七个工具注册、板块读取、支持图片与纯文本的模型路由处理、持久图片结果呈现、有效及越界矩形消除、语义新增／编辑／删除／导入 action、本周／年级目录分离、重复时段拒绝、课程表写后读回确认、成绩身份解析、冲突重试、试题目录与图片操作、分发、本地目录 Office 生成、按学生生成的浏览器同款默认值、显式选择已分发图片、输出存储、内容寻址来源完整性、缺失或猜测试题保存目标的拒绝，以及使用确定性 OCR 几何和语义边界的真实 PDF 到试题批次流程。对话测试固定 PDF 提取与暂存并行执行、“发送”门控和已记录来源元数据。API 测试固定提示词封装与协议 schema。客户端组件测试固定工作台打开或切换模块时重新读取 Host。无外部依赖的组装 Web 快照在既有语义试题分割子 agent 旁固定七个模型可见工具名称、已存图片读取说明、课程表路由说明和试题切割 action 说明。
