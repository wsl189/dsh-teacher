# Agent Note: 视觉复核试题分割

Status: implemented

[English](2026-08-24-vision-reviewed-question-segmentation.md) | 中文

## Problem

OCR 文本与几何能够说明已识别元素出现在哪里，却不能稳定判断两个题头区间内部的语义转换。合订讲义可能在一道题之后、下一道题之前放置章节讲解、例题答案或另一份试卷的答案部分。即使题头列表正确，只把下一道已选题头当作唯一终点，仍会把这些无关内容并入上一题。

第一份边界草稿也无法证明渲染结果可用。即使元素引用通过校验，裁剪仍可能跨入相邻栏、漏掉图形或整道题、保留答案块，或过早结束。在一次语义判断后立即保存，会让这些缺陷直接持久化，而模型没有机会查看自身决策实际产生的像素。

大型扫描页面会让每份视觉预览的 Base64 负载达到数 MB。带重复捕获的整串正则表达式可能在边界子 agent 启动前耗尽 JavaScript 正则栈，即使预览字节和配置的大小限制都合法。

## Decision

浏览器与普通对话管线都会渲染每个所选来源页，并通过本轮专用图片工具把预览交给各语义页组子 agent。规范 Base64 校验使用有界长度检查和字节往返，不再对完整负载运行正则表达式。子 agent 会逐步读取图片，默认每次最多四张；只有全部页面预览和全部有界 OCR 分块都已检查，边界草稿才可能被接受。未声明图片输入能力的路由会明确失败，不会静默退回纯文本分割。图片工具结果使用已存附件，因此每份模型可见预览都能从子 Session 日志重建。每个语义组默认最多拥有四个所选页和 12 个可疑题头候选，并检查两侧各一个相邻所选页。候选密度会让题册在页数上限前拆组，而普通试卷保留较大分组和跨组续题上下文。

初始边界阶段允许配置全新子 agent 的运行总次数，默认值为两次。子 agent 如果以虚构、过期或其他未接受的最终令牌结束，就不会贡献任何草稿；下一个子 agent 会收到明确恢复指令，同时重置来源检查、已接受令牌和提交去重状态。只有经校验的几何才能成功，墙钟截止时间仍约束整个阶段。

每道题的草稿对象可以声明一个 `stopBeforeElementId`。该 id 是排他性边界，表示这道题之外的第一个 OCR 元素；根级 `stopBeforeElementId` 同样表示完整检查文档范围之外的第一个元素。同一元素不能既是停止位置，又被 `additionalElementIds` 声明为题内内容。高召回候选不会被强制提升为试题，但每个候选都必须归类为已选题头、保留的非题头内容或排除像素；Host 会拒绝静默遗漏。带明确题干的例题标签也进入这组召回提示，但仍由子 agent 判断其语义角色。语义分组在归类全部候选后可以提交零道题，因此带编号的定义、公式、方法步骤、理论总结和答案文字不会强制产生虚构裁剪。识别出的层级章节标题、答案标题，以及带方括号或冒号前缀的答案／解析块会自动排除，并且即使子 agent 漏报，也会成为最近的适用硬停止位置；Host 还会拒绝把该转换元素选为题头。只有来源引用标签而没有任何非题头内容归属时，Host 也会拒绝它独立成题；同一标签拥有题干、选项、小问、表格或图形时仍然有效。Host 会校验顺序、元素身份和自相矛盾的归属，从 OCR 几何推导初始矩形，并在同页分栏重新归属期间也把单题停止位置视为硬限制。相邻的题内框与题外框之间存在纵向空隙时，裁剪边缘会落在空隙中点；相邻题头框重叠不超过裁剪边距时，两道题共享后一个题头的上边作为硬切线，避免互相带入题头。自动归属元素与尾部元素簇的间距超过页高的 `maxQuestionAutoOwnedGapRatio` 时，会在该元素簇前停止；元素簇中含有显式附件声明时除外。这项结构兜底会把脱离末题的答案、防盗版文字和后续试卷内容排除，同时保留有意声明的远距离配图。只有另一道纵向重叠题头与附件的横向距离更近时，附件归属才发生冲突；左栏题头不会仅因 y 范围重叠而拒绝右栏配图。

初步渲染完成后，首次完整分组复核会通过相互独立的渐进图片工具接收全部裁剪图和每个核心来源页，因此能发现整页题目全部漏掉的情况；后续裁剪级复核只接收被点名题目及其局部来源页。只有对比检查完全部请求图片，并把每道独立来源题映射到一张裁剪图，它才能接受初始分组。每张合格裁剪都要在 `answerDemand` 中记录学生需要产生的可见作答；编号或主题标题不能作为该证据。缺陷工具可以逐次接收一条合格或异常记录，只有覆盖完整后才确认，同时保留用于有意原子替换的完整数组提交。这避免高密度分组被迫构造一个大型嵌套工具参数，也符合模型逐图检查的自然顺序。带有题干的例题即使后面紧跟印刷答案与解析，也必须为题干保留一张裁剪。没有单一作答要求的整页理论或知识梳理裁剪属于伪题。整道题没有独立裁剪时，即使部分像素混入相邻题，也属于来源页缺陷；完整分组替换可以补回漏掉的题头。伪题裁剪使用一条同时包含其裁剪 id 与来源页 id 的缺陷授权 `removedCropIds`；Host 只删除该题头并保留分组内其他题目。纯来源页缺陷只表示完全没有任何现有裁剪的整道漏题，描述中点名现有裁剪会被拒绝。两张裁剪之间发生内容转移时，两张图都必须记录缺陷，使下一轮仍只处理这些局部图片。初判没有题目的分组仍会在没有裁剪 id 的情况下进入来源页复核；复核者会确认来源中确实没有独立题目，或报告纯来源页缺陷并补回遗漏题头。漏题、混入相邻题、题干、答题横线或图形被截断，以及包含答案、讲解、标题、页脚、脱离题目的页底块或相邻栏内容都属于缺陷。合格复核会确认全部合格记录，完全不读取 OCR。在修正被接受之前，子 agent 可以在进一步检查后替换误报，无需为自己已经确认合格的裁剪虚构几何修改。更新缺陷集合会清空被拒草稿指纹，因为新补充的页面证据可能让同一修正获得授权。复核阶段与初始分割使用同一个可配置的全新子 agent 运行次数上限。每次恢复都会重置已检查图片、已检查 OCR 分块、累计归类、缺陷与修正提交次数、已接受令牌和被拒草稿指纹；子 agent 只能归类本次列出的裁剪 id，并返回本轮实际接受的准确令牌。

裁剪级缺陷会开放 OCR 和按被引用稳定来源题头索引的边界补丁。Host 在校验时补入分组中的全部未变题头，只把已提交题头合并回现有分组，并拒绝修改未引用题目或未改变被引用裁剪的修正。裁剪缺陷即使同时引用来源页作为证据，也仍然只能局部合并。`removedCropIds` 同样保持局部：每个 id 必须由一条同时包含裁剪 id 与其某个来源页 id 的缺陷授权，Host 只删除这些稳定题头并重新编号剩余题目。只有用于完全没有现有裁剪的整道漏题的纯页级缺陷才会开放完整分组替换；Host 会拒绝在纯页级缺陷描述中点名现有裁剪。仅补回附件的补丁会用已校验元素框扩展现有区域，不会重建其归属区间。它会移除与显式补回附件重叠的白色消除区，同时保留原有相邻题停止位置和所有无关消除区。绘制的答题横线等可见内容没有可用 OCR 元素时，复核者只能以 OCR 页坐标单位修改被点名来源切片的上边界或下边界。Host 保留 `left`、`right` 与 `rightLimit`，要求完整保留题头，并且只在实际采样来源矩形跨越另一道题头时拒绝纵向修改；等宽输出中的白色补边不会造成误判。

调用方对单张异常图片最多应用两次局部重切。未受影响的裁剪及其像素不会进入后续复核请求，来源页只作为只读上下文。已校验的伪题删除和几何发生变化的每道题都会进入局部后续复核；未被消费的纯页级缺陷仍可通过完整替换草稿补回整道漏题。第二次结果仍被报告有问题时，调用方保存该最后结果，不让整份 PDF 失败。

Web 后台控制器与对话驱动的 Host 渲染器使用同一分割请求、视觉复核 Remote、分组替换、宽度计算和收敛规则。导航可以让 Web 进度视图暂时卸载，但不会中断插件拥有的队列。对话切题仍单独要求显式保存目标；视觉复核不会增加默认目录。

## Alternatives considered

**只在首次边界判断中使用页面预览。** 这能改善语义理解，却无法发现已接受区域与最终栅格结果之间的不一致。

**只复核产出的裁剪图。** 单张裁剪可能看起来内部完整，但来源中的整道题可能已经漏掉。必须把完整裁剪序列与来源页对比，才能发现漏题。

**让复核者替换完整像素矩形。** 不受约束的视觉坐标会产生第二套横向几何体系，并可能破坏统一宽度规则。因此，复核修正仍用 OCR id 表示语义归属；只有可见内容没有元素 id 时，才允许在同一页坐标单位中提交经 Host 校验的上边界或下边界修改。

**保留固定的题头到下一题头归属，再增加更多排除模式。** 模式列表无法枚举合订来源中的任意章节正文、例题解析或答案转换。单题终点让 agent 描述自己观察到的语义停止位置，同时不削弱坐标校验。

## Consequences

- 试题切割现在要求已配置工具模型具备图片能力；除 MinerU 与 OCR 来源调用外，还会产生页面预览和裁剪复核的图片 token。
- 复核子 agent 及其图片附件会增加 Session 日志与附件存储，但完整的模型可见决策仍可回放。
- 初步裁剪和零题分组都会在持久化前经过视觉检查。模型超时或视觉路由不可用仍会失败。被拒绝的修正会保留为局部未解决复核，让有界后续继续运行，并最终保存局部最后结果，而不是让整份 PDF 失败。页数与候选数双重上限避免高密度题册在同一个子 agent 中累积数十张裁剪图，同时不把普通试卷降为单页分组。
- 初始边界或裁后复核子 agent 绕过工具时，默认可能增加一次全新模型运行。只有无效输出会承担这部分延迟，已接受令牌校验不会放宽。
- MinerU 仍然拥有元素身份与页坐标单位权威。视觉复核可以重新解释已识别元素，并从来源预览补回纵向空白或绘制横线，但不能虚构缺失的来源像素，也不能改变 Host 拥有的横向边界规则。

## Testing

Host 测试要求首次提交前读取全部页面预览，接受候选已全部归类的零题理论分组，校验数 MB 规范预览且不发生正则栈溢出，覆盖初始分割和裁后复核在虚构校验令牌后启动全新子 agent 的恢复，拒绝未归类的可疑题头，强制执行子 agent 漏报的层级章节转换，拒绝只有引用标签的伪题并接受拥有实际题目内容的同类标签，要求接受复核前读取全部请求裁剪图与来源页预览，要求每张合格裁剪提供可见作答要求证据，通过一条同时引用裁剪和页面的缺陷删除伪题，在合格路径保持 OCR 锁定，拒绝既作为停止位置又声明为题内内容的元素，拒绝未改变被点名几何的修正，在没有变化草稿时保留局部未解决复核，在局部补丁中保留被省略的相邻题，移除显式补回附件上方的消除区，接受不改变左右边界的局部纵向修改，拒绝实际采样来源跨越另一题头的修改，在跨越检查中忽略白色输出补边，拒绝改派给横向距离更近题头的附件，允许同一高度但位于所属栏的配图，裁掉未显式归属的脱离页底元素簇，保留显式附加的远距离配图，按语义顺序拼接页底题干与页顶续文，覆盖受污染裁剪的替换，并证明单题停止位置在分栏归属重算后仍是硬限制。页组测试同时覆盖页数与候选数上限。客户端控制器测试证明复核变化只重新渲染被点名的题目，同时保留分组级统一输出宽度，能够从空的初步分组补回漏题，并证明持续异常会保存第二次局部重切。对话流水线测试覆盖来源预览渲染、视觉复核调用与选定结果持久化。浏览器渲染测试校验准确的页面预览索引和 base64 像素。
