# Agent Note: 持久化教师工作台

Status: implemented

[English](2026-08-17-durable-teacher-workbench.md) | 中文

## 问题

教师需要在 dsh Web 应用内使用参考桌面工作台的日常管理面板、彼此关联的课程表和四项教学工作流。日常管理包括带截止时间与完成状态的待办、随记、时间与天气，以及带农历、法定节假日和日期事项的日历。课程表必须显示今日、本周、年级和早晚自习，同时保持普通课程表关联，并防止年级课表班级进入无关模块；其他教学工作流包括备课资源、班级名册、成绩分析和教学记录。整体复制参考应用还会复制它的浏览器存储、独立配置与页面结构，使数据脱离 dsh 持久化，控件也脱离已组合的 Web 界面。

这些工作流共用一份带修订号的文档，但班级所有权随工作流不同：名册、考试与试题切割使用名册班级，今日课表、本周课表与早晚自习使用普通课表班级，年级课表则使用自己的班级。编辑过程中必须保持引用有效，并且多个浏览器窗口不能静默覆盖对方的更改。天气和语音识别还需要可随部署变化的参数，但不能另建第二份配置文件。

## 决策

`@deepseek-ai/dsh-host-teacher-workbench` 持有一份通过 schema 验证的 `teacher_workbench` storage-domain 文档。版本 6 文档在同一个单调递增的修订号下包含待办、随记、日期事项、规范化周课程表条目和全部教学模块的业务数据。每个班级声明名册、普通课表或年级课表用途。课程表条目引用非名册班级，标识课程或自习类型、星期和从一开始的节次，并存储可选时间、课程、教师和地点。schema 拒绝跨用途引用、未知班级及重复的班级、类型、星期和节次组合，删除班级会移除其课程安排。每条待办包含一个互斥的今日待办、重要事项或紧急事项分类，以及经过校验的十色色板键。它生成的 `teacherWorkbench` Remote 提供读取与整份文档的比较并设置写入；过时修订会返回当前文档，客户端因此可以重新应用一次变更。同一命名空间还提供不持久化的天气查询，通过可配置且兼容 Nominatim 的端点解析区县或城市文本，再从 Open-Meteo 请求预报。Host 校验两次响应并返回稳定的业务错误。

`@deepseek-ai/dsh-client-ui-teacher-workbench` 贡献一个 `sidebar.footer.action`、一个 `shell.overlay` 界面与一行 `settings.general.item`。overlay 接收渲染后的侧边栏与详情栏宽度，只占据中间栏并位于仍在挂载的会话之上，因此选择展开区中的模块时会保留应用侧边栏，而不是打开模态窗口，也不会在工作台内重复模块导航或标题栏。侧边栏折叠区展示日常管理、课程表和其他五个教学模块；侧边栏收起时，轨道操作会直接打开当前模块。工作台在运行时发出明确的 `sessions/navigate` 事件时关闭，因此选择其他 Session、再次选择当前 Session 或进入新会话都会恢复对话，而无关的会话列表更新会让当前模块保持打开。日常管理在标题右侧以右对齐方式显示时间、日期、地点与天气摘要；点击摘要会打开详细时间与预报板块，日历也可独立占满界面显示详细内容。今日待办、重要事项和紧急事项由三张同时可见的卡片分别持有；在卡片中新增会设置对应分类，编辑可把事项移到另一张卡片。重要事项和紧急事项行提供十色色板，今日待办行不显示颜色圆点。

今日课表、本周课表和早晚自习投影普通课表目录持有的条目，年级课表则投影独立年级课表目录持有的条目。本周课表负责普通班级选择和课程表变更。今日课表只读，默认跟随本周课表所选班级，也可按规范化教师姓名筛选该教师当天在全部普通班级的课程；可编辑筛选姓名与 dsh 教师姓名设置保持同步，今日课表以每节课的上课班级替代地点。早晚自习按条目类型筛选所选普通班级。每个可编辑视图都用纯图标入口新建班级。本周课表和早晚自习用纯图标入口删除所选普通班级，年级课表则为每个班级行提供纯图标删除操作；每个图标都保留无障碍名称和悬停提示。破坏性确认会指明班级及其课程安排级联关系，成功删除当前班级后会切换到下一个可用班级。年级课表只汇总所选年级的年级课表班级，因此其中的识别与编辑不会填充其他视图或教学模块。新建课表班级只接受班级名称和年级，不要求学科。工具栏不再提供新增课程入口。本周、年级与早晚自习视图的空白格会打开课程编辑器，并预填在该格可明确判定的班级、星期、节次和自习类型；按教师汇总的本周课表空白格保留班级待选。OCR 导入仅由可编辑的本周、年级与早晚自习视图提供，使用共享文档提取 Remote，支持图片、PDF、DOCX、PPTX 和 XLSX，并把每个识别到的班级、年级、类型、星期、节次、时间、课程、教师和地点开放给用户复核。确定性投影会展开合并单元格，跨多个表格区块映射分层的星期与班号表头，将上午和下午重复编号的节次转换为连续序号，复用已配置的班级名称，拆分紧凑排列的课程与教师姓名，并接受班级作为列、星期作为行且分别列出早读和晚自习的自习安排表。年级课表提取会保留丢弃的外围文本，因此主 Markdown 遗漏的年级标签仍可为序号班级列命名。班级名称不以“班”结尾的行保持未选中。一次导入会在自身目录中原子替换已占用的课程表位置。只有折叠、打开状态、当前模块、课程表筛选、板块展开状态和 OCR 复核留在浏览器本地；待办、随记、日期事项、课程表条目、资源、名册、成绩、模板和记录始终经由 Host 服务。[隔离年级课表班级](../bug-fix/2026-08-20-isolate-grade-timetable-classes.zh.md)说明目录拆分与 OCR 准入规则。

客户端注册 `ui-teacher-workbench` 设置命名空间，其中包含教师姓名、学校名称、默认学科、天气地点、浏览器语音识别语言、单科满分、优秀线和及格线。跨字段验证要求 `passScore <= excellentScore <= scoreFullMark`。这些参数使用普通 dsh 设置文件和通用设置生命周期，而不是功能专用配置文件。Host 插件配置选择地理编码端点并限制内存中的地点缓存数量。

实现迁移工作流行为，而不是源应用的呈现或存储。每个语音入口都会先请求麦克风权限，再启动浏览器语音识别；识别故障通过本地化通知呈现，成功文本则交给手动录入所用的同一套待办和随记编辑器。浏览器通过 Host Remote 请求天气，而不跨域直接连接外部服务；经过校验的响应不持久化，只有选定的地点文本进入 dsh 设置。Host 缓存已解析坐标，并按公共地理编码服务的请求限制串行发送缓存未命中的查询。`chinese-days` 提供农历、节气、法定节假日与调休上班日，教师添加的日期事项则留在 Host 文档。基于规则的校历和课程表投影使用 MinerU Markdown 或 HTML 表格，每个识别行在持久化前都可编辑。表格粘贴接受制表符分隔数据与带引号 CSV，成绩行依据持久的学生标识匹配，模板驱动的记录保留生命周期状态，删除所有者时会移除从属数据。该功能不增加模型可见输入，因此不增加 Session 事件。

## 考虑过的替代方案

**保留参考应用的 Local Storage。** 这会使教学数据绑定到单个浏览器配置文件，绕过 dsh 存储配置，也无法在窗口之间提供权威的修订冲突。

**把功能直接放入侧边栏包。** 侧边栏将持有业务状态和与其导航职责无关的大型产品界面，其他 Web 组合也无法以单个插件添加或移除该工作台。

**分别存储各模块。** 分离写入会使班级删除、名册更新、考试引用和模板删除跨越多次提交。当前数据量较小，一份带修订的文档可以更简单地原子更新数据关系；若校级数据量或多用户写入争用变得显著，则应改用独立修订的表。

**为每种课程表视图分别存表。** 复制今日、本周与早晚自习会使普通课程表的一次修改依赖同步，并允许部分失败后留下互相矛盾的记录。单个规范化条目集合仍是权威数据，班级用途则为年级课表提供独立目录，而无需复制存储模型。

**原样复制参考页面与配置。** 这会保留一个独立应用，而不是与 dsh slot、设置、本地化、Remote 传输和存储所有权组合。

**复制参考应用的天气与日历脚本。** 参考天气流程不验证服务响应，也无法可靠解析中国区县名称；自行维护节假日与农历计算还会重复一个持续维护的依赖。经过验证的地理编码、Open-Meteo 预报与 `chinese-days` 使外部数据解析保持明确，也避免产品自行维护日历计算代码。

## 后果

- 日常管理与教学数据（包括待办分类与颜色标记）可在重新加载后保留，并使用已配置的 dsh 存储后端；普通 dsh 设置则持有随部署变化的教师、天气、语音与成绩参数。
- 跨模块编辑是原子的，无效或跨目录标识会在持久化前被拒绝；并发窗口会收到明确的修订冲突，而不是丢失更改的后写覆盖。
- 本周课表与早晚自习共用普通班级；年级课表和名册班级即使显示名称相同，也会保留独立标识。
- 每次接受的变更当前都会重写一份文档。大型多用户部署可能需要表级修订，而无需改变六个客户端模块。
- 天气会由 Host 把已配置的地点文本发送给选定的地理编码服务，并要求 Host 能访问该服务和 Open-Meteo。语音识别取决于浏览器支持和麦克风权限，法定节假日覆盖范围则随 `chinese-days` 已发布年份变化。浏览器跨域与隐私策略不参与天气请求；任一能力不可用时，手动录入和持久化工作台数据仍可使用。
- 参考应用仅作为行为来源。它的视觉结构、浏览器存储和独立设置都不是运行时依赖。

## 测试

Host 测试覆盖初始数据、按目录限定的班级引用、课程表位置唯一性、班级删除级联、日常管理 schema、互斥待办分类与色板校验、持久化重启恢复、验证、不可变读取、比较并设置冲突、销毁顺序、区县地理编码、缓存淘汰、请求限速以及经过校验的天气服务结果。客户端测试覆盖彼此关联的普通课程表、独立年级课表班级、只读取名册的教学模块、班级与教师筛选、班级删除、选择回退、已有课程编辑、从空白格打开并按位置预填的新建课程、无学科课表班级新建、OCR 班级名称准入、丢弃的年级标题、班级列式自习安排表与复核、同时渲染的三张独立待办卡片、自动分类、优先事项颜色持久化、今日待办不显示圆点、随记、日历、Remote 天气、麦克风预检、语音故障与成功文本、教学模块命令、剪贴板解析、成绩汇总、设置验证、修订重试、重复会话导航事件、主界面 slot 接线和临时视图状态。Web 浏览器场景从持续显示的侧边栏选择模块，验证工作台作为不重复显示标题栏的可访问主内容区域，固定标题栏右对齐天气摘要和三张独立待办卡片，从本周课表空白格创建课程，编辑关联的普通课程表投影，删除普通班级及其课程安排，验证年级课表班级保持隔离，复核年级课表与早晚自习 OCR 导入，创建并重新加载独立分类的待办、优先事项颜色标记以及其他日常管理条目，再次选择当前 Session 以恢复其对话界面，再通过已组合的应用创建名册班级与学生，验证重新加载后的 Host 持久化，使用确定性的 Host 服务响应呈现区县天气，记录麦克风拒绝通知及其他可访问性投影，并通过通用设置写入全部工作台参数，整个过程不发起模型调用。
