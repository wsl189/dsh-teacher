# Agent Note: 可选试题保存目录

Status: implemented

[English](2026-08-24-optional-question-save-directory.md) | 中文

## 问题

PDF 页码选择面板默认选中试题库根目录，并暴露所有目录层级。因此，不操作控件会把无关试卷混成根目录直接图片，选择中间目录则允许新图片与其子目录并列。两种行为都无法区分自动按 PDF 归档与用户明确作出的目录组织选择。

## 决策

每次重新选择 PDF 后，保存目录控件都从未选择状态开始。明确选项只包含持久化叶子目录并显示完整层级路径；试题库根目录与含子目录的目录不可选择。

目录控件留空时，Web 切题会明确提交来源同名目录目标。Host 会从来源 PDF 文件名移除 `.pdf` 后缀并派生安全的根级目录名，再复用物理名称相同的持久化根目录，或者在写入首个图片分片的同一次可回滚操作中创建持久化标识与物理目录。明确选择的目标必须标识当前叶子目录，图片会直接保存在该叶子目录中。每个后续分片都会重复首个分片的目标。

纳入持久化关系的叶子目录及其祖先会在 `physicalName` 中保留准确的磁盘名称，并将其与显示文本分开。保存、重新加载、新建子目录、重命名和删除都在当前根目录下解析这些保留的名称。Unicode 规范化与首尾空白清理用于派生新目录名称，不用于解析已纳入的目录。不同的已有物理名称保持独立，即使其规范化标签相同。扫描行显示当前磁盘名称，文件系统派生标识会避开已被其他路径的持久化目录占用的 id。

自动目录仍然符合[仅显示物理目录的试题库树](../bug-fix/2026-08-24-physical-only-question-library-tree.zh.md)：该目录因为物理文件夹真实存在而显示，试卷批次名称与 id 仍然只是元数据，不会成为层级节点。

## 已考虑的替代方案

**继续默认选中根目录。** 这种方式保留根目录直接存储，却会把用户未操作当成目录组织选择，并在试题库根目录混合无关试卷。

**列出所有目录深度。** 中间目录可以同时包含直接图片与子目录，但允许选择它们会削弱新切图所要求的叶子目录组织方式。

**始终在所选目录下增加 PDF 同名子目录。** 这种方式会使明确选择变成间接目标，也会阻止多份 PDF 共用一个所选叶子目录。因此，明确选择表示直接保存到该叶子目录。

**从显示名称重新计算已有路径。** 清理首尾空白或规范化已有名称可能选中其他目录，或者创建同级目录。仅把路径保存在进程内扫描结果中，也会在重启后丢失该标识，因此纳入的物理名称属于持久化目录记录。

## 后果

未操作目录选项的上传会创建一个可见且真实的 PDF 同名根目录，而不是生成根目录直接图片。重复处理同名 PDF 会共用该目录，并使用防重名图片文件名。需要把多份试卷放在一起时，教师可以选择一个现有叶子目录；目录一旦增加子目录，其父目录就不会再出现在后续保存目录列表中。

## 测试

客户端覆盖固定未选择默认值与仅叶子路径列表。Host 集成覆盖检查 PDF 物理目录创建、持久化标识复用、续传位置、拒绝所选父目录和叶子目录直接存储。目录名回归覆盖空白字符、全角括号、已有长名称、重启后读取、续传保存、新建子目录、子树重命名与删除、规范化后相同的独立名称，以及在写入文件系统前拒绝不安全物理名称。组装 Web 快照记录页码面板选项，以及保存图片并新建子目录后仍保持唯一的原目录行。
