# Agent Note：工具模型课程表整理

Status: implemented

[English](2026-08-20-tool-model-timetable-normalization.md) | 中文

## 问题

MinerU 可以提取文本和表格标记，但学校课表没有统一可靠的版式。合并单元格、转置坐标轴、重复工作表、独立自习表、边缘年级标题和 OCR 阅读顺序错误都需要语义理解。解析器可能识别少数单元格，却无声遗漏大部分课程；非空结果不能证明完整性。错误行不能未经复核就写入持久课程表。

识别属于工作台。要求存在活跃用户会话，会阻止尚未创建对话时的导入，并让无关上传依赖会话切换和删除。后台工作也需要独立于对话默认值的模型选择。

## 决策

`agent-default-model` 设置将 `toolProvider` 和 `toolModel` 作为一个经过校验的字段对保存。`currentToolSelection()` 使用该字段对；两个字段均省略时才回退到当前默认提供方与模型。**设置 → 模型 → 工具模型** 按[视觉模型选择策略](2026-09-09-vision-tool-model-selection.zh.md)只列出可用的已配置视觉模型，并在一次修订号校验修改中写入两个字段。界面不接受自由输入的模型 id。

开始识别前，浏览器会捕获本周、年级或早晚自习目标、对应班级目录与当前默认值。每份上传都会交给工具模型子代理；浏览器不把 OCR 解析为课程条目。MinerU 提供来源文本和表格，包括所有已提取工作表。补充文本提取独立于 PDF 几何信息校验：原生 Office 页面没有 `page_size`，而依赖坐标的提取仍要求该字段。提取文本缺失、含糊或相互矛盾时，支持图片的子代理可以通过专用工具按需查看原始栅格图和放大视图。它们先读取细节文本，避免缩小整图覆盖清晰的单元格证据。图片提取失败时，子代理可以只使用原图；纯文本路由需要提取文本。

每次导入都通过 Agent 注册表新建隐藏父任务，再启动全新的 `spawn` 子代理。Remote 不含父会话字段。两个代理均不继承用户对话，也不要求用户对话存在。导入在成功、失败或取消后释放子代理和父任务；Host 工作台插件卸载会中止活跃导入并等待清理。临时来源、图片与校验工具属于单次导入，并随任务移除。

子代理会收到目标的显示含义及条目必需字段。本周视图按每个班级显示星期列和每日节次行；年级视图保留每个班级的完整周课表；早晚自习区分早自习、晚自习及各自时段。子代理自行理解标题、图例、合并单元格、局部节次序列和配套工作表，不要求固定方向或课程词典。来源内容始终是数据，而非指令。重复总表、分班表和明细表是同一课程安排的证据，课时统计与课程清单则不是课程。

大幅规则表格的 OCR 细节裁图会保留列标题和合并行标签。竖排字形使用原始像素横向排列；同一字形的分离笔画保持在一起，保留一、二、三的区别。网格不明确时使用普通重叠区域。HTML 压缩保留单元格位置，并把每行编码为 JSON 数组，使课程与教师之间的换行仍位于同一单元格。这些操作只准备证据；课表语义由子代理确定。

来源工具提供分节目录与有界 UTF-8 页面，并允许重读。否则，单次过大的工具结果可能被溢出预览替代，使受限子代理看不到中间行。子代理每次读取一个由表头限定的区块，立即按来源顺序提交其中的单元格，使用普通 JSON 条目批次及可选公共字段。继续处理前，它会逐格核对来源；工作台负责将条目排入视图。仅核对总数不能发现错位安排。返回的批次 id 可以替换或清空对应批次，而不影响其他已接受批次。无效字段、类型、时间、坐标、重复时段或过量总数会原子拒绝该批次。完成操作要求已核对的来源总数等于草稿条目数；结构化输出只包含该运行专用校验令牌。Host 为只有负责教师的自习安排补充类型标签。没有依据的年级可以留空；班级名称不要求固定后缀。

子代理不设置 `maxTokens`，由所选路由决定请求上下文容量与输出默认值。工作台配置限制来源字符数、工具分页字节数、接受条目数以及文本／图片截止时间。稳定错误与安全的提供方诊断会返回预览。教师切换视图时，浏览器仍保留已捕获目标，允许编辑和选择条目，并只在确认后进行一次带修订号的批量导入。

浏览器插件通过专用可观察控制器持有识别进度、锁定的默认值及可编辑复核条目。窗口是否显示由已挂载视图决定。关闭窗口、离开工作台或切换模块只移除界面订阅，不会取消处理；完成时更新保留的结果，不打开已隐藏的窗口。课程表每个视图都能重新打开待处理任务。新上传不能覆盖待处理任务或复核结果，只有主动清除或成功导入才释放已完成结果。持久化期间禁止重复提交，失败后保留已编辑条目。浏览器刷新或插件卸载会清除这些临时状态，它们不构成持久任务队列。

## 考虑过的替代方案

**规则结果非空时直接采用。** 部分解析看似成功，却跳过唯一的语义完整性检查。增加版式分支不能证明陌生文档已被完整理解。

**把识别挂到所选对话。** 不存在或未加载的对话会阻止无关工作台操作，删除对话也可能终止任务。全新内部父任务让导入拥有独立生命周期和日志。

**只使用模型直接看图。** PDF 和 Office 提取保留了有用的单元格文本及工作表结构，也允许纯文本模型参与。密集栅格表格同样受益于 OCR 细节区域。视觉与提取证据可以共同支持同一子代理。

**所有表格均使用固定矩形裁图。** 缺少班级表头或星期标签的裁图会丢失坐标证据。可靠网格线允许保留完整行组并重复表头；网格不明确时仍使用通用重叠裁图。

**使用对话模型选择。** 后台提取可能需要不同路由。更新对话默认值时会保留显式工具模型字段对。

**允许自由输入工具模型 id。** 这会引入拼写错误和不可用路由；已配置目录提供可实际使用的选项。

**立即导入结构化输出。** 模型重建具有不确定性。可编辑复核仍是写入教师持久数据的授权点。

## 影响

- 每次本周、年级和早晚自习上传都会独立调用模型；速度与识别质量取决于所配置的工具模型。
- 来源元数据、OCR 工具结果、图片附件、默认值和校验往返都对模型可见，并记录在子会话中。
- 子代理可以查看来源、提交或替换草稿批次，不能修改现有工作台条目或用户对话。
- 导入完成后没有活跃父任务或子代理；持久会话日志保留重建模型请求所需的证据。
- OCR 与模型重建均可能出错，因此始终要求复核。

## 测试

Host 测试覆盖配置模型选择、目标角色说明、批次校验、原子替换、来源分页与总数检查、已接受令牌约束、自习值班、独立父任务身份、纯文本模型使用 OCR、按需原图附件、超时和卸载清理、启动失败及临时工具释放。客户端测试覆盖三个目标、规则工作表仍交给代理、未选择会话时导入、目标上下文锁定、可编辑复核、班级命名、批量持久化、两个识别阶段移除订阅、卸载后的延迟返回，以及保存失败后保留草稿重试且不重复写入。组装后的 Web 测试使用真实子代理循环与外部模型脚本：15 个班级、五天、每天八节的样例包含没有 PDF 页面尺寸的原生 Office 元数据，在没有活跃用户会话时，分别从 PNG 与 XLSX 上传得到并保存 600 条复核记录；窗口关闭且其他模块挂载时，两个阶段均继续执行；返回课程表可以查看保留的结果，窗口不会自动重开。进度和完成状态有归属本模块的 ARIA 快照，重复导入仍保持 600 个时段。模型脚本证明应用流程，不代表对陌生文档的识别准确率。
