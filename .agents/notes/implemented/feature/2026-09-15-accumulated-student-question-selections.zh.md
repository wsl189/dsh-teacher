# Agent Note: 累积学生试题选集

Status: implemented

[English](2026-09-15-accumulated-student-question-selections.md) | 中文

> 扩展[试题切割工作台](2026-08-19-question-segmentation-workbench.zh.md)中的临时选集行为。其媒体根目录、分发图片和逐学生独立文档规则仍为当前依据。

## 问题

教师需要从一名学生下的多个目录选择图片，再生成一份文档。每次保存都替换整个暂存选集会丢弃之前目录中选择的图片，而仅收集来源路径无法在原图被编辑或删除后保留已选图片。

## 决策

“临时保存”在同一学生范围内按分发图片标识新增或更新独立图片快照。重复选择会更新同一份快照；不同文件即使同名也保持独立。本次未选择的暂存图片保留已有字节，重启后选集仍会保留。空的分发图片列表明确表示清空该学生的快照，不修改原图或保存历史元数据。

Host 串行执行保存，在待定目录中构建完整候选选集，并保留备份直到文档写入提交。已配置的总字节上限同时约束保留图片和本次所选图片；学生暂存与浏览器目录导出不设图片数量上限。校验、复制或持久化失败会保留原有选集。版本 2 的清单要求唯一分发图片标识，以及安全且唯一的存储文件名；旧版或格式无效的记录会报错并提示清空后重新选择，不会被静默覆盖。

浏览器显示该学生跨目录的暂存总数，并提供“清空暂存”。保存、清空或生成成功后会使更早的可用性查询失效，避免延迟响应恢复过期总数。Word 和 PowerPoint 分别读取按自然顺序排列的累积快照，为每名符合条件的学生生成一份文件；生成成功会清空该学生的选集。

已存储的 Office 输入逐张读取并完成 WebP 转换，避免活动文件读取与转换任务随选集数量增加。打包与 base64 传输会在内存中保留完整文档，因此字节检查可降低资源风险，但不保证每份通过校验的输入都能放入可用内存。

临时来源的可用性检查与生成从名册目录解析当前学生标识，不重新扫描试题库图片或作业后代目录。暂存字节保持独立于原图，设置修订变化仍会拒绝操作。浏览器保存转换直接填充预分配的字节数组；通过 `Uint8Array.from` 迭代二进制字符串会物化大得多的中间数组。部分写入失败后，保存窗口只保留失败文件，中止出错的可写流，并在请求被拒绝后解除忙碌控件。独立进度文字分别标识暂存、生成、选择目标位置和写入。

Office 保存使用已组合的 Host 目录选择器与专用的已认证 Remote 写入。选择器操作运行 DSH 的电脑，应用内标题会明确说明；它不能选择另一台浏览器电脑的目录。Host 接受现有绝对目录与规范的 Office 字节，保留目录中的空白字符，并以排他方式创建带防重名序号的文件。浏览器每次请求发送一个保留的产物，重试时只移除已成功写入的文件。文件刷新并关闭后才报告完成路径。仅使用浏览器的配置保留 File System Access 保存，但不会自动回退到下载。这将文档生成与浏览器目录写入权限分开，无需扩大浏览器权限。

## 考虑过的替代方案

**固定图片数量上限。** 数量检查会把大量小题图与同样数量的大扫描图视为相同负担，在没有衡量内存成本的情况下拒绝原本可处理的选集。已有字节检查继续生效，浏览器会提交目录中全部所选图片，不截断列表。

**按文件名去重。** 不同作业目录经常使用相同题目文件名，因此名称无法标识所选图片。

**不记录标识，直接追加每次保存。** 先选择子目录再选择父目录，会使两者共有的图片重复出现。

**重新读取所有已选原图。** 编辑、删除或来源文件丢失会改变或破坏已经成功保存的快照。

## 影响

教师可以通过多次进入目录来组成一份文档。清空和生成只影响所选学生的暂存集合。已有版本 1 暂存记录需要明确清空后重新选择；来源图片与持久化工作台记录保持不变。

## 测试

组装后的保存场景通过应用内选择器选中包含空格的真实 Host 目录。它先取消一次，再删除已选目录以触发真实写入失败，随后重建目录并在不重新生成的情况下重试。从该目录读取的文件包含全部 124 张 Word 图片与 124 张 PowerPoint 幻灯片；预先存在的同名文档保持不变。

Host 回归覆盖跨目录累积、重复选择、独立同名文件、来源删除、重启恢复、并发保存、学生隔离、清空、Office 图片数量、完整选集字节上限、500 张图片的 Word 与 PowerPoint 导出、快照字节丢失和无效清单。客户端覆盖累积总数、清空和拒绝延迟的可用性结果。组装浏览器场景重新加载已暂存子树，追加同级目录，生成含 124 张图片的 Word 和 124 页 PowerPoint，并验证清空不会删除原图。同一场景保留单个活动选择器及取消检查。浏览器目录回归验证全部 121 张所选图片均进入两种 Office 格式。这些小图片用例验证完整性，不代表与硬件无关的容量上限。额外回归覆盖无关试题库不可用、暂存与生成请求被拒绝、部分写入失败后的重试，以及 8 MiB 产物保存后的完整字节。客户端测试覆盖写入等待与重复点击；浏览器场景覆盖目标选择、真实写入失败与成功重试。
