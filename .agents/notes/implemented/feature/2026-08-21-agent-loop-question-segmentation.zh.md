# Agent Note: Agent-loop 试题分割

Status: implemented

[English](2026-08-21-agent-loop-question-segmentation.md) | 中文

> 页面证据、语义候选强制规则与单一文档级终点决策已被[视觉复核试题分割](2026-08-24-vision-reviewed-question-segmentation.zh.md)部分取代。不透明 OCR id、有界分组与 Host 拥有的坐标仍是权威来源。

## Problem

数学试卷 PDF 不具备统一可靠的阅读顺序或页面模板。顶层题目可能按分栏共用一页、跨页延续、包含下级编号，几何图也可能在 OCR 顺序中出现在下一道题题头之后。标题、说明、章节标签、页眉页脚和答案页同样可能与带编号题目相似。因此，只按题号形态与共同左边距工作的浏览器规则可能漏题、拆开小问、把图归到下一题，或夹入无关内容。模型可以判断这些语义角色，但不能把模型产生的坐标和标识符当作源文档事实。

## Decision

试题切割只把 MinerU 用作与提供方无关的页面几何来源。浏览器把所选页面发送给 `teacherWorkbench/segmentQuestions`，服务在当前活动 Session 下使用已配置工具模型与内置 `question-boundary-detection` 运行时 skill，启动一次短生命周期 `spawn` 子 agent。子 agent 只能调用本轮唯一的来源工具和边界提交工具。来源工具以有界分块返回带不透明 id 的有序 OCR 元素、文本、内容类别、页面尺寸与边界框；提交前必须读取全部分块。

边界草稿会说明从完整所选范围归纳出的题目起点模式，并为每道顶层题声明题头 id，不提交印刷题号。该模式可以使用任意数字或文本标签，可以在章节之间重复或重启、在合订来源内部变化，也可以在练习没有显式标签时依赖反复出现的语义起点。题目对象内的 `additionalElementIds` 会转移默认区间之外的 OCR 元素，包括分栏错序的续文与图形。根级 `excludedElementIds` 会移除章节标签、页眉、页码、水印和其他非题目元素，`stopBeforeElementId` 标记末题之后的首个元素。模型不提交坐标或显示序号。重复的已拒绝草稿不消耗重试次数。

Host 会按可信 OCR 序号排列提交的题头，并校验请求上限、元素 id、顺序、补充元素归属、非空裁剪，以及仅对本轮有效的接受令牌。它不解析或校验来源的编号语法，不强制把文本模式发现的候选提升为试题，也不自行推断分区标题与答案角色；这些语义判断由子 agent 根据 OCR 与页面证据完成。不过，每个可疑候选都必须明确归类为题头、保留的非题头或排除像素，遗漏不会成为静默结果。已接受题头按来源顺序获得唯一显示序号。默认最多接受五份不同草稿，截止时间为 60 分钟。已接受元素集合会映射回二维页面坐标，留白受相邻未归属内容限制。多页区域仍属于同一道题，PDF.js 会从浏览器保留的原 PDF 栅格化并纵向拼接后再持久化。

上传前，浏览器会读取所选 OCR 提供方当前的解码字节与页数限制，只把选中的源页面复制成有界 PDF 批次，再把各批相对版面页码恢复为原页码。多页批次超限时会不断二分；单个复制页仍超限时，会按已配置切题倍率栅格化，并逐步缩小到限制以内。原始 PDF 只保留在浏览器中，不受 OCR 上传大小限制，而每次 base64 请求与 MinerU 解析仍然有界。题目版面来源还会按序列化字符数独立分块，避免 agent-loop 溢出策略把后续页面隐藏在受限子 agent 无法读取的文件中。

OCR 版面合并后，Host 默认让每个语义核心组最多拥有 20 个所选页面和 300 个可疑题头候选，并在可用时加入两侧各一个相邻所选页供检查。每组运行一个独立子 agent；[切题有界并行决策](2026-08-26-bounded-parallel-question-cutting.zh.md)允许最多两组同时运行。Host 只保留已校验题头元素位于核心页的返回题目，因此重叠页可以解决跨组续文，又不会重复边界题目；随后不依赖任何印刷标签，为合并题目分配唯一的来源顺序显示序列。浏览器每次只渲染一个最终保存分组，并将该组的有序裁剪继续拆分到 `maxQuestionBatchBytes` 以下；Web 组合包默认设为 96 MiB，为 base64 JSON 在默认 160 MiB 请求载体内预留空间。首个保存分片创建一个逻辑试卷批次并返回不透明 id，后续分片全部追加到该 id，因此传输分片不会产生额外的试题库条目。该字节设置是单个保存分片的保护值，而不是源 PDF 或完整结果上限。

编号版式标记会在每一种精确页面尺寸内聚类为横向栏，其中包括已排除为学习者试题的编号定义、结论和组合理论标题。区域没有同高度右侧阻挡内容时，会在该尺寸族任意位置确定的下一栏起点停止；其归属 OCR 内容跨过该起点时除外。因此，整份 PDF 的统一输出宽度不会因为半空拼版而扩展到整张拼版，也不需要编码针对某份试卷的装订线坐标。

## Alternatives considered

**保留浏览器题号与左边距规则。** 该方案速度快，却把阅读顺序和单栏对齐当成语义，无法正确归属分栏交错元素、稳定区分带编号说明，或在不堆叠模板分支的前提下恢复跨页题目。

**让模型返回边界框。** 模型坐标不是源文档事实，可能漂移、越过页面或漏掉图形。不透明 id 让 MinerU 输出和 Host 继续拥有几何权威。

**只把页面图片交给视觉模型。** 该方案仍不采用，因为图片理解仍然需要坐标校验。后续的[视觉复核分割决策](2026-08-24-vision-reviewed-question-segmentation.zh.md)把渲染页面作为 MinerU 元素旁的强制辅助证据；图片不会成为坐标来源。

**一次工具调用返回完整版面。** 较长选择会超过 agent-loop 的内联工具结果限额，溢出到受限子 agent 无法读取的文件。有界且必须完整读取的分块同时保留工具限制与完整检查。

**移除提供方上传限制。** 单次无界 base64 RPC 与同步 MinerU 请求会放大内存占用，并失去单次请求的资源上限。浏览器侧 PDF 复制既取消原文件限制，也保留有界传输与解析。

## Consequences

- 每次试题切割会在 MinerU 提取后为每个语义页组增加一次工具模型子循环；配置的组大小与单个子 agent 上限以更多长试卷调用换取有界内存。
- 子 agent 会看到 OCR 文本与几何，因此已选工具模型提供方会按其部署策略接收这些内容。来源、草稿修订与最终令牌都记录在子 Session 中。
- 题号重启、重复的变式标签和无编号练习都会形成唯一的持久化来源顺序显示序列。
- 初始裁剪坐标仍由 Host 推导，图片字节仍由浏览器从原 PDF 渲染。模型无法编造可接受的 id；后续视觉复核决策只允许使用 OCR 页坐标单位且经 Host 校验的纵向修改。
- MinerU 文本与非文本元素同时缺失的题目无法获得可信坐标。页面预览与渲染后复核会提升语义召回，但不会把模型坐标变成源文档事实。

## Testing

Host 回归覆盖半空双栏拼版、越过推断栏位的全宽归属内容，以及移动到下一栏的同页续题。真实 `segmentQuestions` 服务的组装 Web 快照记录其归一化输出宽度与准确区域右界。

Host 测试覆盖标题与题头区分、下级小问、跨页归属、图形、交错分栏、多行分区排除、题号重启、局部变式标签、无编号练习、答案页标题、OCR 损坏题头、编造与重复 id、候选显式归类、自动来源顺序归一化、来源上限、工具限制、接受令牌校验、生成显示序号、配置为 20 页时的 `20/20/5` 归属夹具、候选密度拆组、重叠页检查、按题头页去重，以及把后续保存分片持久化到同一试卷批次。MinerU 测试覆盖规范的大型 base64 输入、公布的限制，以及十页范围的串行 `4/4/2` 版面分批。客户端测试覆盖带源页码恢复的精确页面 PDF 分批、字节上限二分、超大单页栅格缩减、按解码字节拆分保存分片、页码范围解析、Host 分割接线、批次 id 传递，以及二维单页与多页渲染。

桌面三份 PDF 的 MinerU 记录版面通过最终 Host 与已配置 `qwen3.8:27b` 工具模型运行：167 个元素的八页竖版试卷 agent 阶段耗时 32.2 秒，92 个元素的四页竖版试卷耗时 25.0 秒，103 个元素的四页双栏横版试卷耗时 52.6 秒。三份都连续返回第 1 至第 19 题。像素复核确认横版第 17 题保留几何图且不含第 18 题，八页试卷排除了后续章节标签与答案页标题，各下级小问均留在对应顶层题内。把已记录 MinerU 耗时与这些最终 agent 耗时合并后，折算每十页约 78 秒，低于十分钟目标。
