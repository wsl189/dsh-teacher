# 工作台提醒共用自动化任务页面

[English](guide.md) | 中文

## 变更

**自动化任务 → 工作台提醒**取代原先显示工作台提醒的独立**定时任务**入口。待办、备忘录、账目和日历提醒保留原文档、机器人选择与通知运行时。共用搜索与状态筛选也适用于这些活动记录。选择提醒会打开工作台进行编辑。

发行版不再挂载或包含 `dsh-plugin-cron` 及其 `cron_add`、`cron_list`、`cron_remove`、`cron_run` 工具。官方 Schedule 仍支持基于会话的自动化，包括其自己的 cron 重复规则。旧命令任务不会转换为会话提示，也不再通过已移除的内置插件执行。

## 迁移

1. 打开**自动化任务**并检查**工作台提醒**。现有活动提醒会自动出现，不要重新创建为会话任务；在工作台中修改截止时间与通知选项。
2. 如果使用过命令任务，请保留旧 cron 存储和备份。应用不会删除 JSON 存储单元的 `cron.json` 或 `cron/jobs`、`cron/runs` 记录。需要继续执行的命令应在你明确配置的调度器中重新建立。
3. 如果自定义 profile 独立挂载了 `name` 为 `dsh-plugin-cron` 的行，请移除该行及其 profile 本地依赖，以移除旧界面与运行时。在恢复所需任务前保留其用户数据。
4. 验证从工作台切换至插件或自动化任务时能显示所选页面，并确认返回自动化任务后能看到提醒修改。
